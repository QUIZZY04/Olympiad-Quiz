NCERT Exercise 7.1: Distance Formula & Geometric Applications
Question 1
Find the distance between the following pairs of points: (i) $(2, 3), (4, 1)$, (ii) $(-5, 7), (-1, 3)$, (iii) $(a, b), (-a, -b)$.
[2 Marks]
✅ CBSE Board Standard Step-by-Step Solution
Figure 7.1: Coordinate Geometry — Distance & Section Formula P(x, y)

Distance Formula:

The distance between two points $P(x_1, y_1)$ and $Q(x_2, y_2)$ is given by:

$$d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$

(i) Points $(2, 3)$ and $(4, 1)$:

$$d = \sqrt{(4 - 2)^2 + (1 - 3)^2} = \sqrt{2^2 + (-2)^2} = \sqrt{4 + 4} = \sqrt{8} = 2\sqrt{2}\text{ units}$$

(ii) Points $(-5, 7)$ and $(-1, 3)$:

$$d = \sqrt{(-1 - (-5))^2 + (3 - 7)^2} = \sqrt{(4)^2 + (-4)^2} = \sqrt{16 + 16} = \sqrt{32} = 4\sqrt{2}\text{ units}$$

(iii) Points $(a, b)$ and $(-a, -b)$:

$$d = \sqrt{(-a - a)^2 + (-b - b)^2} = \sqrt{(-2a)^2 + (-2b)^2} = \sqrt{4a^2 + 4b^2} = 2\sqrt{a^2 + b^2}\text{ units}$$

Question 2
Determine if the points $(1, 5), (2, 3)$ and $(-2, -11)$ are collinear.
[2 Marks]
✅ CBSE Board Standard Step-by-Step Solution

Condition for Collinearity using Distance Formula:

Three points $A, B, C$ are collinear if the sum of the lengths of any two segments equals the length of the third segment (e.g., $AB + BC = AC$).

Let $A(1, 5)$, $B(2, 3)$, and $C(-2, -11)$.

  1. Distance $AB$:
    $$AB = \sqrt{(2 - 1)^2 + (3 - 5)^2} = \sqrt{1^2 + (-2)^2} = \sqrt{1 + 4} = \sqrt{5}$$
  2. Distance $BC$:
    $$BC = \sqrt{(-2 - 2)^2 + (-11 - 3)^2} = \sqrt{(-4)^2 + (-14)^2} = \sqrt{16 + 196} = \sqrt{212} = 2\sqrt{53}$$
  3. Distance $AC$:
    $$AC = \sqrt{(-2 - 1)^2 + (-11 - 5)^2} = \sqrt{(-3)^2 + (-16)^2} = \sqrt{9 + 256} = \sqrt{265}$$

Since $\sqrt{5} + 2\sqrt{53} \neq \sqrt{265}$, $AB + BC \neq AC$.

Conclusion: The given points $(1, 5), (2, 3)$ and $(-2, -11)$ are NOT collinear.

Question 3
Find the point on the x-axis which is equidistant from $(2, -5)$ and $(-2, 9)$.
[3 Marks]
✅ CBSE Board Standard Step-by-Step Solution

Step 1: Point Representation

Any point lying on the x-axis has its y-coordinate equal to 0. Let the required point be $P(x, 0)$.

Let the given points be $A(2, -5)$ and $B(-2, 9)$.

Step 2: Equate Distances

Since $P$ is equidistant from $A$ and $B$, $PA = PB \implies PA^2 = PB^2$.

$$(x - 2)^2 + (0 - (-5))^2 = (x - (-2))^2 + (0 - 9)^2$$ $$(x - 2)^2 + 25 = (x + 2)^2 + 81$$

Step 3: Expand and Solve for $x$

$$(x^2 - 4x + 4) + 25 = (x^2 + 4x + 4) + 81$$ $$x^2 - 4x + 29 = x^2 + 4x + 85$$ $$-4x - 4x = 85 - 29$$ $$-8x = 56 \implies x = \frac{56}{-8} = -7$$

Final Answer: The point on the x-axis which is equidistant from the given points is $(-7, 0)$.

Question 4
Find the values of $y$ for which the distance between the points $P(2, -3)$ and $Q(10, y)$ is 10 units.
[3 Marks]
✅ CBSE Board Standard Step-by-Step Solution

Step 1: Formulate Equation using Distance Formula

Given $P(2, -3)$ and $Q(10, y)$, and $PQ = 10\text{ units}$.

$$PQ^2 = (10)^2 = 100$$ $$(10 - 2)^2 + (y - (-3))^2 = 100$$ $$8^2 + (y + 3)^2 = 100$$ $$64 + (y + 3)^2 = 100$$

Step 2: Solve for $y$

$$(y + 3)^2 = 100 - 64 = 36$$

Taking square root on both sides:

$$y + 3 = \pm\sqrt{36} = \pm 6$$
  • If $y + 3 = 6 \implies y = 6 - 3 = 3$
  • If $y + 3 = -6 \implies y = -6 - 3 = -9$

Final Answer: The possible values of $y$ are $3$ and $-9$.

Question 5
Find the coordinates of the point which divides the join of $(-1, 7)$ and $(4, -3)$ in the ratio $2 : 3$.
[2 Marks]
✅ CBSE Board Standard Step-by-Step Solution

Section Formula:

The coordinates of the point $P(x, y)$ dividing the line segment joining $A(x_1, y_1)$ and $B(x_2, y_2)$ internally in the ratio $m_1 : m_2$ are:

$$x = \frac{m_1 x_2 + m_2 x_1}{m_1 + m_2}, \quad y = \frac{m_1 y_2 + m_2 y_1}{m_1 + m_2}$$

Substitution:

Here $(x_1, y_1) = (-1, 7)$, $(x_2, y_2) = (4, -3)$, $m_1 = 2$, and $m_2 = 3$.

$$x = \frac{2(4) + 3(-1)}{2 + 3} = \frac{8 - 3}{5} = \frac{5}{5} = 1$$ $$y = \frac{2(-3) + 3(7)}{2 + 3} = \frac{-6 + 21}{5} = \frac{15}{5} = 3$$

Final Answer: The coordinates of the dividing point are $(1, 3)$.

Question 6
Find the coordinates of the points of trisection of the line segment joining $(4, -1)$ and $(-2, -3)$.
[3 Marks]
✅ CBSE Board Standard Step-by-Step Solution

Concept of Trisection:

The points of trisection divide a segment into three equal parts. Let $P$ and $Q$ trisect $AB$ joining $A(4, -1)$ and $B(-2, -3)$.

  • $P$ divides $AB$ in the ratio $1 : 2$.
  • $Q$ divides $AB$ in the ratio $2 : 1$ (or $Q$ is the midpoint of $PB$).

1. Coordinates of Point $P$ ($m_1 : m_2 = 1 : 2$):

$$x_P = \frac{1(-2) + 2(4)}{1 + 2} = \frac{-2 + 8}{3} = \frac{6}{3} = 2$$ $$y_P = \frac{1(-3) + 2(-1)}{1 + 2} = \frac{-3 - 2}{3} = -\frac{5}{3}$$

Thus, $P = \left(2, -\frac{5}{3}\right)$.

2. Coordinates of Point $Q$ ($m_1 : m_2 = 2 : 1$):

$$x_Q = \frac{2(-2) + 1(4)}{2 + 1} = \frac{-4 + 4}{3} = \frac{0}{3} = 0$$ $$y_Q = \frac{2(-3) + 1(-1)}{2 + 1} = \frac{-6 - 1}{3} = -\frac{7}{3}$$

Thus, $Q = \left(0, -\frac{7}{3}\right)$.

Final Answer: The points of trisection are $\left(2, -\frac{5}{3}\right)$ and $\left(0, -\frac{7}{3}\right)$.

Question 7
If $(1, 2), (4, y), (x, 6)$ and $(3, 5)$ are the vertices of a parallelogram taken in order, find $x$ and $y$.
[3 Marks]
✅ CBSE Board Standard Step-by-Step Solution

Geometric Property:

The diagonals of a parallelogram bisect each other. That is, the midpoint of diagonal $AC$ is identical to the midpoint of diagonal $BD$.

Given vertices in order: $A(1, 2), B(4, y), C(x, 6), D(3, 5)$.

1. Midpoint of $AC$:

$$M_{AC} = \left(\frac{1 + x}{2}, \frac{2 + 6}{2}\right) = \left(\frac{1 + x}{2}, 4\right)$$

2. Midpoint of $BD$:

$$M_{BD} = \left(\frac{4 + 3}{2}, \frac{y + 5}{2}\right) = \left(\frac{7}{2}, \frac{y + 5}{2}\right)$$

3. Equating Coordinates:

  • Equating x-coordinates:
    $$\frac{1 + x}{2} = \frac{7}{2} \implies 1 + x = 7 \implies x = 6$$
  • Equating y-coordinates:
    $$\frac{y + 5}{2} = 4 \implies y + 5 = 8 \implies y = 3$$

Final Answer: $x = 6$ and $y = 3$.

Question 8
Find the ratio in which the line segment joining $A(1, -5)$ and $B(-4, 5)$ is divided by the x-axis. Also find the coordinates of the point of division.
[3 Marks]
✅ CBSE Board Standard Step-by-Step Solution

Step 1: Point on x-axis

Let the point on the x-axis dividing the segment joining $A(1, -5)$ and $B(-4, 5)$ be $P(x, 0)$, dividing $AB$ in the ratio $k : 1$.

Step 2: Apply Section Formula for y-coordinate

$$y = \frac{k(5) + 1(-5)}{k + 1} = 0$$ $$\frac{5k - 5}{k + 1} = 0 \implies 5k - 5 = 0 \implies 5k = 5 \implies k = 1$$

Thus, the ratio is $1 : 1$ ($P$ is the midpoint of $AB$).

Step 3: Calculate x-coordinate

$$x = \frac{1(-4) + 1(1)}{1 + 1} = \frac{-4 + 1}{2} = -\frac{3}{2}$$

Final Answer: The x-axis divides the segment in the ratio $1 : 1$, and the coordinates of the point of division are $\left(-\frac{3}{2}, 0\right)$.

Niharika runs 1/4th the distance AD on the 2nd line and posts a green flag. Preet runs 1/5th the distance AD on the 8th line and posts a red flag. (i) What is the distance between both flags? (ii) If Rashmi has to post a blue flag exactly halfway between the line segment joining the two flags, where should she post her flag?

Step-by-step Solution:

  1. Total distance along $AD = 100\text{ m}$.
  2. Niharika's Flag Position (Green):
    $x_1 = 2$, $y_1 = \frac{1}{4} \times 100 = 25\text{ m}$. Coordinates = $(2, 25)$.
  3. Preet's Flag Position (Red):
    $x_2 = 8$, $y_2 = \frac{1}{5} \times 100 = 20\text{ m}$. Coordinates = $(8, 20)$.
  4. (i) Distance between the two flags:
    $$d = \sqrt{(8 - 2)^2 + (20 - 25)^2} = \sqrt{6^2 + (-5)^2} = \sqrt{36 + 25} = \sqrt{61}\text{ m} \approx 7.81\text{ m}$$
  5. (ii) Halfway point (Midpoint) for Rashmi's blue flag:
    $$x = \frac{2 + 8}{2} = \frac{10}{2} = 5, \quad y = \frac{25 + 20}{2} = \frac{45}{2} = 22.5\text{ m}$$ Rashmi should post her blue flag on the 5th line at a distance of 22.5 metres.
