NCERT Exercise 13.2: Mode of Grouped Data
Question 1
The following table shows the ages of the patients admitted in a hospital during a year:
Age (in years)5-1515-2525-3535-4545-5555-65
Number of patients6112123145
Find the mode and the mean of the data given above.
[4 Marks]
✅ CBSE Board Standard Step-by-Step Solution

Step-by-step Detailed Solution:

  1. Finding Modal Class:

    The maximum frequency is 23, which corresponds to the class interval 35 - 45.

    • Lower limit of modal class $l = 35$
    • Frequency of modal class $f_1 = 23$
    • Frequency of preceding class $f_0 = 21$
    • Frequency of succeeding class $f_2 = 14$
    • Class size $h = 45 - 35 = 10$
  2. Applying Mode Formula: $$\text{Mode} = l + \left(\frac{f_1 - f_0}{2f_1 - f_0 - f_2}\right) \times h$$ $$\text{Mode} = 35 + \left(\frac{23 - 21}{2(23) - 21 - 14}\right) \times 10$$ $$= 35 + \left(\frac{2}{46 - 35}\right) \times 10 = 35 + \left(\frac{2}{11}\right) \times 10 = 35 + \frac{20}{11} = 35 + 1.82 = 36.82\text{ years}$$
  3. Mean Calculation:

    Using $\bar{x} = \frac{\sum f_i x_i}{\sum f_i}$ with total patients $= 80$ and $\sum f_i x_i = 2830$:

    $$\bar{x} = \frac{2830}{80} = 35.375 \approx 35.38\text{ years}$$
  4. Interpretation:
    Mode $= 36.82\text{ years}$ (maximum number of patients admitted were of age 36.8 years).
    Mean $= 35.38\text{ years}$ (average age of all patients admitted is 35.38 years).

Calculate the median age, if policies are given only to persons having age 18 years on wards but less than 60 year: (Below 20: 2, Below 25: 6, Below 30: 24, Below 35: 45, Below 40: 78, Below 45: 89, Below 50: 92, Below 55: 98, Below 60: 100).

✅ CBSE Board Standard Step-by-Step Solution

Step-by-step Solution:

  1. Convert cumulative frequency distribution to class intervals ($h = 5$):
    • $15-20: f = 2$ ($cf = 2$)
    • $20-25: f = 6 - 2 = 4$ ($cf = 6$)
    • $25-30: f = 24 - 6 = 18$ ($cf = 24$)
    • $30-35: f = 45 - 24 = 21$ ($cf = 45$)
    • $35-40: f = 78 - 45 = 33$ ($cf = 78$)
    • $40-45: f = 89 - 78 = 11$ ($cf = 89$)
    • $45-50: f = 92 - 89 = 3$ ($cf = 92$)
    • $50-55: f = 98 - 92 = 6$ ($cf = 98$)
    • $55-60: f = 100 - 98 = 2$ ($cf = 100$)
  2. $N = 100 \implies N/2 = 50$. Cumulative frequency just greater than 50 is $78$.
    Median class $= 35 - 40, l = 35, cf = 45, f = 33, h = 5$.
  3. $\text{Median} = l + \left(\frac{N/2 - cf}{f}\right) \times h = 35 + \left(\frac{50 - 45}{33}\right) \times 5 = 35 + \frac{25}{33} = 35 + 0.76 = \mathbf{35.76\text{ years}}$

Answer: The median age is 35.76 years.

NCERT Exercise 13.3 • Q4
The lengths of 40 leaves of a plant are measured correct to the nearest millimetre, and the data is obtained: (118-126: 3, 127-135: 5, 136-144: 9, 145-153: 12, 154-162: 5, 163-171: 4, 172-180: 2). Find the median length of the leaves.
[4 Marks]
✅ CBSE Board Standard Step-by-Step Solution

Step-by-step Solution:

  1. The classes are non-continuous. Subtract 0.5 from lower limits and add 0.5 to upper limits:
    • $117.5 - 126.5: f = 3$ ($cf = 3$)
    • $126.5 - 135.5: f = 5$ ($cf = 8$)
    • $135.5 - 144.5: f = 9$ ($cf = 17$)
    • $144.5 - 153.5: f = 12$ ($cf = 29$)
    • $153.5 - 162.5: f = 5$ ($cf = 34$)
    • $162.5 - 171.5: f = 4$ ($cf = 38$)
    • $171.5 - 180.5: f = 2$ ($cf = 40$)
  2. $N = 40 \implies N/2 = 20$. The $cf$ just greater than 20 is $29$.
    Median class $= 144.5 - 153.5, l = 144.5, cf = 17, f = 12, h = 9$.
  3. $\text{Median} = l + \left(\frac{N/2 - cf}{f}\right) \times h = 144.5 + \left(\frac{20 - 17}{12}\right) \times 9 = 144.5 + \frac{27}{12} = 144.5 + 2.25 = \mathbf{146.75\text{ mm}}$

Answer: The median length of the leaves is $146.75\text{ mm}$.

Case-Study Competency Question
A city public health clinic records the systolic blood pressure (SBP in mmHg) of 100 middle-aged residents:
SBP (mmHg)100-110110-120120-130130-140140-150
Frequency1228321810

(i) Find the modal blood pressure class and compute the Mode.
(ii) Find the median class and estimate the Median.
(iii) Using the empirical relationship, approximate the Mean blood pressure.

Step-by-step Solution:

  1. (i) Modal class is $120-130$ ($f_1 = 32, f_0 = 28, f_2 = 18, h = 10, l = 120$):
    $$\text{Mode} = 120 + \frac{32 - 28}{2(32) - 28 - 18} \times 10 = 120 + \frac{4}{18} \times 10 = 120 + 2.22 = 122.22\text{ mmHg}.$$
  2. (ii) $N/2 = 50$. Cumulative frequencies: 12, 40, 72, 90, 100. Median class is $120-130$ ($l=120, cf=40, f=32, h=10$):
    $$\text{Median} = 120 + \left(\frac{50 - 40}{32}\right) \times 10 = 120 + \frac{100}{32} = 123.125\text{ mmHg}.$$
  3. (iii) By empirical relationship $3\text{ Median} = \text{Mode} + 2\text{ Mean}$:
    $$2\text{ Mean} = 3(123.125) - 122.22 = 369.375 - 122.22 = 247.155 \implies \text{Mean} \approx 123.58\text{ mmHg}.$$
Assertion & Reason HOTS Question
Assertion (A): If the value of each observation in a data set is increased by 5, then their mean also increases by 5.
Reason (R): The algebraic sum of the deviations of a set of values from their arithmetic mean is always zero.

CBSE Board Solution:

Both Assertion (A) and Reason (R) are true, but Reason (R) is NOT the correct explanation of Assertion (A).

Explanation: If new observations are $y_i = x_i + 5$, then $\bar{y} = \frac{\sum (x_i + 5)}{n} = \frac{\sum x_i}{n} + \frac{5n}{n} = \bar{x} + 5$. Reason (R) states that $\sum (x_i - \bar{x}) = 0$, which is a fundamental property of arithmetic mean but does not directly explain the linear shift property.
