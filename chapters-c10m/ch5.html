NCERT Exercise 5.1 & 5.2: Identifying AP & the n-th Term
Question 1
Write first four terms of the AP, when the first term $a$ and the common difference $d$ are given as follows: (i) $a = 10, d = 10$, (ii) $a = -2, d = 0$, (iii) $a = 4, d = -3$, (iv) $a = -1, d = \frac{1}{2}$.
[2 Marks]
✅ CBSE Board Standard Step-by-Step Solution

Formula:

The general terms of an AP with first term $a$ and common difference $d$ are: $a, a + d, a + 2d, a + 3d, \dots$

Calculations:

  1. (i) $a = 10, d = 10$:
    $a_1 = 10$, $a_2 = 10 + 10 = 20$, $a_3 = 20 + 10 = 30$, $a_4 = 30 + 10 = 40$.
    First four terms: 10, 20, 30, 40.
  2. (ii) $a = -2, d = 0$:
    All terms are equal: -2, -2, -2, -2.
  3. (iii) $a = 4, d = -3$:
    $a_1 = 4$, $a_2 = 4 + (-3) = 1$, $a_3 = 1 + (-3) = -2$, $a_4 = -2 + (-3) = -5$.
    First four terms: 4, 1, -2, -5.
  4. (iv) $a = -1, d = \frac{1}{2}$:
    $a_1 = -1$, $a_2 = -1 + \frac{1}{2} = -\frac{1}{2}$, $a_3 = -\frac{1}{2} + \frac{1}{2} = 0$, $a_4 = 0 + \frac{1}{2} = \frac{1}{2}$.
    First four terms: -1, -1/2, 0, 1/2.

Question 2
Find the: (i) 10th term of the AP: $2, 7, 12, \dots$, (ii) 30th term of the AP: $10, 7, 4, \dots$
[2 Marks]
✅ CBSE Board Standard Step-by-Step Solution

Formula for $n$-th Term of an AP:

$$a_n = a + (n - 1)d$$

(i) 10th term of the AP: $2, 7, 12, \dots$:

  • Here $a = 2$, common difference $d = 7 - 2 = 5$, and $n = 10$.
  • $$a_{10} = a + (10 - 1)d = 2 + 9(5) = 2 + 45 = 47$$
  • Answer: The 10th term is 47.

(ii) 30th term of the AP: $10, 7, 4, \dots$:

  • Here $a = 10$, common difference $d = 7 - 10 = -3$, and $n = 30$.
  • $$a_{30} = a + (30 - 1)d = 10 + 29(-3) = 10 - 87 = -77$$
  • Answer: The 30th term is -77.

Question 3
(i) Which term of the AP: $3, 8, 13, 18, \dots$, is 78? (ii) Check whether $-150$ is a term of the AP: $11, 8, 5, 2, \dots$
[3 Marks]
✅ CBSE Board Standard Step-by-Step Solution

(i) Which term of the AP: $3, 8, 13, 18, \dots$, is 78?

  • Here $a = 3$, $d = 8 - 3 = 5$, and $a_n = 78$.
  • $$a_n = a + (n - 1)d \implies 78 = 3 + (n - 1)5$$
  • $$78 - 3 = 5(n - 1) \implies 75 = 5(n - 1) \implies n - 1 = 15 \implies n = 16$$
  • Answer: 78 is the 16th term of the AP.

(ii) Check whether $-150$ is a term of the AP: $11, 8, 5, 2, \dots$:

  • Here $a = 11$, $d = 8 - 11 = -3$. Let $a_n = -150$.
  • $$-150 = 11 + (n - 1)(-3) \implies -150 - 11 = -3(n - 1) \implies -161 = -3(n - 1)$$
  • $$n - 1 = \frac{161}{3} \implies n = \frac{161}{3} + 1 = \frac{164}{3} = 54\frac{2}{3}$$
  • Since $n$ must be a positive integer (natural number) to be a term number, and here $n$ is a fraction, $-150$ is NOT a term of this AP.

Question 4
Find the 31st term of an AP whose 11th term is 38 and the 16th term is 73.
[3 Marks]
✅ CBSE Board Standard Step-by-Step Solution

Step 1: Set Up System of Equations

Let the first term of the AP be $a$ and the common difference be $d$.

  1. $11\text{th term} = a_{11} = 38$:
    $$a + 10d = 38 \quad \text{--- (1)}$$
  2. $16\text{th term} = a_{16} = 73$:
    $$a + 15d = 73 \quad \text{--- (2)}$$

Step 2: Solve for $a$ and $d$

Subtract equation (1) from equation (2):

$$(a + 15d) - (a + 10d) = 73 - 38$$ $$5d = 35 \implies d = 7$$

Substitute $d = 7$ into equation (1):

$$a + 10(7) = 38 \implies a + 70 = 38 \implies a = 38 - 70 = -32$$

Step 3: Calculate the 31st Term ($a_{31}$)

$$a_{31} = a + (31 - 1)d = a + 30d$$ $$a_{31} = -32 + 30(7) = -32 + 210 = 178$$

Final Answer: The 31st term of the AP is 178.

Question 5
How many three-digit numbers are divisible by 7?
[3 Marks]
✅ CBSE Board Standard Step-by-Step Solution

Step 1: Identify the Sequence

  • Smallest 3-digit number is 100. $100 \div 7 = 14$ with remainder 2. Smallest 3-digit multiple of 7 is $100 + (7 - 2) = 105$.
  • Largest 3-digit number is 999. $999 \div 7 = 142$ with remainder 5. Largest 3-digit multiple of 7 is $999 - 5 = 994$.
  • The sequence is: $105, 112, 119, \dots, 994$.
  • This forms an AP with:
    • First term $a = 105$
    • Common difference $d = 7$
    • Last term $a_n = 994$

Step 2: Calculate the Number of Terms ($n$)

$$a_n = a + (n - 1)d$$ $$994 = 105 + (n - 1)7$$ $$994 - 105 = 7(n - 1)$$ $$889 = 7(n - 1) \implies n - 1 = \frac{889}{7} = 127$$ $$n = 127 + 1 = 128$$

Final Answer: There are 128 three-digit numbers divisible by 7.

NCERT Exercise 5.3: Sum of First n Terms of an AP
Question 6
Find the sum of the following APs: (i) $2, 7, 12, \dots$, to 10 terms, (ii) $-37, -33, -29, \dots$, to 12 terms.
[2 Marks]
✅ CBSE Board Standard Step-by-Step Solution

Formula for Sum of First $n$ Terms:

$$S_n = \frac{n}{2}[2a + (n - 1)d]$$

(i) $2, 7, 12, \dots$, to 10 terms:

  • Here $a = 2, d = 5, n = 10$.
  • $$S_{10} = \frac{10}{2}[2(2) + (10 - 1)5] = 5[4 + 9(5)] = 5[4 + 45] = 5[49] = 245$$
  • Sum: 245.

(ii) $-37, -33, -29, \dots$, to 12 terms:

  • Here $a = -37, d = -33 - (-37) = 4, n = 12$.
  • $$S_{12} = \frac{12}{2}[2(-37) + (12 - 1)4] = 6[-74 + 11(4)] = 6[-74 + 44] = 6[-30] = -180$$
  • Sum: -180.

Question 7
How many terms of the AP: $9, 17, 25, \dots$ must be taken to give a sum of 636?
[3 Marks]
✅ CBSE Board Standard Step-by-Step Solution

Step 1: Identify Parameters

AP: $9, 17, 25, \dots$

  • First term $a = 9$
  • Common difference $d = 17 - 9 = 8$
  • Sum $S_n = 636$

Step 2: Substitute into Sum Formula

$$S_n = \frac{n}{2}[2a + (n - 1)d]$$ $$636 = \frac{n}{2}[2(9) + (n - 1)8]$$ $$636 = \frac{n}{2}[18 + 8n - 8] = \frac{n}{2}[8n + 10] = n(4n + 5)$$ $$4n^2 + 5n - 636 = 0$$

Step 3: Solve the Quadratic Equation

Using the quadratic formula for $4n^2 + 5n - 636 = 0$:

$$D = b^2 - 4ac = 5^2 - 4(4)(-636) = 25 + 10176 = 10201$$ $$\sqrt{D} = \sqrt{10201} = 101$$ $$n = \frac{-b \pm \sqrt{D}}{2a} = \frac{-5 \pm 101}{8}$$ $$n = \frac{-5 + 101}{8} = \frac{96}{8} = 12 \quad \text{or} \quad n = \frac{-106}{8} = -\frac{53}{4}$$

Step 4: Conclude

The number of terms $n$ must be a natural number ($n \in \mathbb{N}$), so we reject the negative fraction $-\frac{53}{4}$.

Final Answer: 12 terms must be taken to give a sum of 636.

Question 8
200 logs are stacked in the following manner: 20 logs in the bottom row, 19 in the next row, 18 in the row next to it and so on. In how many rows are the 200 logs placed and how many logs are in the top row?
[5 Marks]
✅ CBSE Board Standard Step-by-Step Solution

Step 1: Mathematical Formulation

Number of logs in bottom row (1st row) $= 20$.
Number of logs in 2nd row $= 19$.
Number of logs in 3rd row $= 18$.
This forms an AP: $20, 19, 18, \dots$

  • First term $a = 20$
  • Common difference $d = 19 - 20 = -1$
  • Total number of logs $S_n = 200$

Step 2: Solve for Number of Rows ($n$)

$$S_n = \frac{n}{2}[2a + (n - 1)d]$$ $$200 = \frac{n}{2}[2(20) + (n - 1)(-1)]$$ $$400 = n[40 - n + 1] = n[41 - n] = 41n - n^2$$ $$n^2 - 41n + 400 = 0$$

Factorise $n^2 - 41n + 400 = 0$ (product $= 400$, sum $= -41 \implies -25, -16$):

$$(n - 25)(n - 16) = 0 \implies n = 25 \quad \text{or} \quad n = 16$$

Step 3: Test Feasibility for Both Values

  1. If $n = 25$:
    Number of logs in top (25th) row $= a_{25} = a + 24d = 20 + 24(-1) = 20 - 24 = -4$.
    The number of logs cannot be negative. Hence, $n = 25$ is impossible.
  2. If $n = 16$:
    Number of logs in top (16th) row $= a_{16} = a + 15d = 20 + 15(-1) = 20 - 15 = 5$.
    This is positive and realistic.

Final Answer: The 200 logs are placed in 16 rows, and there are 5 logs in the top row.

Case Study Question • Semicircular Spiral
A decorative gold wire spiral is made of thirteen successive semicircles, with centres alternately at A and B, starting with centre at A, of radii 0.5 cm, 1.0 cm, 1.5 cm, 2.0 cm, ... What is the total length of such a spiral? (Take $\pi = \frac{22}{7}$)

Step-by-step Solution:

  1. Length of semicircle of radius $r$ is $l = \pi r$.
  2. $l_1 = \pi(0.5)$, $l_2 = \pi(1.0)$, $l_3 = \pi(1.5), \dots, l_{13} = \pi(6.5)$.
  3. This is an AP with first term $a = 0.5\pi$ and difference $d = 0.5\pi$.
  4. Total length $L = S_{13} = \frac{13}{2}[l_1 + l_{13}] = \frac{13}{2}[\pi(0.5 + 6.5)] = \frac{13}{2}[7\pi]$.
  5. Substituting $\pi = \frac{22}{7}$:
    $$L = \frac{13}{2} \times 7 \times \frac{22}{7} = 13 \times 11 = 143\text{ cm}$$
  6. Answer: The total length of the spiral wire is 143 cm.
