Q1
Find the roots of the following quadratic equations by factorisation: (i) 2x² + x - 6 = 0, (ii) √2x² + 7x + 5√2 = 0.
5 Marks
✅ CBSE Board Standard Step-by-Step Solution

(i) Method of Factorisation:

Solve $2x^2 + x - 6 = 0$:

  1. Find two numbers whose product is $a imes c = 2 imes (-6) = -12$ and sum is $b = 1$. The numbers are $4$ and $-3$.
  2. Splitting the middle term:
    $$2x^2 + 4x - 3x - 6 = 0$$ $$2x(x + 2) - 3(x + 2) = 0$$ $$(2x - 3)(x + 2) = 0$$
  3. Zero-product rule:
    $$2x - 3 = 0 \implies x = rac{3}{2}$$ $$x + 2 = 0 \implies x = -2$$
  4. Roots: $x = rac{3}{2}, -2$.

(ii) Solving $\sqrt{2}x^2 + 7x + 5\sqrt{2} = 0$:

  1. Product $a imes c = \sqrt{2} imes 5\sqrt{2} = 5 imes 2 = 10$, sum $b = 7$. The numbers are $5$ and $2$.
  2. Splitting the middle term:
    $$\sqrt{2}x^2 + 2x + 5x + 5\sqrt{2} = 0$$ $$\sqrt{2}x(x + \sqrt{2}) + 5(x + \sqrt{2}) = 0$$ $$(\sqrt{2}x + 5)(x + \sqrt{2}) = 0$$
  3. Roots:
    $$\sqrt{2}x + 5 = 0 \implies x = - rac{5}{\sqrt{2}} = - rac{5\sqrt{2}}{2}$$ $$x + \sqrt{2} = 0 \implies x = -\sqrt{2}$$
  4. Roots: $x = -\sqrt{2}, - rac{5\sqrt{2}}{2}$.

Q2
Find the nature of the roots of the following quadratic equations. If the real roots exist, find them: (i) 2x² - 3x + 5 = 0, (ii) 3x² - 4√3x + 4 = 0, (iii) 2x² - 6x + 3 = 0.
5 Marks
✅ CBSE Board Standard Step-by-Step Solution

1. Theory of the Discriminant and Nature of Roots:

For a quadratic equation $ax^2 + bx + c = 0$ ($a eq 0$), the Discriminant is given by $D = b^2 - 4ac$:

  • If $D > 0$: Two distinct real roots exist: $x = rac{-b \pm \sqrt{D}}{2a}$.
  • If $D = 0$: Two equal real roots exist: $x = - rac{b}{2a}$.
  • If $D < 0$: No real roots exist (roots are imaginary).

2. (i) For $2x^2 - 3x + 5 = 0$:

  • Here $a = 2, b = -3, c = 5$.
  • $$D = b^2 - 4ac = (-3)^2 - 4(2)(5) = 9 - 40 = -31$$
  • Since $D < 0$, the equation has no real roots.

3. (ii) For $3x^2 - 4\sqrt{3}x + 4 = 0$:

  • Here $a = 3, b = -4\sqrt{3}, c = 4$.
  • $$D = (-4\sqrt{3})^2 - 4(3)(4) = (16 imes 3) - 48 = 48 - 48 = 0$$
  • Since $D = 0$, the equation has two equal real roots.
  • Finding the roots:
    $$x = rac{-b \pm \sqrt{D}}{2a} = rac{-(-4\sqrt{3}) \pm 0}{2(3)} = rac{4\sqrt{3}}{6} = rac{2\sqrt{3}}{3} = rac{2}{\sqrt{3}}$$
  • Roots: $x = rac{2}{\sqrt{3}}, rac{2}{\sqrt{3}}$.

4. (iii) For $2x^2 - 6x + 3 = 0$:

  • Here $a = 2, b = -6, c = 3$.
  • $$D = (-6)^2 - 4(2)(3) = 36 - 24 = 12 > 0$$
  • Since $D > 0$, the equation has two distinct real roots.
  • $$x = rac{-(-6) \pm \sqrt{12}}{2(2)} = rac{6 \pm 2\sqrt{3}}{4} = rac{2(3 \pm \sqrt{3})}{4} = rac{3 \pm \sqrt{3}}{2}$$
  • Roots: $x = rac{3 + \sqrt{3}}{2}$ and $x = rac{3 - \sqrt{3}}{2}$.

Q3
A train travels 360 km at a uniform speed. If the speed had been 5 km/h more, it would have taken 1 hour less for the same journey. Find the speed of the train.
5 Marks
✅ CBSE Board Standard Step-by-Step Solution

Step 1: Formulate the Mathematical Model

  • Total distance to be covered = $360 ext{ km}$.
  • Let the uniform speed of the train be $x ext{ km/h}$ ($x > 0$).
  • Time taken at original speed: $T_1 = rac{ ext{Distance}}{ ext{Speed}} = rac{360}{x} ext{ hours}$.
  • If the speed had been $5 ext{ km/h}$ more, new speed = $(x + 5) ext{ km/h}$.
  • Time taken at increased speed: $T_2 = rac{360}{x + 5} ext{ hours}$.

Step 2: Set Up the Equation

According to the given condition, it would have taken 1 hour less for the same journey:

$$T_1 - T_2 = 1$$ $$ rac{360}{x} - rac{360}{x + 5} = 1$$

Step 3: Simplify to a Quadratic Equation

$$360 \left[ rac{1}{x} - rac{1}{x + 5} ight] = 1$$ $$360 \left[ rac{(x + 5) - x}{x(x + 5)} ight] = 1$$ $$360 \left[ rac{5}{x^2 + 5x} ight] = 1$$ $$1800 = x^2 + 5x \implies x^2 + 5x - 1800 = 0$$

Step 4: Solve the Quadratic Equation

Splitting the middle term (product $-1800$, sum $5$): numbers are $45$ and $-40$.

$$x^2 + 45x - 40x - 1800 = 0$$ $$x(x + 45) - 40(x + 45) = 0$$ $$(x - 40)(x + 45) = 0$$ $$\implies x = 40 \quad ext{or} \quad x = -45$$

Step 5: Physical Feasibility and Conclusion

Since speed cannot be negative, we reject $x = -45$.
Therefore, $x = 40$.
Conclusion: The original uniform speed of the train is $40 ext{ km/h}$.

Competency Real-Life Geometry Problem
Question: The diagonal of a rectangular field is 60 metres more than the shorter side. If the longer side is 30 metres more than the shorter side, find the sides of the field.

Step-by-step Solution:

  1. Let the shorter side of the rectangular field be $x$ metres.
  2. Then, longer side = $(x + 30)$ metres, and diagonal = $(x + 60)$ metres.
  3. In a rectangle, the angle between sides is $90^\circ$. By Pythagoras Theorem:
    $$(\text{Diagonal})^2 = (\text{Shorter side})^2 + (\text{Longer side})^2$$
    $$(x + 60)^2 = x^2 + (x + 30)^2$$
  4. Expand both sides:
    $$x^2 + 120x + 3600 = x^2 + (x^2 + 60x + 900)$$
    $$x^2 + 120x + 3600 = 2x^2 + 60x + 900$$
    $$x^2 - 60x - 2700 = 0$$
  5. Factorise: product $-2700$, sum $-60$ $\implies -90$ and $30$.
    $$(x - 90)(x + 30) = 0 \implies x = 90 \text{ or } x = -30$$
  6. Since length cannot be negative, $x = 90$.
    Shorter side = 90 m; Longer side = $90 + 30 =$ 120 m.
Assertion & Reason Assessment
Assertion (A): The equation $(x - 2)^2 + 1 = 2x - 3$ is a quadratic equation.
Reason (R): Any equation of the form $ax^2 + bx + c = 0$, where $a, b, c$ are real numbers and $a \neq 0$, is a quadratic equation in variable $x$.

Evaluate whether Assertion (A) and Reason (R) are correct and if (R) explains (A).

CBSE Board Solution:

Both Assertion (A) and Reason (R) are true, and Reason (R) is the correct explanation of Assertion (A).

Simplification:
$$\text{LHS} = (x - 2)^2 + 1 = x^2 - 4x + 4 + 1 = x^2 - 4x + 5$$
Setting $\text{LHS} = \text{RHS}$:
$$x^2 - 4x + 5 = 2x - 3 \implies x^2 - 6x + 8 = 0$$
Since it has the standard form $ax^2 + bx + c = 0$ with $a = 1 \neq 0$, it is indeed a quadratic equation.
