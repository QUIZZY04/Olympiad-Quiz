NCERT Exercise 2.1: Geometric Representation of Zeroes
Question 1
The graphs of $y = p(x)$ are given in NCERT Fig. 2.10, for some polynomials $p(x)$. Find the number of zeroes of $p(x)$, in each case.
[2 Marks]
✅ CBSE Board Standard Step-by-Step Solution

Geometrical Principle:

The number of real zeroes of a polynomial $y = p(x)$ is equal to the number of points where the graph intersects or touches the x-axis.

(i) 0 Zeroes (Parallel)
(ii) 1 Zero (1 Point)
(iii) 3 Zeroes (3 Points)
(iv) 2 Zeroes (Parabola)
(v) 4 Zeroes (4 Points)
(vi) 3 Zeroes (Touches/Cuts)
Figure: NCERT Fig. 2.10 — Graphs of y = p(x) showing points of intersection/contact with the x-axis

Analysis of the 6 Graphs:

  1. (i) Graph 1: The graph is a horizontal line parallel to the x-axis. It does not intersect the x-axis at all.
    Number of zeroes: 0 (No zero).
  2. (ii) Graph 2: The curve intersects the x-axis at exactly 1 point.
    Number of zeroes: 1.
  3. (iii) Graph 3: The curve intersects the x-axis at 3 distinct points.
    Number of zeroes: 3.
  4. (iv) Graph 4: The parabola opens upwards and intersects the x-axis at 2 points.
    Number of zeroes: 2.
  5. (v) Graph 5: The curve intersects the x-axis at 4 distinct points.
    Number of zeroes: 4.
  6. (vi) Graph 6: The curve touches the x-axis at 2 points and intersects at 1 point, meeting the x-axis at a total of 3 points.
    Number of zeroes: 3.

NCERT Exercise 2.2: Zeroes and Coefficients of Quadratic Polynomials
Question 2
Find the zeroes of the following quadratic polynomials and verify the relationship between the zeroes and the coefficients: (i) $x^2 - 2x - 8$, (ii) $4s^2 - 4s + 1$, (iii) $6x^2 - 3 - 7x$.
[3 Marks]
✅ CBSE Board Standard Step-by-Step Solution

Standard Quadratic Relations:

For $p(x) = ax^2 + bx + c$, if $\alpha$ and $\beta$ are zeroes:

$$\text{Sum of zeroes: } \alpha + \beta = -\frac{b}{a} = -\frac{\text{Coefficient of } x}{\text{Coefficient of } x^2}$$ $$\text{Product of zeroes: } \alpha\beta = \frac{c}{a} = \frac{\text{Constant term}}{\text{Coefficient of } x^2}$$

(i) $x^2 - 2x - 8$:

  • Factorisation: $x^2 - 4x + 2x - 8 = x(x - 4) + 2(x - 4) = (x - 4)(x + 2) = 0$.
  • Zeroes: $\alpha = 4, \beta = -2$.
  • Verification:
    $\alpha + \beta = 4 + (-2) = 2$. From coefficients: $-\frac{b}{a} = -\frac{-2}{1} = 2$. (Verified)
    $\alpha\beta = 4 \times (-2) = -8$. From coefficients: $\frac{c}{a} = \frac{-8}{1} = -8$. (Verified)

(ii) $4s^2 - 4s + 1$:

  • Factorisation: $(2s - 1)^2 = 0 \implies s = \frac{1}{2}, \frac{1}{2}$.
  • Zeroes: $\alpha = \frac{1}{2}, \beta = \frac{1}{2}$.
  • Verification:
    $\alpha + \beta = \frac{1}{2} + \frac{1}{2} = 1$. From coefficients: $-\frac{-4}{4} = 1$. (Verified)
    $\alpha\beta = \frac{1}{2} \times \frac{1}{2} = \frac{1}{4}$. From coefficients: $\frac{1}{4}$. (Verified)

(iii) $6x^2 - 3 - 7x = 6x^2 - 7x - 3$:

  • Splitting middle term: $6x^2 - 9x + 2x - 3 = 3x(2x - 3) + 1(2x - 3) = (3x + 1)(2x - 3) = 0$.
  • Zeroes: $\alpha = \frac{3}{2}, \beta = -\frac{1}{3}$.
  • Verification:
    $\alpha + \beta = \frac{3}{2} - \frac{1}{3} = \frac{9 - 2}{6} = \frac{7}{6}$. From coefficients: $-\frac{-7}{6} = \frac{7}{6}$. (Verified)
    $\alpha\beta = \frac{3}{2} \times \left(-\frac{1}{3}\right) = -\frac{3}{6} = -\frac{1}{2}$. From coefficients: $\frac{-3}{6} = -\frac{1}{2}$. (Verified)

Question 3
Find the zeroes of the polynomials and verify the relationship between the zeroes and coefficients: (iv) $4u^2 + 8u$, (v) $t^2 - 15$, (vi) $3x^2 - x - 4$.
[3 Marks]
✅ CBSE Board Standard Step-by-Step Solution

(iv) $4u^2 + 8u$:

  • Factorisation: $4u(u + 2) = 0 \implies u = 0 \text{ or } u = -2$.
  • Zeroes: $\alpha = 0, \beta = -2$. Here $a = 4, b = 8, c = 0$.
  • Verification:
    $\alpha + \beta = 0 + (-2) = -2 = -\frac{8}{4} = -\frac{b}{a}$. (Verified)
    $\alpha\beta = 0 \times (-2) = 0 = \frac{0}{4} = \frac{c}{a}$. (Verified)

(v) $t^2 - 15$:

  • Factorisation: $(t - \sqrt{15})(t + \sqrt{15}) = 0 \implies t = \sqrt{15}, -\sqrt{15}$.
  • Zeroes: $\alpha = \sqrt{15}, \beta = -\sqrt{15}$. Here $a = 1, b = 0, c = -15$.
  • Verification:
    $\alpha + \beta = \sqrt{15} + (-\sqrt{15}) = 0 = -\frac{0}{1} = -\frac{b}{a}$. (Verified)
    $\alpha\beta = \sqrt{15} \times (-\sqrt{15}) = -15 = \frac{-15}{1} = \frac{c}{a}$. (Verified)

(vi) $3x^2 - x - 4$:

  • Factorisation: $3x^2 - 4x + 3x - 4 = x(3x - 4) + 1(3x - 4) = (3x - 4)(x + 1) = 0$.
  • Zeroes: $\alpha = \frac{4}{3}, \beta = -1$. Here $a = 3, b = -1, c = -4$.
  • Verification:
    $\alpha + \beta = \frac{4}{3} - 1 = \frac{1}{3} = -\frac{-1}{3} = -\frac{b}{a}$. (Verified)
    $\alpha\beta = \frac{4}{3} \times (-1) = -\frac{4}{3} = \frac{-4}{3} = \frac{c}{a}$. (Verified)

Question 4
Find a quadratic polynomial each with the given numbers as the sum and product of its zeroes respectively: (i) $\frac{1}{4}, -1$, (ii) $\sqrt{2}, \frac{1}{3}$, (iii) $0, \sqrt{5}$, (iv) $1, 1$, (v) $-\frac{1}{4}, \frac{1}{4}$, (vi) $4, 1$.
[3 Marks]
✅ CBSE Board Standard Step-by-Step Solution

General Formula for Quadratic Polynomial:

If $S$ is the sum of zeroes ($\alpha + \beta$) and $P$ is the product of zeroes ($\alpha\beta$), the family of quadratic polynomials is given by:

$$p(x) = k[x^2 - Sx + P], \quad k \in \mathbb{R}, k \neq 0$$

Calculations for Each Case:

  1. (i) $S = \frac{1}{4}, P = -1$:
    $$p(x) = k\left[x^2 - \frac{1}{4}x - 1\right] = \frac{k}{4}(4x^2 - x - 4)$$ Taking $k = 4$, the required polynomial is $4x^2 - x - 4$.
  2. (ii) $S = \sqrt{2}, P = \frac{1}{3}$:
    $$p(x) = k\left[x^2 - \sqrt{2}x + \frac{1}{3}\right] = \frac{k}{3}(3x^2 - 3\sqrt{2}x + 1)$$ Taking $k = 3$, the required polynomial is $3x^2 - 3\sqrt{2}x + 1$.
  3. (iii) $S = 0, P = \sqrt{5}$:
    $$p(x) = x^2 - 0x + \sqrt{5} = x^2 + \sqrt{5}$$
  4. (iv) $S = 1, P = 1$:
    $$p(x) = x^2 - x + 1$$
  5. (v) $S = -\frac{1}{4}, P = \frac{1}{4}$:
    $$p(x) = k\left[x^2 - \left(-\frac{1}{4}\right)x + \frac{1}{4}\right] = \frac{k}{4}(4x^2 + x + 1)$$ Taking $k = 4$, the required polynomial is $4x^2 + x + 1$.
  6. (vi) $S = 4, P = 1$:
    $$p(x) = x^2 - 4x + 1$$

Case Study Question • Parabolic Trajectory
A highway underpass is designed in the shape of a downward-opening parabola $p(x) = -x^2 + 2x + 8$. (i) Find the zeroes of this polynomial. (ii) What are the coordinates of the points where the underpass arch touches the road level ($y = 0$)? (iii) Find the maximum height of the arch above the road.

Step-by-step Solution:

  1. (i) Zeroes of the polynomial:
    Set $p(x) = 0$: $$-x^2 + 2x + 8 = 0 \implies x^2 - 2x - 8 = 0$$ $$(x - 4)(x + 2) = 0 \implies x = 4 \text{ or } x = -2$$ The zeroes are $4$ and $-2$.
  2. (ii) Road-level coordinates:
    The arch touches the road at $y = 0$, giving the points $(-2, 0)$ and $(4, 0)$. The width of the underpass at road level is $4 - (-2) = 6\text{ units}$.
  3. (iii) Maximum height of the arch:
    The vertex occurs at the midpoint of zeroes: $x = \frac{-2 + 4}{2} = 1$.
    Maximum height $= p(1) = -(1)^2 + 2(1) + 8 = -1 + 2 + 8 = 9\text{ units}$.
