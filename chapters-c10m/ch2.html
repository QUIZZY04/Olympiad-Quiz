Q1
Find the zeroes of the following quadratic polynomials and verify the relationship between the zeroes and the coefficients: (i) x² - 2x - 8, (ii) 4s² - 4s + 1, (iii) 6x² - 3 - 7x.
5 Marks
✅ CBSE Board Standard Step-by-Step Solution

Formula and Core Relationship:

For a standard quadratic polynomial $p(x) = ax^2 + bx + c$ ($a eq 0$):

  • $ ext{Sum of zeroes } (lpha + eta) = - rac{b}{a} = - rac{ ext{Coefficient of } x}{ ext{Coefficient of } x^2}$
  • $ ext{Product of zeroes } (lpha \cdot eta) = rac{c}{a} = rac{ ext{Constant term}}{ ext{Coefficient of } x^2}$

(i) For $x^2 - 2x - 8$:

  1. Splitting the middle term: Find two numbers whose product is $-8$ and sum is $-2$: these are $-4$ and $2$.
    $$x^2 - 4x + 2x - 8 = x(x - 4) + 2(x - 4) = (x - 4)(x + 2)$$
  2. Finding zeroes: Set $(x - 4)(x + 2) = 0 \implies x = 4$ or $x = -2$.
    So, $lpha = 4$ and $eta = -2$.
  3. Verification:
    Here $a = 1, b = -2, c = -8$.
    $ ext{Sum of zeroes} = lpha + eta = 4 + (-2) = 2 = - rac{(-2)}{1} = - rac{b}{a}$ [Verified]
    $ ext{Product of zeroes} = lpha eta = 4 imes (-2) = -8 = rac{-8}{1} = rac{c}{a}$ [Verified]

(ii) For $4s^2 - 4s + 1$:

  1. Factoring: $4s^2 - 2s - 2s + 1 = 2s(2s - 1) - 1(2s - 1) = (2s - 1)^2$.
  2. Zeroes: $2s - 1 = 0 \implies s = rac{1}{2}, rac{1}{2}$. Thus $lpha = rac{1}{2}, eta = rac{1}{2}$.
  3. Verification ($a = 4, b = -4, c = 1$):
    $lpha + eta = rac{1}{2} + rac{1}{2} = 1 = - rac{(-4)}{4} = - rac{b}{a}$ [Verified]
    $lpha eta = rac{1}{2} imes rac{1}{2} = rac{1}{4} = rac{c}{a}$ [Verified]

(iii) For $6x^2 - 3 - 7x$:

  1. Rearranging in standard form: $6x^2 - 7x - 3$.
  2. Splitting middle term (product $6 imes (-3) = -18$, sum $-7$): $-9$ and $2$.
    $$6x^2 - 9x + 2x - 3 = 3x(2x - 3) + 1(2x - 3) = (2x - 3)(3x + 1)$$
  3. Zeroes: $x = rac{3}{2}, x = - rac{1}{3}$. So $lpha = rac{3}{2}, eta = - rac{1}{3}$.
  4. Verification ($a = 6, b = -7, c = -3$):
    $lpha + eta = rac{3}{2} - rac{1}{3} = rac{9 - 2}{6} = rac{7}{6} = - rac{(-7)}{6} = - rac{b}{a}$ [Verified]
    $lpha eta = rac{3}{2} imes \left(- rac{1}{3} ight) = - rac{3}{6} = - rac{1}{2} = rac{c}{a}$ [Verified]

Q2
Find a quadratic polynomial each with the given numbers as the sum and product of its zeroes respectively: (i) 1/4, -1, (ii) √2, 1/3, (iii) 0, √5, (iv) 1, 1.
5 Marks
✅ CBSE Board Standard Step-by-Step Solution

Methodology and Formula:

If $lpha$ and $eta$ are the zeroes of a quadratic polynomial, the polynomial is given by:

$$p(x) = k [x^2 - (lpha + eta)x + lpha eta]$$

where $k$ is any non-zero real constant. Substituting $ ext{Sum} = S$ and $ ext{Product} = P$, we have $p(x) = k[x^2 - Sx + P]$.

(i) Given $ ext{Sum} = rac{1}{4}$ and $ ext{Product} = -1$:

  • Here $S = rac{1}{4}$ and $P = -1$.
  • $$p(x) = k \left[x^2 - rac{1}{4}x + (-1) ight] = k \left[ rac{4x^2 - x - 4}{4} ight]$$
  • Choosing $k = 4$, the required quadratic polynomial is: $4x^2 - x - 4$.

(ii) Given $ ext{Sum} = \sqrt{2}$ and $ ext{Product} = rac{1}{3}$:

  • Here $S = \sqrt{2}$ and $P = rac{1}{3}$.
  • $$p(x) = k \left[x^2 - \sqrt{2}x + rac{1}{3} ight] = k \left[ rac{3x^2 - 3\sqrt{2}x + 1}{3} ight]$$
  • Choosing $k = 3$, the required quadratic polynomial is: $3x^2 - 3\sqrt{2}x + 1$.

(iii) Given $ ext{Sum} = 0$ and $ ext{Product} = \sqrt{5}$:

  • Here $S = 0$ and $P = \sqrt{5}$.
  • $$p(x) = k [x^2 - (0)x + \sqrt{5}] = k [x^2 + \sqrt{5}]$$
  • Choosing $k = 1$, the required quadratic polynomial is: $x^2 + \sqrt{5}$.

(iv) Given $ ext{Sum} = 1$ and $ ext{Product} = 1$:

  • $$p(x) = k [x^2 - (1)x + 1] = k [x^2 - x + 1]$$
  • Choosing $k = 1$, the required quadratic polynomial is: $x^2 - x + 1$.

Competency Algebraic Manipulation (HOTS)
Question: If $\alpha$ and $\beta$ are the zeroes of the polynomial $f(x) = 2x^2 + 5x + k$ such that $\alpha^2 + \beta^2 + \alpha \beta = \frac{21}{4}$, find the value of $k$.

Step-by-step Solution:

  1. From the quadratic polynomial $2x^2 + 5x + k$ ($a = 2, b = 5, c = k$):
    $$\alpha + \beta = -\frac{b}{a} = -\frac{5}{2}$$
    $$\alpha \beta = \frac{c}{a} = \frac{k}{2}$$
  2. We know the algebraic identity:
    $$\alpha^2 + \beta^2 = (\alpha + \beta)^2 - 2\alpha \beta$$
  3. Substituting into the given equation:
    $$\alpha^2 + \beta^2 + \alpha \beta = (\alpha + \beta)^2 - 2\alpha \beta + \alpha \beta = (\alpha + \beta)^2 - \alpha \beta$$
  4. Substitute the values:
    $$\left(-\frac{5}{2}\right)^2 - \frac{k}{2} = \frac{21}{4}$$
    $$\frac{25}{4} - \frac{k}{2} = \frac{21}{4}$$
  5. Solve for $k$:
    $$\frac{k}{2} = \frac{25}{4} - \frac{21}{4} = \frac{4}{4} = 1 \implies k = 2$$
  6. Final Answer: $k = 2$.
Assertion & Reason Assessment
Assertion (A): The graph of a quadratic polynomial $y = ax^2 + bx + c$ intersects the x-axis at at most two points.
Reason (R): A polynomial of degree $n$ has at most $n$ zeroes.

Evaluate whether Assertion (A) and Reason (R) are correct and if (R) explains (A).

CBSE Board Solution:

Both Assertion (A) and Reason (R) are true, and Reason (R) is the correct explanation of Assertion (A).

Geometrical Explanation: The zeroes of a polynomial $p(x)$ are precisely the x-coordinates of the points where the graph $y = p(x)$ intersects the x-axis. Since a quadratic polynomial has degree 2, by the Fundamental Theorem of Algebra, it has at most 2 real zeroes, meaning its parabolic graph can intersect the x-axis at at most two distinct points.
