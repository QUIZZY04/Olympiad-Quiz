NCERT Exercise 8.1: Trigonometric Ratios of Acute Angles
Question 1
In $\Delta ABC$, right-angled at $B$, $AB = 24\text{ cm}, BC = 7\text{ cm}$. Determine:
(i) $\sin A, \cos A$
(ii) $\sin C, \cos C$
[3 Marks]
✅ CBSE Board Standard Step-by-Step Solution

Step-by-step Detailed Solution:

  1. Given: A right-angled triangle $\Delta ABC$, right-angled at $B$.
    • Side adjacent to $\angle B$: $AB = 24\text{ cm}$
    • Side adjacent to $\angle B$: $BC = 7\text{ cm}$
  2. Finding Hypotenuse ($AC$) using Pythagoras Theorem:

    In $\Delta ABC$, $\angle B = 90^\circ$:

    $$AC^2 = AB^2 + BC^2$$ $$AC^2 = (24)^2 + (7)^2 = 576 + 49 = 625$$ $$AC = \sqrt{625} = 25\text{ cm}$$
    3. Figure: Right Triangle with Perpendicular, Base, and Hypotenuse
  3. (i) Determining $\sin A$ and $\cos A$:

    With reference to acute angle $A$:

    • Opposite side (Perpendicular) = $BC = 7\text{ cm}$
    • Adjacent side (Base) = $AB = 24\text{ cm}$
    • Hypotenuse = $AC = 25\text{ cm}$
    $$\sin A = \frac{\text{Opposite side}}{\text{Hypotenuse}} = \frac{BC}{AC} = \frac{7}{25}$$ $$\cos A = \frac{\text{Adjacent side}}{\text{Hypotenuse}} = \frac{AB}{AC} = \frac{24}{25}$$
  4. (ii) Determining $\sin C$ and $\cos C$:

    With reference to acute angle $C$:

    • Opposite side (Perpendicular) = $AB = 24\text{ cm}$
    • Adjacent side (Base) = $BC = 7\text{ cm}$
    • Hypotenuse = $AC = 25\text{ cm}$
    $$\sin C = \frac{\text{Opposite side}}{\text{Hypotenuse}} = \frac{AB}{AC} = \frac{24}{25}$$ $$\cos C = \frac{\text{Adjacent side}}{\text{Hypotenuse}} = \frac{BC}{AC} = \frac{7}{25}$$
  5. Final Answer:
    (i) $\sin A = \frac{7}{25}$, $\cos A = \frac{24}{25}$
    (ii) $\sin C = \frac{24}{25}$, $\cos C = \frac{7}{25}$

Question 2
In the given figure, find $\tan P - \cot R$ where in right $\Delta PQR$, $\angle Q = 90^\circ, PQ = 12\text{ cm}, PR = 13\text{ cm}$.
[2 Marks]
✅ CBSE Board Standard Step-by-Step Solution

Step-by-step Solution:

  1. Given: In $\Delta PQR$, $\angle Q = 90^\circ$, $PQ = 12\text{ cm}$, Hypotenuse $PR = 13\text{ cm}$.
  2. Find Base $QR$: By Pythagoras Theorem: $$PR^2 = PQ^2 + QR^2 \implies 13^2 = 12^2 + QR^2$$ $$169 = 144 + QR^2 \implies QR^2 = 169 - 144 = 25 \implies QR = 5\text{ cm}$$
  3. Calculating $\tan P$:

    For angle $P$, Opposite side = $QR = 5\text{ cm}$, Adjacent side = $PQ = 12\text{ cm}$.

    $$\tan P = \frac{\text{Opposite}}{\text{Adjacent}} = \frac{QR}{PQ} = \frac{5}{12}$$
  4. Calculating $\cot R$:

    For angle $R$, Adjacent side = $QR = 5\text{ cm}$, Opposite side = $PQ = 12\text{ cm}$.

    $$\cot R = \frac{\text{Adjacent}}{\text{Opposite}} = \frac{QR}{PQ} = \frac{5}{12}$$
  5. Evaluation: $$\tan P - \\cot R = \frac{5}{12} - \frac{5}{12} = 0$$
  6. Conclusion: The value of $\tan P - \cot R$ is 0.

Question 3
If $\sin A = \frac{3}{4}$, calculate $\cos A$ and $\tan A$.
[2 Marks]
✅ CBSE Board Standard Step-by-Step Solution

Step-by-step Solution:

  1. Given: $\sin A = \frac{3}{4}$.

    Since $\sin A = \frac{\text{Opposite side}}{\text{Hypotenuse}} = \frac{BC}{AC}$, let $BC = 3k$ and $AC = 4k$, where $k$ is a positive real constant.

  2. Finding $AB$ by Pythagoras theorem: $$AC^2 = AB^2 + BC^2 \implies (4k)^2 = AB^2 + (3k)^2$$ $$16k^2 = AB^2 + 9k^2 \implies AB^2 = 16k^2 - 9k^2 = 7k^2$$ $$AB = \sqrt{7k^2} = k\sqrt{7}$$
  3. Finding Trigonometric Ratios: $$\cos A = \frac{\text{Adjacent side}}{\text{Hypotenuse}} = \frac{AB}{AC} = \frac{k\sqrt{7}}{4k} = \frac{\sqrt{7}}{4}$$ $$\tan A = \frac{\text{Opposite side}}{\text{Adjacent side}} = \frac{BC}{AB} = \frac{3k}{k\sqrt{7}} = \frac{3}{\sqrt{7}}$$
  4. Answer: $\cos A = \frac{\sqrt{7}}{4}$ and $\tan A = \frac{3}{\sqrt{7}}$.

Question 4

  5. Answer: $\sin A = \frac{15}{17}$, $\sec A = \frac{17}{8}$.

Question 6
If $\angle A$ and $\angle B$ are acute angles such that $\cos A = \cos B$, then show that $\angle A = \angle B$.
[3 Marks]
✅ CBSE Board Standard Step-by-Step Solution

Rigorous Mathematical Proof:

  1. Construction / Consideration:

    Consider two right-angled triangles $\Delta APQ$ and $\Delta BCD$ (or a single triangle $\Delta ABC$ right-angled at $C$).

    Method 1 (Single Triangle): Let $\Delta ABC$ be right-angled at $C$.

  2. Trigonometric Definitions:

    In $\Delta ABC$ with $\angle C = 90^\circ$:

    $$\cos A = \frac{\text{Side adjacent to } \angle A}{\text{Hypotenuse}} = \frac{AC}{AB}$$ $$\cos B = \frac{\text{Side adjacent to } \angle B}{\text{Hypotenuse}} = \frac{BC}{AB}$$
  3. Equating Given Condition: $$\cos A = \cos B \implies \frac{AC}{AB} = \frac{BC}{AB}$$ $$\implies AC = BC$$
  4. Geometric Property:

    Since sides $AC$ and $BC$ are equal, $\Delta ABC$ is an isosceles right triangle.

    In any triangle, angles opposite to equal sides are equal:

    $$\angle B = \angle A \implies \angle A = \angle B$$
  5. Conclusion: Hence proved, $\angle A = \angle B$.

Question 7
If $\cot \theta = \frac{7}{8}$, evaluate:
(i) $\frac{(1 + \sin \theta)(1 - \sin \theta)}{(1 + \cos \theta)(1 - \cos \theta)}$
(ii) $\cot^2 \theta$
[3 Marks]
✅ CBSE Board Standard Step-by-Step Solution

Step-by-step Solution:

  1. Given: $\cot \theta = \frac{7}{8}$.
  2. (i) Evaluating $\frac{(1 + \sin \theta)(1 - \sin \theta)}{(1 + \cos \theta)(1 - \cos \theta)}$:

    Using algebraic identity $(a + b)(a - b) = a^2 - b^2$:

    $$\text{Numerator} = 1 - \sin^2 \theta$$ $$\text{Denominator} = 1 - \cos^2 \theta$$

    From fundamental trigonometric identities: $1 - \sin^2 \theta = \cos^2 \theta$ and $1 - \cos^2 \theta = \sin^2 \theta$.

    $$\frac{1 - \sin^2 \theta}{1 - \cos^2 \theta} = \frac{\cos^2 \theta}{\sin^2 \theta} = \left(\frac{\cos \theta}{\sin \theta}\right)^2 = \cot^2 \theta$$

    Substitute the given value $\cot \theta = \frac{7}{8}$:

    $$= \left(\frac{7}{8}\right)^2 = \frac{49}{64}$$
  3. (ii) Evaluating $\cot^2 \theta$: $$\cot^2 \theta = (\cot \theta)^2 = \left(\frac{7}{8}\right)^2 = \frac{49}{64}$$
  4. Conclusion: Both parts evaluate to $\frac{49}{64}$.

Question 8
If $3\cot A = 4$, check whether $\frac{1 - \tan^2 A}{1 + \tan^2 A} = \cos^2 A - \sin^2 A$ or not.
[3 Marks]
✅ CBSE Board Standard Step-by-Step Solution

Step-by-step Solution:

  1. Given: $3\cot A = 4 \implies \cot A = \frac{4}{3} \implies \tan A = \frac{1}{\cot A} = \frac{3}{4}$.
  2. Finding $\cos A$ and $\sin A$:

    Let Opposite = $3k$, Adjacent = $4k$.

    Hypotenuse = $\sqrt{(3k)^2 + (4k)^2} = \sqrt{9k^2 + 16k^2} = \sqrt{25k^2} = 5k$.

    $$\sin A = \frac{3}{5}, \quad \cos A = \frac{4}{5}$$
  3. Evaluating Left Hand Side (LHS): $$\text{LHS} = \frac{1 - \tan^2 A}{1 + \tan^2 A} = \frac{1 - \left(\frac{3}{4}\right)^2}{1 + \left(\frac{3}{4}\right)^2} = \frac{1 - \frac{9}{16}}{1 + \frac{9}{16}} = \frac{\frac{7}{16}}{\frac{25}{16}} = \frac{7}{25}$$
  4. Evaluating Right Hand Side (RHS): $$\text{RHS} = \cos^2 A - \sin^2 A = \left(\frac{4}{5}\right)^2 - \left(\frac{3}{5}\right)^2 = \frac{16}{25} - \frac{9}{25} = \frac{7}{25}$$
  5. Comparison: $$\text{LHS} = \text{RHS} = \frac{7}{25}$$
  6. Conclusion: Yes, $\frac{1 - \tan^2 A}{1 + \tan^2 A} = \cos^2 A - \sin^2 A$.

(i) $\sin A \cos C + \cos A \sin C$

[3 Marks]
✅ CBSE Board Standard Step-by-Step Solution

Step-by-step Solution:

  1. Given: $\tan A = \frac{1}{\sqrt{3}}$ in right triangle $ABC$ ($\angle B = 90^\circ$).

    Since $\tan A = \frac{BC}{AB}$, let $BC = 1k, AB = \sqrt{3}k$.

    $$AC = \sqrt{AB^2 + BC^2} = \sqrt{(\sqrt{3}k)^2 + (1k)^2} = \sqrt{3k^2 + 1k^2} = \sqrt{4k^2} = 2k$$
  2. Determining Ratios for $\angle A$ and $\angle C$: $$\sin A = \frac{BC}{AC} = \frac{1}{2}, \quad \cos A = \frac{AB}{AC} = \frac{\sqrt{3}}{2}$$ $$\sin C = \frac{AB}{AC} = \frac{\sqrt{3}}{2}, \quad \cos C = \frac{BC}{AC} = \frac{1}{2}$$

  5. Answer: (i) 1, (ii) 0.

Question 4 (i)-(iv) [Identities]
Prove the following identities, where the angles involved are acute angles for which the expressions are defined:
(i) $(\csc \theta - \cot \theta)^2 = \frac{1 - \cos \theta}{1 + \cos \theta}$
(ii) $\frac{\cos A}{1 + \sin A} + \frac{1 + \sin A}{\cos A} = 2\sec A$
(iii) $\frac{\tan \theta}{1 - \cot \theta} + \frac{\cot \theta}{1 - \tan \theta} = 1 + \sec \theta \csc \theta$
(iv) $\frac{1 + \sec A}{\sec A} = \frac{\sin^2 A}{1 - \cos A}$
[5 Marks]
✅ CBSE Board Standard Step-by-Step Solution

Step-by-step Rigorous Proofs:

  1. Proof of (i): $$\text{LHS} = (\csc \theta - \cot \theta)^2 = \left(\frac{1}{\sin \theta} - \frac{\cos \theta}{\sin \theta}\right)^2 = \frac{(1 - \cos \theta)^2}{\sin^2 \theta}$$

    Using $\sin^2 \theta = 1 - \cos^2 \theta = (1 - \cos \theta)(1 + \cos \theta)$:

    $$= \frac{(1 - \cos \theta)^2}{(1 - \cos \theta)(1 + \cos \theta)} = \frac{1 - \cos \theta}{1 + \cos \theta} = \text{RHS. Hence Proved.}$$
  2. Proof of (ii): $$\text{LHS} = \frac{\cos A}{1 + \sin A} + \frac{1 + \sin A}{\cos A} = \frac{\cos^2 A + (1 + \sin A)^2}{\cos A(1 + \sin A)}$$ $$= \frac{\cos^2 A + 1 + 2\sin A + \sin^2 A}{\cos A(1 + \sin A)}$$

    Since $\sin^2 A + \cos^2 A = 1$:

    $$= \frac{1 + 1 + 2\sin A}{\cos A(1 + \sin A)} = \frac{2 + 2\sin A}{\cos A(1 + \sin A)} = \frac{2(1 + \sin A)}{\cos A(1 + \sin A)} = \frac{2}{\cos A} = 2\sec A = \text{RHS.}$$
  3. Proof of (iii):

    Convert $\tan \theta, \cot \theta$ to $\sin \theta, \cos \theta$:

    $$\frac{\frac{\sin \theta}{\cos \theta}}{1 - \frac{\cos \theta}{\sin \theta}} + \frac{\frac{\cos \theta}{\sin \theta}}{1 - \frac{\sin \theta}{\cos \theta}} = \frac{\sin^2 \theta}{\cos \theta(\sin \theta - \cos \theta)} - \frac{\cos^2 \theta}{\sin \theta(\sin \theta - \cos \theta)}$$ $$= \frac{\sin^3 \theta - \cos^3 \theta}{\sin \theta \cos \theta(\sin \theta - \cos \theta)}$$

    Factoring $a^3 - b^3 = (a - b)(a^2 + ab + b^2)$:

    $$= \frac{(\sin \theta - \cos \theta)(\sin^2 \theta + \sin \theta \cos \theta + \cos^2 \theta)}{\sin \theta \cos \theta(\sin \theta - \cos \theta)} = \frac{1 + \sin \theta \cos \theta}{\sin \theta \cos \theta} = \frac{1}{\sin \theta \cos \theta} + 1 = 1 + \sec \theta \csc \theta = \text{RHS.}$$
  4. Proof of (iv): $$\text{LHS} = \frac{1 + \sec A}{\sec A} = \frac{1 + \frac{1}{\cos A}}{\frac{1}{\cos A}} = \frac{\frac{\cos A + 1}{\cos A}}{\frac{1}{\cos A}} = 1 + \cos A$$ $$\text{RHS} = \frac{\sin^2 A}{1 - \cos A} = \frac{1 - \cos^2 A}{1 - \cos A} = \frac{(1 - \cos A)(1 + \cos A)}{1 - \cos A} = 1 + \cos A$$ $$\implies \text{LHS} = \text{RHS}. \text{ Hence Proved.}$$

Question 4 (v)-(x) [Identities]
Prove the following identities:
(v) $\frac{\cos A - \sin A + 1}{\cos A + \sin A - 1} = \csc A + \cot A$ using $\csc^2 A = 1 + \cot^2 A$
(vi) $\sqrt{\frac{1 + \sin A}{1 - \sin A}} = \sec A + \tan A$
(vii) $\frac{\sin \theta - 2\sin^3 \theta}{2\cos^3 \theta - \cos \theta} = \tan \theta$
(viii) $(\sin A + \csc A)^2 + (\cos A + \sec A)^2 = 7 + \tan^2 A + \cot^2 A$
(ix) $(\csc A - \sin A)(\sec A - \cos A) = \frac{1}{\tan A + \cot A}$
(x) $\left(\frac{1 + \tan^2 A}{1 + \cot^2 A}\right) = \left(\frac{1 - \tan A}{1 - \cot A}\right)^2 = \tan^2 A$
[5 Marks]
✅ CBSE Board Standard Step-by-Step Solution

Step-by-step Complete Proofs:

  1. Proof of (v):

    Divide numerator and denominator by $\sin A$:

    $$\text{LHS} = \frac{\cot A - 1 + \csc A}{\cot A + 1 - \csc A} = \frac{(\cot A + \csc A) - 1}{\cot A - \csc A + 1}$$

    Substitute $1 = \csc^2 A - \cot^2 A = (\csc A - \cot A)(\csc A + \cot A)$ in numerator:

    $$= \frac{(\csc A + \cot A) - (\csc A - \cot A)(\csc A + \cot A)}{(\cot A - \csc A + 1)}$$ $$= \frac{(\csc A + \cot A)[1 - (\csc A - \cot A)]}{1 - \csc A + \cot A} = \csc A + \cot A = \text{RHS.}$$
  2. Proof of (vi): $$\text{LHS} = \sqrt{\frac{1 + \sin A}{1 - \sin A} \times \frac{1 + \sin A}{1 + \sin A}} = \sqrt{\frac{(1 + \sin A)^2}{1 - \sin^2 A}} = \sqrt{\frac{(1 + \sin A)^2}{\cos^2 A}} = \frac{1 + \sin A}{\cos A} = \sec A + \\tan A = \text{RHS.}$$
  3. Proof of (vii): $$\text{LHS} = \frac{\sin \theta(1 - 2\sin^2 \theta)}{\cos \theta(2\cos^2 \theta - 1)} = \tan \theta \cdot \frac{1 - 2(1 - \cos^2 \theta)}{2\cos^2 \theta - 1} = \tan \theta \cdot \frac{2\cos^2 \theta - 1}{2\cos^2 \theta - 1} = \tan \theta = \text{RHS.}$$
  4. Proof of (viii): $$\text{LHS} = (\sin^2 A + \csc^2 A + 2\sin A \csc A) + (\cos^2 A + \sec^2 A + 2\cos A \sec A)$$

    Since $\sin A \csc A = 1$ and $\cos A \sec A = 1$, and $\sin^2 A + \cos^2 A = 1$:

    $$= (1) + 2 + 2 + \csc^2 A + \sec^2 A = 5 + (1 + \cot^2 A) + (1 + \tan^2 A) = 7 + \tan^2 A + \cot^2 A = \text{RHS.}$$
  5. Proof of (ix): $$\text{LHS} = \left(\frac{1}{\sin A} - \sin A\right)\left(\frac{1}{\cos A} - \cos A\right) = \left(\frac{1 - \sin^2 A}{\sin A}\right)\left(\frac{1 - \cos^2 A}{\cos A}\right) = \frac{\cos^2 A \sin^2 A}{\sin A \cos A} = \sin A \cos A$$ $$\text{RHS} = \frac{1}{\frac{\sin A}{\cos A} + \frac{\cos A}{\sin A}} = \frac{1}{\frac{\sin^2 A + \cos^2 A}{\sin A \cos A}} = \frac{1}{\frac{1}{\sin A \cos A}} = \sin A \cos A \implies \text{LHS} = \text{RHS.}$$
  6. Proof of (x): $$\text{Term 1} = \frac{1 + \tan^2 A}{1 + \cot^2 A} = \frac{\sec^2 A}{\csc^2 A} = \frac{\frac{1}{\cos^2 A}}{\frac{1}{\sin^2 A}} = \frac{\sin^2 A}{\cos^2 A} = \tan^2 A$$ $$\text{Term 2} = \left(\frac{1 - \tan A}{1 - \frac{1}{\tan A}}\right)^2 = \left(\frac{1 - \tan A}{\frac{\tan A - 1}{\tan A}}\right)^2 = (-\tan A)^2 = \tan^2 A$$ $$\implies \text{Term 1} = \text{Term 2} = \tan^2 A. \text{ Hence Proved.}$$

Case-Study Competency Question
A solar engineer mounts a photovoltaic solar panel on a rooftop. In the morning, the solar rays strike the panel at an angle $\theta$ such that $\sin \theta = \frac{1}{2}$. Later at noon, the angle of inclination becomes $\phi = 2\theta$.
(i) Find the measure of angle $\theta$ and angle $\phi$.
(ii) Find the exact value of $\sin^2 \phi + \cos^2 \phi$.
(iii) Determine the ratio of the horizontal projection of rays at morning to noon: $\frac{\cos \theta}{\cos \phi}$.

Step-by-step Solution:

  1. (i) Since $\sin \theta = \frac{1}{2}$ for acute angle, $\theta = 30^\circ$.
    Angle at noon $\phi = 2\theta = 2(30^\circ) = 60^\circ$.
  2. (ii) By fundamental Pythagorean trigonometric identity, for any angle $\phi$:
    $$\sin^2 60^\circ + \cos^2 60^\circ = 1.$$
  3. (iii) Horizontal projection ratio:
    $$\frac{\cos \theta}{\cos \phi} = \frac{\cos 30^\circ}{\cos 60^\circ} = \frac{\frac{\sqrt{3}}{2}}{\frac{1}{2}} = \sqrt{3}:1.$$
Assertion & Reason HOTS Question
Assertion (A): For any acute angle $\theta$, $\sec^2 \theta - \tan^2 \theta = 1$.
Reason (R): The value of $\sin \theta$ increases as $\theta$ increases from $0^\circ$ to $90^\circ$.

CBSE Board Solution:

Both Assertion (A) and Reason (R) are true, but Reason (R) is NOT the correct explanation of Assertion (A).

Explanation: Assertion (A) is the standard Pythagorean identity $\sec^2 \theta - \tan^2 \theta = 1$, which is derived directly from $1 + \tan^2 \theta = \sec^2 \theta$ via Pythagoras theorem ($b^2 + p^2 = h^2 \implies 1 + (p/b)^2 = (h/b)^2$). Reason (R) is also mathematically true since $\sin 0^\circ = 0$ monotonically increases to $\sin 90^\circ = 1$, but it does not explain why $\sec^2 \theta - \tan^2 \theta = 1$.
