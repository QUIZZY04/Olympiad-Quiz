📌 Key Factorisation Techniques & Identities
  • Factorisation: Writing an algebraic expression as the product of its irreducible factors.
  • Method 1 — Common Factors: Extract the Highest Common Factor (HCF) of terms: ax + ay = a(x + y).
  • Method 2 — Regrouping Terms: Rearrange terms into groups having common factors: x^2 + xy + 8x + 8y = x(x + y) + 8(x + y) = (x + y)(x + 8).
  • Method 3 — Using Algebraic Identities:
    • a^2 + 2ab + b^2 = (a + b)^2
    • a^2 - 2ab + b^2 = (a - b)^2
    • a^2 - b^2 = (a - b)(a + b)
  • Method 4 — Splitting the Middle Term: For quadratic trinomial x^2 + (a + b)x + ab = (x + a)(x + b).
  • Division of Polynomials: Factorise the dividend polynomial completely and cancel out common linear/monomial factors with the divisor.
NCERT Exercise 12.1
Q1
Find the common factors of the given terms:
(i) 12x,\; 36    (ii) 2y,\; 22xy    (iii) 14pq,\; 28p^2q^2
(iv) 2x,\; 3x^2,\; 4    (v) 6abc,\; 24ab^2,\; 12a^2b    (vi) 16x^3,\; -4x^2,\; 32x
3 Marks
✅ CBSE Standard Answer
(i) 12x = 2 \times 2 \times 3 \times x; 36 = 2 \times 2 \times 3 \times 3.
Common factors = 2 \times 2 \times 3 = 12.
(ii) 2y = 2 \times y; 22xy = 2 \times 11 \times x \times y.
Common factors = 2 \times y = 2y.
(iii) 14pq = 2 \times 7 \times p \times q; 28p^2q^2 = 2 \times 2 \times 7 \times p^2 \times q^2.
Common factors = 2 \times 7 \times p \times q = 14pq.
(iv) 2x = 2 \times x; 3x^2 = 3 \times x^2; 4 = 2 \times 2.
Common factor = 1 (no variable or prime factor common to all three).
(v) 6abc = 2 \times 3 \times a \times b \times c; 24ab^2 = 2^3 \times 3 \times a \times b^2; 12a^2b = 2^2 \times 3 \times a^2 \times b.
Common factor = 2 \times 3 \times a \times b = 6ab.
(vi) 16x^3 = 2^4 \times x^3; -4x^2 = (-1) \times 2^2 \times x^2; 32x = 2^5 \times x.
Common factor = 2^2 \times x = 4x.

Q2
Factorise by regrouping:
(i) x^2 + xy + 8x + 8y
(ii) 15xy - 6x + 5y - 2
(iii) ax + bx - ay - by
(iv) 15pq + 15 + 9q + 25p
4 Marks
✅ CBSE Standard Answer
(i) Group first two and last two terms:
= x(x + y) + 8(x + y) = (x + y)(x + 8).
(ii) Group (15xy - 6x) + (5y - 2):
= 3x(5y - 2) + 1(5y - 2) = (5y - 2)(3x + 1).
(iii) Group (ax + bx) - (ay + by):
= x(a + b) - y(a + b) = (a + b)(x - y).
(iv) Rearrange terms: 15pq + 25p + 9q + 15:
= 5p(3q + 5) + 3(3q + 5) = (3q + 5)(5p + 3).

Q4
Factorise using difference of squares identity a^2 - b^2 = (a - b)(a + b):
(i) 4p^2 - 9q^2
(ii) 63a^2 - 112b^2
(iii) 49x^2 - 36
(iv) 16x^5 - 144x^3
(v) (x^2 - 2xy + y^2) - z^2
5 Marks
✅ CBSE Standard Answer
(i) (2p)^2 - (3q)^2 = (2p - 3q)(2p + 3q).
(ii) Take out common factor 7:
= 7(9a^2 - 16b^2) = 7[(3a)^2 - (4b)^2] = 7(3a - 4b)(3a + 4b).
(iii) (7x)^2 - 6^2 = (7x - 6)(7x + 6).
(iv) Take out common factor 16x^3:
= 16x^3(x^2 - 9) = 16x^3(x^2 - 3^2) = 16x^3(x - 3)(x + 3).
(v) Recognize (x^2 - 2xy + y^2) = (x - y)^2:
= (x - y)^2 - z^2 = (x - y - z)(x - y + z).

Q5
Factorise the expressions by splitting the middle term:
(i) p^2 + 6p + 8
(ii) q^2 - 10q + 21
(iii) p^2 + 6p - 16
3 Marks
✅ CBSE Standard Answer
(i) p^2 + 6p + 8:
Find two numbers whose product is 8 and sum is 6: numbers are 4 and 2.
= p^2 + 4p + 2p + 8 = p(p + 4) + 2(p + 4) = (p + 4)(p + 2).
(ii) q^2 - 10q + 21:
Find two numbers whose product is 21 and sum is -10: numbers are -7 and -3.
= q^2 - 7q - 3q + 21 = q(q - 7) - 3(q - 7) = (q - 7)(q - 3).
(iii) p^2 + 6p - 16:
Find two numbers whose product is -16 and sum is 6: numbers are 8 and -2.
= p^2 + 8p - 2p - 16 = p(p + 8) - 2(p + 8) = (p + 8)(p - 2).

NCERT Exercise 12.3
Q6
Divide as directed:
(i) 28x^4 \div 56x
(ii) (5x^2 - 6x) \div 3x
(iii) 10y(6y + 21) \div 5(2y + 7)
(iv) (y^2 + 7y + 10) \div (y + 5)
(v) (m^2 - 14m - 32) \div (m + 2)
5 Marks
✅ CBSE Standard Answer
(i) \frac{28x^4}{56x} = \frac{28}{56} \times \frac{x^4}{x} = \frac{1}{2}x^{4 - 1} = \frac{x^3}{2}.
(ii) \frac{5x^2 - 6x}{3x} = \frac{x(5x - 6)}{3x} = \frac{5x - 6}{3} (or \frac{5}{3}x - 2).
(iii) \frac{10y \times 3(2y + 7)}{5(2y + 7)} = \frac{30y(2y + 7)}{5(2y + 7)} = 6y.
(iv) Factorise numerator: y^2 + 7y + 10 = (y + 5)(y + 2).
\frac{(y + 5)(y + 2)}{(y + 5)} = y + 2.
(v) Factorise numerator: m^2 - 14m - 32 = (m - 16)(m + 2).
\frac{(m - 16)(m + 2)}{(m + 2)} = m - 16.

Case Study: Land Area Division
Scenario: A developer owns a rectangular commercial plot of total area (2x^2 + 7x + 3)\text{ m}^2. The length of the plot is known to be (2x + 1)\text{ m}. (i) Find the algebraic expression for the breadth of the plot. (ii) If x = 10\text{ m}, calculate the perimeter of the plot.

(i) Breadth of plot:
\text{Breadth} = \frac{\text{Area}}{\text{Length}} = \frac{2x^2 + 7x + 3}{2x + 1}.
Factorise numerator: 2x^2 + 6x + x + 3 = 2x(x + 3) + 1(x + 3) = (2x + 1)(x + 3).
\text{Breadth} = \frac{(2x + 1)(x + 3)}{2x + 1} = (x + 3)\text{ m}.

(ii) Perimeter for x = 10\text{ m}:
Length = 2(10) + 1 = 21\text{ m}.
Breadth = 10 + 3 = 13\text{ m}.
\text{Perimeter} = 2(\text{length} + \text{breadth}) = 2(21 + 13) = 2(34) = 68\text{ m}.

⚡ Repeated Factorisation Challenge (HOTS)
Factorise completely: x^8 - y^8 into its irreducible factors.

Apply identity a^2 - b^2 = (a - b)(a + b) repeatedly:
x^8 - y^8 = (x^4)^2 - (y^4)^2 = (x^4 - y^4)(x^4 + y^4).
Factorise (x^4 - y^4) = (x^2 - y^2)(x^2 + y^2) = (x - y)(x + y)(x^2 + y^2).

Final Answer: (x - y)(x + y)(x^2 + y^2)(x^4 + y^4).
