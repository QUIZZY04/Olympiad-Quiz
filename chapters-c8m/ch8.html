📌 Key Algebraic Definitions & Standard Identities
  • Classification by Number of Terms:
    • Monomial: Expression with 1 term (e.g. 7xy, -5p²).
    • Binomial: Expression with 2 terms (e.g. 2x + 3y).
    • Trinomial: Expression with 3 terms (e.g. a + b + c).
    • Polynomial: Expression with one or more terms with non-negative integer exponents.
  • Like Terms: Terms having the exact same algebraic factors (e.g. 7xy and -3xy). Only like terms can be added or subtracted.
  • The Four Standard Identities:
    • Identity I: (a + b)² = a² + 2ab + b²
    • Identity II: (a − b)² = a² − 2ab + b²
    • Identity III: (a + b)(a − b) = a² − b²
    • Identity IV: (x + a)(x + b) = x² + (a + b)x + ab
NCERT Exercise 8.1
Q1
Add the following:
(i) ab − bc, bc − ca, ca − ab
(ii) a − b + ab, b − c + bc, c − a + ac
(iii) 2p²q² − 3pq + 4, 5 + 7pq − 3p²q²
(iv) l² + m², m² + n², n² + l², 2lm + 2mn + 2nl
4 Marks
✅ CBSE Standard Answer
(i) (ab − bc) + (bc − ca) + (ca − ab)
= (ab − ab) + (−bc + bc) + (−ca + ca) = 0.
(ii) (a − b + ab) + (b − c + bc) + (c − a + ac)
= (a − a) + (−b + b) + (−c + c) + ab + bc + ac = ab + bc + ac.
(iii) (2p²q² − 3pq + 4) + (−3p²q² + 7pq + 5)
= (2 − 3)p²q² + (−3 + 7)pq + (4 + 5) = -p²q² + 4pq + 9.
(iv) (l² + m²) + (m² + n²) + (n² + l²) + (2lm + 2mn + 2nl)
= 2l² + 2m² + 2n² + 2lm + 2mn + 2nl = 2(l² + m² + n² + lm + mn + nl).

Q2
Subtract:
(a) 4a − 7ab + 3b + 12 from 12a − 9ab + 5b − 3
(b) 3xy + 5yz − 7zx from 5xy − 2yz − 2zx + 10xyz

(a) (12a − 9ab + 5b − 3) − (4a − 7ab + 3b + 12)

= 12a − 9ab + 5b − 3 − 4a + 7ab − 3b − 12
= (12 − 4)a + (−9 + 7)ab + (5 − 3)b + (−3 − 12)

= (5 − 3)xy + (−2 − 5)yz + (−2 + 7)zx + 10xyz
= 2xy − 7yz + 5zx + 10xyz.

(iv) a × 2b × 3c = (1 × 2 × 3)(abc) = 6abc.

NCERT Exercise 8.3
Q5
(a) Simplify 3x(4x − 5) + 3 and find its values for (i) x = 3, (ii) x = 1/2.
(b) Simplify a(a² + a + 1) + 5 and find its value for (i) a = 0, (ii) a = 1, (iii) a = -1.
4 Marks
✅ CBSE Standard Answer
(a) Simplification: 3x(4x − 5) + 3 = 12x² − 15x + 3.
(i) For x = 3: 12(3)² − 15(3) + 3 = 12(9) − 45 + 3 = 108 − 45 + 3 = 66.
(ii) For x = 1/2: 12(1/4) − 15(1/2) + 3 = 3 − 15/2 + 3 = 6 − 7.5 = -3/2 (or -1.5).
(b) Simplification: a(a² + a + 1) + 5 = a³ + a² + a + 5.
(i) For a = 0: 0 + 0 + 0 + 5 = 5.
(ii) For a = 1: 1³ + 1² + 1 + 5 = 1 + 1 + 1 + 5 = 8.
(iii) For a = -1: (−1)³ + (−1)² + (−1) + 5 = -1 + 1 − 1 + 5 = 4.

Q6
Multiply the binomials:
(i) (2x + 5) and (4x − 3)
(ii) (y − 8) and (3y − 4)
(iii) (2.5l − 0.5m) and (2.5l + 0.5m)
3 Marks
✅ CBSE Standard Answer
(i) (2x + 5)(4x − 3) = 2x(4x − 3) + 5(4x − 3)
= 8x² − 6x + 20x − 15 = 8x² + 14x − 15.
(ii) (y − 8)(3y − 4) = y(3y − 4) − 8(3y − 4)
= 3y² − 4y − 24y + 32 = 3y² − 28y + 32.
(iii) Using Identity (a − b)(a + b) = a² − b²:
= (2.5l)² − (0.5m)² = 6.25l² − 0.25m².

Q7
Use a suitable identity to get each of the following products:
(i) (2y + 5)(2y + 5)
(ii) (2a − 7)(2a − 7)
(iii) (1.1m − 0.4)(1.1m + 0.4)
(iv) (a² + b²)(−a² + b²)
4 Marks
✅ CBSE Standard Answer
(i) Identity I (a + b)² = a² + 2ab + b²:
(2y + 5)² = (2y)² + 2(2y)(5) + 5² = 4y² + 20y + 25.
(ii) Identity II (a − b)² = a² − 2ab + b²:
(2a − 7)² = (2a)² − 2(2a)(7) + 7² = 4a² − 28a + 49.
(iii) Identity III (a − b)(a + b) = a² − b²:
(1.1m)² − (0.4)² = 1.21m² − 0.16.
(iv) Rearrange as (b² + a²)(b² − a²):
= (b²)² − (a²)² = b⁴ − a⁴.

Case Study: Geometric Area & Binomial Expansion
Scenario: A square park has side length (3x + 4) metres. A uniform gravel path of width 2 metres is built around the outside of the park. (i) Write the polynomial expression for the area of the original park. (ii) Write the polynomial expression for the area of the gravel path.

(i) Area of original square park:
Area = (3x + 4)² = (3x)² + 2(3x)(4) + 4² = (9x² + 24x + 16) m².

(ii) Outer side length with 2 m path:
New side = (3x + 4) + 2(2) = (3x + 8) m.
Outer Area = (3x + 8)² = 9x² + 48x + 64.
Area of path = Outer Area − Inner Area:
= (9x² + 48x + 64) − (9x² + 24x + 16) = (24x + 48) m².

⚡ Mental Math Identity Challenge (HOTS)
Using standard algebraic identities, evaluate 103 × 104 and 95 × 96 without direct vertical multiplication.

103 × 104: Write as (100 + 3)(100 + 4).
Using (x + a)(x + b) = x² + (a + b)x + ab with x = 100, a = 3, b = 4:
= 100² + (3 + 4)(100) + (3)(4) = 10000 + 700 + 12 = 10,712.

95 × 96: Write as (100 − 5)(100 − 4):
= 100² + (−5 − 4)(100) + (−5)(−4) = 10000 − 900 + 20 = 9,120.
