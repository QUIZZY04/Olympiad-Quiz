📌 Key Concepts & Formulas Summary
  • Square Number: A natural number m is a perfect square if m = n² for some natural number n.
  • Unit Digit Rules:
    • Squares can only end in digits 0, 1, 4, 5, 6, 9. Numbers ending in 2, 3, 7, 8 are never perfect squares.
    • Squares of even numbers are always even; squares of odd numbers are always odd.
    • A square number can only end in an even number of trailing zeros.
  • Pythagorean Triplet: Three numbers a, b, c satisfying a² + b² = c². For any natural number m > 1, the triplet is (2m, m² − 1, m² + 1).
  • Non-Square Numbers between Consecutive Squares: Between n² and (n + 1)², there are exactly 2n non-square numbers.
  • Methods to Find Square Root (√n):
    • Repeated Subtraction: Successively subtract consecutive odd numbers 1, 3, 5, 7, ... from n until 0 is reached. Number of steps = √n.
    • Prime Factorisation: Group identical prime factors into pairs. Take one factor from each pair.
    • Long Division Method: Pair digits from the right (units place) for whole numbers and from the decimal point for decimals.

Q1
What will be the unit digit of the squares of the following numbers?
(i) 81    (ii) 272    (iii) 799    (iv) 3853    (v) 1234
(vi) 26387    (vii) 52698    (viii) 99880    (ix) 12796    (x) 55555
3 Marks
✅ CBSE Standard Answer

Rule: The unit digit of n² equals the unit digit of (unit digit of n)².

(i) 81: Unit digit is 1 ⇒ 1² = 1 ⇒ 1
(ii) 272: Unit digit is 2 ⇒ 2² = 4 ⇒ 4
(iii) 799: Unit digit is 9 ⇒ 9² = 81 ⇒ 1
(iv) 3853: Unit digit is 3 ⇒ 3² = 9 ⇒ 9
(v) 1234: Unit digit is 4 ⇒ 4² = 16 ⇒ 6
(vi) 26387: Unit digit is 7 ⇒ 7² = 49 ⇒ 9
(vii) 52698: Unit digit is 8 ⇒ 8² = 64 ⇒ 4
(viii) 99880: Unit digit is 0 ⇒ 0² = 0 ⇒ 0
(ix) 12796: Unit digit is 6 ⇒ 6² = 36 ⇒ 6
(x) 55555: Unit digit is 5 ⇒ 5² = 25 ⇒ 5

Q2

(ii) 23453: Ends in digit 3, so not a square.
(iii) 7928: Ends in digit 8, so not a square.
(iv) 222222: Ends in digit 2, so not a square.

(vi) 89722: Ends in digit 2, so not a square.
(vii) 222000: Ends in 3 zeros (odd count), so not a square.
(viii) 505050: Ends in 1 zero (odd count), so not a square.

Q5
Find the square of the following numbers without actual multiplication:
(i) 32    (ii) 35    (iii) 86    (iv) 93    (v) 71    (vi) 46
3 Marks
✅ CBSE Standard Answer

Identity: (a + b)² = a² + 2ab + b².

(i) 32² = (30 + 2)² = 30² + 2(30)(2) + 2² = 900 + 120 + 4 = 1024.
(ii) 35² = (30 + 5)² = 30(30 + 10) + 25 = 3 × 4 × 100 + 25 = 1200 + 25 = 1225.
(iii) 86² = (80 + 6)² = 80² + 2(80)(6) + 6² = 6400 + 960 + 36 = 7396.
(iv) 93² = (90 + 3)² = 90² + 2(90)(3) + 3² = 8100 + 540 + 9 = 8649.
(v) 71² = (70 + 1)² = 70² + 2(70)(1) + 1² = 4900 + 140 + 1 = 5041.
(vi) 46² = (40 + 6)² = 40² + 2(40)(6) + 6² = 1600 + 480 + 36 = 2116.

Q6
Write a Pythagorean triplet whose one member is:
(i) 6    (ii) 14    (iii) 16    (iv) 18
3 Marks
✅ CBSE Standard Answer

Formula: For any natural number m > 1, the triplet is (2m, m² − 1, m² + 1).

(i) 6: Let 2m = 6 ⇒ m = 3.
m² − 1 = 3² − 1 = 8;
m² + 1 = 3² + 1 = 10.
Triplet: (6, 8, 10).
(ii) 14: Let 2m = 14 ⇒ m = 7.
m² − 1 = 7² − 1 = 48;
m² + 1 = 7² + 1 = 50.
Triplet: (14, 48, 50).
(iii) 16: Let 2m = 16 ⇒ m = 8.
m² − 1 = 8² − 1 = 63;
m² + 1 = 8² + 1 = 65.
Triplet: (16, 63, 65).
(iv) 18: Let 2m = 18 ⇒ m = 9.
m² − 1 = 9² − 1 = 80;
m² + 1 = 9² + 1 = 82.
Triplet: (18, 80, 82).

Q9
For 252, find the smallest whole number by which it should be multiplied so as to get a perfect square number. Also find the square root of the square number so obtained.
3 Marks
✅ CBSE Standard Answer
Prime factorisation of 252:
252 = 2 × 2 × 3 × 3 × 7 = (2 × 2) × (3 × 3) × 7.
The prime factor 7 has no pair. To make it a perfect square, we must multiply 252 by 7:
Smallest multiplier = 7.
New number = 252 × 7 = 1764.
√1764 = 2 × 3 × 7 = 42.

Q11
Find the least number which must be subtracted from 1989 so as to get a perfect square. Also find the square root of the perfect square.
3 Marks
✅ CBSE Standard Answer
Apply division method on 1989:
Pairing: 19 89.
4² = 16. Remainder = 3. Bring down 89 → 389.
Divisor double = 8. Since 84 × 4 = 336 and 85 × 5 = 425, quotient = 44.
Remainder = 389 − 336 = 53.
This shows 44² < 1989 by 53.
Therefore, the least number that must be subtracted is 53.
Perfect square = 1989 − 53 = 1936.
√1936 = 44.

Case Study: Garden Layout
Scenario: A school gardener has 1000 saplings to plant. He wants to plant them in such a way that the number of rows equals the number of columns. What is the minimum number of additional saplings he needs?

Let the number of rows and columns be x. Total plants = x².

We find the next perfect square greater than 1000:
31² = 961 < 1000 < 32² = 1024.

To form a complete square of side 32, total plants needed = 1024.
Additional saplings required = 1024 − 1000 = 24 saplings.

⚡ Pythagorean Distance in Navigation
A ship sails 12 km due north and then 5 km due east. How far is the ship from its starting point? Explain how this relates to Pythagorean triplets.

North and East directions are mutually perpendicular (90°).

By Pythagoras theorem, distance d = √(12² + 5²) = √(144 + 25) = √169 = 13 km.

This directly forms the primitive Pythagorean triplet (5, 12, 13), confirming 5² + 12² = 13².
