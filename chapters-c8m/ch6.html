Chapter 6: We Distribute, Yet Things Multiply

NCERT Ganita Prakash (Part 1) — The Distributive Law, Geometric Area Models, Multiplying Binomials & Algebraic Identities

📌 Key Concepts & Mathematical Foundations
  • Distributive Property: a(b + c) = ab + ac. Geometrically, a rectangle of width a and length (b + c) splits into two smaller rectangles of areas ab and ac.
  • Binomial Multiplication: (a + b)(c + d) = a(c + d) + b(c + d) = ac + ad + bc + bd. Visualized as a 2×2 grid of rectangle partitions.
  • Standard Identities:
    • (a + b)² = a² + 2ab + b²
    • (a − b)² = a² − 2ab + b²
    • (a + b)(a − b) = a² − b²

Q1
Multiply using the distributive law:
(a) 4p(q + r)
(b) (2x + 5)(4x − 3)
(c) (a² + 5)(b³ + 3) + 5
3 Marks
✓ Suggested Step-by-Step Solution
(a): 4p(q + r) = 4pq + 4pr.
(b): 2x(4x − 3) + 5(4x − 3) = 8x² − 6x + 20x − 15 = 8x² + 14x − 15.
(c): a²(b³ + 3) + 5(b³ + 3) + 5 = a²b³ + 3a² + 5b³ + 15 + 5 = a²b³ + 3a² + 5b³ + 20.

Q2
Use identities to evaluate without long multiplication:
(a) 103 × 104
(b) 95 × 96
(c) 105 × 95
3 Marks
✓ Suggested Step-by-Step Solution
(a) 103 × 104: (100 + 3)(100 + 4) = 100² + (3 + 4)(100) + 3 × 4 = 10,000 + 700 + 12 = 10,712.
(b) 95 × 96: (100 − 5)(100 − 4) = 100² − (5 + 4)(100) + (−5)(−4) = 10,000 − 900 + 20 = 9,120.
(c) 105 × 95: (100 + 5)(100 − 5) = 100² − 5² = 10,000 − 25 = 9,975.

📝 Case Study & Conceptual Modeling
Modular Construction Area Expansion: A park of square dimension x meters is expanded by adding 3 meters to its length and 2 meters to its width.
(a) Write an algebraic expression for the new area.
(b) If x = 20 meters, find the additional area gained.
(a) New Area = (x + 3)(x + 2) = x² + 5x + 6 m².
(b) Old area = 20² = 400 m². New area = (23)(22) = 506 m². Additional area = 506 − 400 = 106 m² (or 5(20) + 6 = 106 m²).
🧠 HOTS Practice Questions (Assertion-Reasoning)
Assertion (A): (x + y)² − (x − y)² = 4xy.
Reason (R): Expanding both gives (x² + 2xy + y²) − (x² − 2xy + y²) = 2xy − (−2xy) = 4xy.
Choose: (a) Both A and R are true and R is correct explanation. (b) Both A and R are true but R is not explanation. (c) A is true, R is false. (d) A is false, R is true.
Correct Choice: (a) Both A and R are true and R is the correct explanation.
