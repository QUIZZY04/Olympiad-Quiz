NCERT Exercise 2.1: Cartesian Product of Sets, Ordered Pairs & Subsets of Cartesian Products
Question 1
Exercise 2.1
If $\left(\dfrac{x}{3} + 1, \, y - \dfrac{2}{3}\right) = \left(\dfrac{5}{3}, \, \dfrac{1}{3}\right)$, find the values of $x$ and $y$.
[2 Marks]
✅ CBSE Step-by-Step Solution

Equality of Ordered Pairs: Two ordered pairs $(a, b)$ and $(c, d)$ are equal if and only if their corresponding first elements are equal ($a = c$) and second elements are equal ($b = d$).

• Equating first coordinates:
$$\frac{x}{3} + 1 = \frac{5}{3}$$ $$\frac{x}{3} = \frac{5}{3} - 1 = \frac{5 - 3}{3} = \frac{2}{3}$$ Multiplying both sides by 3:
$$\mathbf{x = 2}$$
• Equating second coordinates:
$$y - \frac{2}{3} = \frac{1}{3}$$ $$y = \frac{1}{3} + \frac{2}{3} = \frac{3}{3} = 1$$ $$\mathbf{y = 1}$$
Final Answer: $\mathbf{x = 2}$ and $\mathbf{y = 1}$.

Question 2
Exercise 2.1
If the set $A$ has $3$ elements and the set $B = \{3, 4, 5\}$, then find the number of elements in $(A \times B)$.
[2 Marks]
✅ CBSE Step-by-Step Solution

Theorem on Number of Elements in Cartesian Product: If set $A$ contains $p$ elements and set $B$ contains $q$ elements, then the Cartesian product $A \times B$ contains $p \times q$ elements: $n(A \times B) = n(A) \times n(B)$.

• Given: $n(A) = 3$
• Given set $B = \{3, 4, 5\} \implies n(B) = 3$
• Therefore:
$$n(A \times B) = n(A) \times n(B) = 3 \times 3 = 9$$
Final Answer: The number of elements in $(A \times B)$ is $\mathbf{9}$.

Question 3
Exercise 2.1
If $G = \{7, 8\}$ and $H = \{5, 4, 2\}$, find $G \times H$ and $H \times G$.
[2 Marks]
✅ CBSE Step-by-Step Solution

Cartesian Product Definition: $G \times H = \{(g, h) : g \in G, h \in H\}$ and $H \times G = \{(h, g) : h \in H, g \in G\}$.

• Finding $G \times H$:
Each element of $G = \{7, 8\}$ is paired with each element of $H = \{5, 4, 2\}$:
$$\mathbf{G \times H = \{(7, 5), (7, 4), (7, 2), (8, 5), (8, 4), (8, 2)\}}$$
$n(G \times H) = 2 \times 3 = 6$ ordered pairs.

• Finding $H \times G$:
Each element of $H = \{5, 4, 2\}$ is paired with each element of $G = \{7, 8\}$:
$$\mathbf{H \times G = \{(5, 7), (5, 8), (4, 7), (4, 8), (2, 7), (2, 8)\}}$$
$n(H \times G) = 3 \times 2 = 6$ ordered pairs.

Remark: Notice that $G \times H \ne H \times G$ since ordered pairs are not commutative, e.g. $(7, 5) \ne (5, 7)$.

Question 4
Exercise 2.1
State whether each of the following statements are true or false. If the statement is false, rewrite the given statement correctly:
(i) If $P = \{m, n\}$ and $Q = \{n, m\}$, then $P \times Q = \{(m, n), (n, m)\}$.
(ii) If $A$ and $B$ are non-empty sets, then $A \times B$ is a non-empty set of ordered pairs $(x, y)$ such that $x \in A$ and $y \in B$.
(iii) If $A = \{1, 2\}, B = \{3, 4\}$, then $A \times (B \cap \phi) = \phi$.
[3 Marks]
✅ CBSE Step-by-Step Solution
• (i) Statement: If $P = \{m, n\}$ and $Q = \{n, m\}$, then $P \times Q = \{(m, n), (n, m)\}$.
Status: FALSE.
Reason: $n(P) = 2$ and $n(Q) = 2$, so $n(P \times Q)$ must have $2 \times 2 = 4$ elements.
Correct Statement:
$$\mathbf{P \times Q = \{(m, n), (m, m), (n, n), (n, m)\}}$$

• (ii) Statement: If $A$ and $B$ are non-empty sets, then $A \times B$ is a non-empty set of ordered pairs $(x, y)$ such that $x \in A$ and $y \in B$.
Status: TRUE.
Reason: This is the exact formal mathematical definition of the Cartesian product of two non-empty sets.

• (iii) Statement: If $A = \{1, 2\}, B = \{3, 4\}$, then $A \times (B \cap \phi) = \phi$.
Status: TRUE.
Reason: The intersection of any set with the empty set is the empty set: $B \cap \phi = \phi$. By definition, the Cartesian product of any set with $\phi$ contains no pairs: $A \times \phi = \phi$.

Question 7
Exercise 2.1
Let $A = \{1, 2\}, B = \{1, 2, 3, 4\}, C = \{5, 6\}$ and $D = \{5, 6, 7, 8\}$. Verify that:
(i) $A \times (B \cap C) = (A \times B) \cap (A \times C)$
(ii) $A \times C$ is a subset of $B \times D$.
[4 Marks]
✅ CBSE Step-by-Step Solution
• Part (i): Verify $A \times (B \cap C) = (A \times B) \cap (A \times C)$
1. First, find $B \cap C$:
$B \cap C = \{1, 2, 3, 4\} \cap \{5, 6\} = \phi$
Therefore, $\text{LHS} = A \times (B \cap C) = \{1, 2\} \times \phi = \mathbf{\phi}$.

2. Now compute $A \times B$ and $A \times C$:
$A \times B = \{(1, 1), (1, 2), (1, 3), (1, 4), (2, 1), (2, 2), (2, 3), (2, 4)\}$
$A \times C = \{(1, 5), (1, 6), (2, 5), (2, 6)\}$
There are no common ordered pairs between $A \times B$ and $A \times C$:
$\text{RHS} = (A \times B) \cap (A \times C) = \mathbf{\phi}$.

Since $\text{LHS} = \text{RHS} = \phi$, the identity is verified.

• Part (ii): Verify that $A \times C$ is a subset of $B \times D$
1. $A \times C = \{(1, 5), (1, 6), (2, 5), (2, 6)\}$
2. $B \times D = \{1, 2, 3, 4\} \times \{5, 6, 7, 8\}$
$B \times D$ contains $4 \times 4 = 16$ elements:
$\{(1, 5), (1, 6), (1, 7), (1, 8), (2, 5), (2, 6), (2, 7), (2, 8), (3, 5), (3, 6), (3, 7), (3, 8), (4, 5), (4, 6), (4, 7), (4, 8)\}$

All four elements of $A \times C$, namely $(1, 5), (1, 6), (2, 5), (2, 6)$, belong to $B \times D$.
Since $A \subset B$ and $C \subset D$, it follows directly that:
$$\mathbf{A \times C \subset B \times D}$$ Hence verified.

NCERT Exercise 2.2: Relations, Arrow Diagrams, Domain, Range & Codomain
Question 1
Exercise 2.2
Let $A = \{1, 2, 3, ..., 14\}$. Define a relation $R$ from $A$ to $A$ by $R = \{(x, y) : 3x - y = 0, \text{ where } x, y \in A\}$. Write down its domain, codomain and range.
[3 Marks]
✅ CBSE Step-by-Step Solution

Condition: $3x - y = 0 \implies y = 3x$, with the constraint that both $x \in A$ and $y \in A$.

• For $x = 1: \quad y = 3(1) = 3 \in A \implies (1, 3) \in R$
• For $x = 2: \quad y = 3(2) = 6 \in A \implies (2, 6) \in R$
• For $x = 3: \quad y = 3(3) = 9 \in A \implies (3, 9) \in R$
• For $x = 4: \quad y = 3(4) = 12 \in A \implies (4, 12) \in R$
• For $x = 5: \quad y = 3(5) = 15 \notin A$ (since $15 > 14$, not in $A$).
For all $x \ge 5$, $y > 14$, so no other pairs belong to $R$.

• Roster Form of R:
$$\mathbf{R = \{(1, 3), (2, 6), (3, 9), (4, 12)\}}$$
• Domain of R (set of first elements):
$$\mathbf{\text{Domain}(R) = \{1, 2, 3, 4\}}$$
• Range of R (set of second elements):
$$\mathbf{\text{Range}(R) = \{3, 6, 9, 12\}}$$
• Codomain of R (the entire target set):
$$\mathbf{\text{Codomain}(R) = A = \{1, 2, 3, 4, ..., 14\}}$$

$A = \{1, 2, 3, 5\}$ and $B = \{4, 6, 9\}$. Define a relation $R$ from $A$ to $B$ by $R = \{(x, y) : \text{the difference between } x \text{ and } y \text{ is odd}; \, x \in A, y \in B\}$. Write $R$ in roster form.
[3 Marks]
✅ CBSE Step-by-Step Solution

Rule: The difference $|x - y|$ is odd if and only if one number is even and the other number is odd (even $-$ odd = odd, odd $-$ even = odd).

• Elements of $A = \{1, 2, 3, 5\}$: Odd numbers are $1, 3, 5$; Even number is $2$.
• Elements of $B = \{4, 6, 9\}$: Even numbers are $4, 6$; Odd number is $9$.

Now pair an odd from $A$ with an even from $B$, and an even from $A$ with an odd from $B$:
1. For $x = 1$ (odd): $y \in \{4, 6\} \implies |1 - 4| = 3$ (odd), $|1 - 6| = 5$ (odd). Pairs: $(1, 4), (1, 6)$.
2. For $x = 2$ (even): $y = 9 \implies |2 - 9| = 7$ (odd). Pair: $(2, 9)$.
3. For $x = 3$ (odd): $y \in \{4, 6\} \implies |3 - 4| = 1$ (odd), $|3 - 6| = 3$ (odd). Pairs: $(3, 4), (3, 6)$.
4. For $x = 5$ (odd): $y \in \{4, 6\} \implies |5 - 4| = 1$ (odd), $|5 - 6| = 1$ (odd). Pairs: $(5, 4), (5, 6)$.

• Roster Form:
$$\mathbf{R = \{(1, 4), (1, 6), (2, 9), (3, 4), (3, 6), (5, 4), (5, 6)\}}$$

Condition for a Function: A relation is a function if every element in its domain has a unique image. At any overlap point of piecewise definitions, both rules must evaluate to the identical output.

• Analysis of Relation $f$:
The definition changes at the boundary $x = 3$.
- Using first rule ($x^2$ for $0 \le x \le 3$): at $x = 3$, $f(3) = 3^2 = 9$.

Sum: $a + b = 0 + 1 = 1$
$$\implies (0, 1) \in f$$
Case 2: Choose $a = 0, b = 2 \in \mathbb{Z}$:
Product: $ab = 0 \times 2 = 0$
Sum: $a + b = 0 + 2 = 2$
$$\implies (0, 2) \in f$$

Alternative Non-Zero Counterexample:
- Take $a = 2, b = 6 \implies ab = 12, a + b = 8 \implies (12, 8) \in f$
- Take $a = 3, b = 4 \implies ab = 12, a + b = 7 \implies (12, 7) \in f$

• Conclusion:
The single domain element $0$ (or $12$) has two distinct images ($1$ and $2$, or $8$ and $7$).
Because an input does not have a unique image, $f$ is NOT a function from $\mathbb{Z}$ to $\mathbb{Z}$.

Question 12
Miscellaneous Exercise
Let $A = \{9, 10, 11, 12, 13\}$ and let $f : A \to \mathbb{N}$ be defined by $f(n) = \text{the highest prime factor of } n$. Find the range of $f$.
[3 Marks]
✅ CBSE Step-by-Step Solution
Find the prime factorisation of each element $n \in A$ and determine its highest prime factor:

• For $n = 9$:
Prime factorisation: $9 = 3^2$
Prime factors: $\{3\}$
Highest prime factor: $\mathbf{f(9) = 3}$

• For $n = 10$:
Prime factorisation: $10 = 2 \times 5$
Prime factors: $\{2, 5\}$
Highest prime factor: $\mathbf{f(10) = 5}$

• For $n = 11$:
$11$ is a prime number.
Highest prime factor: $\mathbf{f(11) = 11}$

• For $n = 12$:
Prime factorisation: $12 = 2^2 \times 3$
Prime factors: $\{2, 3\}$
Highest prime factor: $\mathbf{f(12) = 3}$

• For $n = 13$:
$13$ is a prime number.
Highest prime factor: $\mathbf{f(13) = 13}$

• Range of $f$:
The range is the set of all distinct outputs $\{f(n) : n \in A\}$:
$$\mathbf{\text{Range}(f) = \{3, 5, 11, 13\}}$$
