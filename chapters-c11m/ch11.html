NCERT Exercise 11.1: Coordinate Axes, Coordinate Planes & Eight Octants
Question 1
Exercise 11.1
A point is on the x-axis. What are its y-coordinate and z-coordinates?
[1 Mark]
✅ CBSE Step-by-Step Solution
• In a 3-dimensional Cartesian coordinate system, any point lying on the x-axis has coordinates of the form $(x, 0, 0)$.
• This is because the distance of the point from the XZ-plane is its y-coordinate ($y = 0$), and its distance from the XY-plane is its z-coordinate ($z = 0$).
• Therefore:
y-coordinate = $\mathbf{0}$
z-coordinate = $\mathbf{0}$

Question 2
Exercise 11.1
A point is in the XZ-plane. What can you say about its y-coordinate?
[1 Mark]
✅ CBSE Step-by-Step Solution
• The XZ-plane is determined by the x-axis and the z-axis.
• Every point in the XZ-plane has zero perpendicular distance from the XZ-plane itself.
• Thus, the general coordinates of any point in the XZ-plane are of the form $(x, 0, z)$.
• Hence, its y-coordinate is zero: $\mathbf{y = 0}$.

Question 3
Exercise 11.1
Name the octants in which the following points lie:
(i) $(1, 2, 3)$
(ii) $(4, -2, 3)$
(iii) $(4, -2, -5)$
(iv) $(4, 2, -5)$
(v) $(-4, 2, -5)$
(vi) $(-4, 2, 5)$
(vii) $(-3, -1, 6)$
(viii) $(2, -4, -7)$
[2 Marks]
✅ CBSE Step-by-Step Solution
• The signs of coordinates in the eight octants are defined as:
- Octant I: $(+, +, +)$
- Octant II: $(-, +, +)$
- Octant III: $(-, -, +)$
- Octant IV: $(+, -, +)$
- Octant V: $(+, +, -)$
- Octant VI: $(-, +, -)$
- Octant VII: $(-, -, -)$
- Octant VIII: $(+, -, -)$
• Mapping each point according to the sign of its $(x, y, z)$ coordinates:
1. $(1, 2, 3) \rightarrow (+, +, +) \implies$ Octant I
2. $(4, -2, 3) \rightarrow (+, -, +) \implies$ Octant IV
3. $(4, -2, -5) \rightarrow (+, -, -) \implies$ Octant VIII
4. $(4, 2, -5) \rightarrow (+, +, -) \implies$ Octant V
5. $(-4, 2, -5) \rightarrow (-, +, -) \implies$ Octant VI
6. $(-4, 2, 5) \rightarrow (-, +, +) \implies$ Octant II
7. $(-3, -1, 6) \rightarrow (-, -, +) \implies$ Octant III
8. $(2, -4, -7) \rightarrow (+, -, -) \implies$ Octant VIII

NCERT Exercise 11.2: Distance Between Points, Collinearity & Equidistant Loci
Question 1
Exercise 11.2
Find the distance between the following pairs of points:
(i) $(2, 3, 5)$ and $(4, 3, 1)$
(ii) $(-3, 7, 2)$ and $(2, 4, -1)$
(iii) $(-1, 3, -4)$ and $(1, -3, 4)$
(iv) $(2, -1, 3)$ and $(-2, 1, 3)$
[4 Marks]
✅ CBSE Step-by-Step Solution
• The distance formula in 3D between $P(x_1, y_1, z_1)$ and $Q(x_2, y_2, z_2)$ is:
$$PQ = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}$$
• (i) $(2, 3, 5)$ and $(4, 3, 1)$:
$$d = \sqrt{(4 - 2)^2 + (3 - 3)^2 + (1 - 5)^2} = \sqrt{2^2 + 0^2 + (-4)^2} = \sqrt{4 + 0 + 16} = \sqrt{20} = \mathbf{2\sqrt{5}\text{ units}}$$ • (ii) $(-3, 7, 2)$ and $(2, 4, -1)$:
$$d = \sqrt{(2 - (-3))^2 + (4 - 7)^2 + (-1 - 2)^2} = \sqrt{5^2 + (-3)^2 + (-3)^2} = \sqrt{25 + 9 + 9} = \mathbf{\sqrt{43}\text{ units}}$$ • (iii) $(-1, 3, -4)$ and $(1, -3, 4)$:
$$d = \sqrt{(1 - (-1))^2 + (-3 - 3)^2 + (4 - (-4))^2} = \sqrt{2^2 + (-6)^2 + 8^2} = \sqrt{4 + 36 + 64} = \sqrt{104} = \mathbf{2\sqrt{26}\text{ units}}$$ • (iv) $(2, -1, 3)$ and $(-2, 1, 3)$:
$$d = \sqrt{(-2 - 2)^2 + (1 - (-1))^2 + (3 - 3)^2} = \sqrt{(-4)^2 + 2^2 + 0^2} = \sqrt{16 + 4 + 0} = \sqrt{20} = \mathbf{2\sqrt{5}\text{ units}}$$

Question 2
Exercise 11.2
Show that the points $P(-2, 3, 5), Q(1, 2, 3)$ and $R(7, 0, -1)$ are collinear.
[3 Marks]
✅ CBSE Step-by-Step Solution
• Points $P, Q, R$ are collinear if the sum of the distances between two pairs equals the distance between the third pair.
• Calculate distances between each pair using the 3D distance formula:
• Distance $PQ$:
$$PQ = \sqrt{(1 - (-2))^2 + (2 - 3)^2 + (3 - 5)^2} = \sqrt{3^2 + (-1)^2 + (-2)^2} = \sqrt{9 + 1 + 4} = \sqrt{14}$$
• Distance $QR$:
$$QR = \sqrt{(7 - 1)^2 + (0 - 2)^2 + (-1 - 3)^2} = \sqrt{6^2 + (-2)^2 + (-4)^2} = \sqrt{36 + 4 + 16} = \sqrt{56} = 2\sqrt{14}$$
• Distance $PR$:
$$PR = \sqrt{(7 - (-2))^2 + (0 - 3)^2 + (-1 - 5)^2} = \sqrt{9^2 + (-3)^2 + (-6)^2} = \sqrt{81 + 9 + 36} = \sqrt{126} = 3\sqrt{14}$$
• Notice that:
$$PQ + QR = \sqrt{14} + 2\sqrt{14} = 3\sqrt{14} = PR$$
• Since $PQ + QR = PR$, the point $Q$ lies on the line segment joining $P$ and $R$.
• Hence, the points $P, Q,$ and $R$ are collinear. (Hence Proved).

Question 3
Exercise 11.2
Verify the following:
(i) $(0, 7, -10), (1, 6, -6)$ and $(4, 9, -6)$ are the vertices of an isosceles triangle.
(ii) $(0, 7, 10), (-1, 6, 6)$ and $(-4, 9, 6)$ are the vertices of a right angled triangle.
(iii) $(-1, 2, 1), (1, -2, 5), (4, -7, 8)$ and $(2, -3, 4)$ are the vertices of a parallelogram.
[6 Marks]
✅ CBSE Step-by-Step Solution
• (i) Let $A(0, 7, -10), B(1, 6, -6), C(4, 9, -6)$:
$$AB = \sqrt{(1 - 0)^2 + (6 - 7)^2 + (-6 - (-10))^2} = \sqrt{1 + 1 + 16} = \sqrt{18} = 3\sqrt{2}$$
$$BC = \sqrt{(4 - 1)^2 + (9 - 6)^2 + (-6 - (-6))^2} = \sqrt{9 + 9 + 0} = \sqrt{18} = 3\sqrt{2}$$
$$CA = \sqrt{(0 - 4)^2 + (7 - 9)^2 + (-10 - (-6))^2} = \sqrt{16 + 4 + 16} = \sqrt{36} = 6$$
Since $AB = BC = 3\sqrt{2} \neq CA$, two sides are equal. Therefore, $\triangle ABC$ is an isosceles triangle.

• (ii) Let $P(0, 7, 10), Q(-1, 6, 6), R(-4, 9, 6)$:
$$PQ^2 = (-1 - 0)^2 + (6 - 7)^2 + (6 - 10)^2 = 1 + 1 + 16 = 18$$
$$QR^2 = (-4 - (-1))^2 + (9 - 6)^2 + (6 - 6)^2 = 9 + 9 + 0 = 18$$
$$PR^2 = (-4 - 0)^2 + (9 - 7)^2 + (6 - 10)^2 = 16 + 4 + 16 = 36$$
Here $PQ^2 + QR^2 = 18 + 18 = 36 = PR^2$. By the converse of Pythagoras theorem, $\triangle PQR$ is a right-angled triangle right-angled at $Q$.

• (iii) Let $A(-1, 2, 1), B(1, -2, 5), C(4, -7, 8), D(2, -3, 4)$:
A quadrilateral is a parallelogram if its diagonals bisect each other (i.e. share the same midpoint).
- Midpoint of diagonal $AC$:
$$\left(\frac{-1 + 4}{2}, \frac{2 + (-7)}{2}, \frac{1 + 8}{2}\right) = \left(\frac{3}{2}, -\frac{5}{2}, \frac{9}{2}\right)$$
- Midpoint of diagonal $BD$:
$$\left(\frac{1 + 2}{2}, \frac{-2 + (-3)}{2}, \frac{5 + 4}{2}\right) = \left(\frac{3}{2}, -\frac{5}{2}, \frac{9}{2}\right)$$
Since midpoints of both diagonals $AC$ and $BD$ coincide, $ABCD$ is a parallelogram.

Question 4
Exercise 11.2
Find the equation of the set of points which are equidistant from the points $(1, 2, 3)$ and $(3, 2, -1)$.
[3 Marks]
✅ CBSE Step-by-Step Solution
• Let $P(x, y, z)$ be any point equidistant from $A(1, 2, 3)$ and $B(3, 2, -1)$.
• Given condition: $PA = PB \implies PA^2 = PB^2$.
• Writing expressions for $PA^2$ and $PB^2$:
$$PA^2 = (x - 1)^2 + (y - 2)^2 + (z - 3)^2$$
$$= (x^2 - 2x + 1) + (y^2 - 4y + 4) + (z^2 - 6z + 9) = x^2 + y^2 + z^2 - 2x - 4y - 6z + 14$$
$$PB^2 = (x - 3)^2 + (y - 2)^2 + (z - (-1))^2$$
$$= (x^2 - 6x + 9) + (y^2 - 4y + 4) + (z^2 + 2z + 1) = x^2 + y^2 + z^2 - 6x - 4y + 2z + 14$$
• Equating $PA^2 = PB^2$ and canceling $x^2 + y^2 + z^2$ and constant $14$:
$$-2x - 4y - 6z + 14 = -6x - 4y + 2z + 14$$
$$-2x + 6x - 4y + 4y - 6z - 2z = 0$$
$$4x - 8z = 0$$
$$4(x - 2z) = 0 \implies \mathbf{x - 2z = 0}$$
• Hence, the required equation of the set of points is $\mathbf{x - 2z = 0}$.

Question 5
Exercise 11.2
Find the equation of the set of points $P$, the sum of whose distances from $A(4, 0, 0)$ and $B(-4, 0, 0)$ is equal to $10$.
[4 Marks]
✅ CBSE Step-by-Step Solution
• Let the coordinates of point $P$ be $(x, y, z)$.
• Given condition: $PA + PB = 10$.
• Using distance formula:
$$PA = \sqrt{(x - 4)^2 + y^2 + z^2}$$
$$PB = \sqrt{(x + 4)^2 + y^2 + z^2}$$
• Thus:
$$\sqrt{(x - 4)^2 + y^2 + z^2} + \sqrt{(x + 4)^2 + y^2 + z^2} = 10$$
$$\sqrt{(x - 4)^2 + y^2 + z^2} = 10 - \sqrt{(x + 4)^2 + y^2 + z^2}$$
• Squaring both sides:
$$(x - 4)^2 + y^2 + z^2 = 100 - 20\sqrt{(x + 4)^2 + y^2 + z^2} + (x + 4)^2 + y^2 + z^2$$
$$x^2 - 8x + 16 + y^2 + z^2 = 100 - 20\sqrt{(x + 4)^2 + y^2 + z^2} + x^2 + 8x + 16 + y^2 + z^2$$
$$-8x = 100 - 20\sqrt{(x + 4)^2 + y^2 + z^2} + 8x$$
$$20\sqrt{(x + 4)^2 + y^2 + z^2} = 100 + 16x$$
$$5\sqrt{(x + 4)^2 + y^2 + z^2} = 25 + 4x$$
• Squaring both sides again:
$$25\left[(x + 4)^2 + y^2 + z^2\right] = (25 + 4x)^2$$
$$25\left[x^2 + 8x + 16 + y^2 + z^2\right] = 625 + 200x + 16x^2$$
$$25x^2 + 200x + 400 + 25y^2 + 25z^2 = 625 + 200x + 16x^2$$
$$(25 - 16)x^2 + 25y^2 + 25z^2 = 625 - 400$$
$$\mathbf{9x^2 + 25y^2 + 25z^2 - 225 = 0} \quad \left(\text{or } \frac{x^2}{25} + \frac{y^2}{9} + \frac{z^2}{9} = 1\right)$$

Question 1
Misc Exercise
Three vertices of a parallelogram $ABCD$ are $A(3, -1, 2), B(1, 2, -4)$ and $C(-1, 1, 2)$. Find the coordinates of the fourth vertex $D$.
[3 Marks]
✅ CBSE Step-by-Step Solution
• Let the coordinates of the fourth vertex $D$ be $(x, y, z)$.
• We know that the diagonals of a parallelogram bisect each other.
• Therefore, Midpoint of diagonal $AC$ = Midpoint of diagonal $BD$.
• Midpoint of $AC$:
$$\left(\frac{3 + (-1)}{2}, \frac{-1 + 1}{2}, \frac{2 + 2}{2}\right) = \left(\frac{2}{2}, 0, \frac{4}{2}\right) = (1, 0, 2)$$
• Midpoint of $BD$:
$$\left(\frac{1 + x}{2}, \frac{2 + y}{2}, \frac{-4 + z}{2}\right)$$
• Equating the corresponding coordinates:
$$\frac{1 + x}{2} = 1 \implies 1 + x = 2 \implies \mathbf{x = 1}$$
$$\frac{2 + y}{2} = 0 \implies 2 + y = 0 \implies \mathbf{y = -2}$$
$$\frac{-4 + z}{2} = 2 \implies -4 + z = 4 \implies \mathbf{z = 8}$$
• Hence, the coordinates of the fourth vertex $D$ are $\mathbf{(1, -2, 8)}$.

Find the lengths of the medians of the triangle with vertices $A(0, 0, 6), B(0, 4, 0)$ and $C(6, 0, 0)$.
[4 Marks]
✅ CBSE Step-by-Step Solution
• A median joins a vertex to the midpoint of the opposite side.
• Let $D, E, F$ be the midpoints of sides $BC, CA,$ and $AB$ respectively:
• Midpoint $D$ of $BC$:
$$D = \left(\frac{0 + 6}{2}, \frac{4 + 0}{2}, \frac{0 + 0}{2}\right) = (3, 2, 0)$$
- Length of median $AD$ from $A(0, 0, 6)$ to $D(3, 2, 0)$:
$$AD = \sqrt{(3 - 0)^2 + (2 - 0)^2 + (0 - 6)^2} = \sqrt{9 + 4 + 36} = \sqrt{49} = \mathbf{7}$$
• Midpoint $E$ of $CA$:
$$E = \left(\frac{6 + 0}{2}, \frac{0 + 0}{2}, \frac{0 + 6}{2}\right) = (3, 0, 3)$$
- Length of median $BE$ from $B(0, 4, 0)$ to $E(3, 0, 3)$:
$$BE = \sqrt{(3 - 0)^2 + (0 - 4)^2 + (3 - 0)^2} = \sqrt{9 + 16 + 9} = \mathbf{\sqrt{34}}$$
• Midpoint $F$ of $AB$:
$$F = \left(\frac{0 + 0}{2}, \frac{0 + 4}{2}, \frac{6 + 0}{2}\right) = (0, 2, 3)$$
- Length of median $CF$ from $C(6, 0, 0)$ to $F(0, 2, 3)$:
$$CF = \sqrt{(0 - 6)^2 + (2 - 0)^2 + (3 - 0)^2} = \sqrt{36 + 4 + 9} = \sqrt{49} = \mathbf{7}$$
• Thus, the lengths of the medians are $\mathbf{7, \sqrt{34},}$ and $\mathbf{7}$.

Find the coordinates of a point on y-axis which are at a distance of $5\sqrt{2}$ from the point $P(3, -2, 5)$.
[3 Marks]
✅ CBSE Step-by-Step Solution
• Any point on the y-axis has coordinates of the form $Q(0, y, 0)$.
• The distance between $P(3, -2, 5)$ and $Q(0, y, 0)$ is given as $5\sqrt{2}$:
$$PQ = \sqrt{(0 - 3)^2 + (y - (-2))^2 + (0 - 5)^2} = 5\sqrt{2}$$

$$9 + (y + 2)^2 + 25 = 25 \times 2$$
$$(y + 2)^2 + 34 = 50$$
$$(y + 2)^2 = 50 - 34 = 16$$
$$y + 2 = \pm 4$$
• Two cases:
1. $y + 2 = 4 \implies y = 2$
2. $y + 2 = -4 \implies y = -6$
• Therefore, the required points on the y-axis are $\mathbf{(0, 2, 0)}$ and $\mathbf{(0, -6, 0)}$.

Misc Exercise
A point $R$ with x-coordinate $4$ lies on the line segment joining the points $P(2, -3, 4)$ and $Q(8, 0, 10)$. Find the coordinates of the point $R$.
[4 Marks]
✅ CBSE Step-by-Step Solution
• Let point $R$ divide the line segment joining $P(2, -3, 4)$ and $Q(8, 0, 10)$ in the ratio $k : 1$.
• By section formula, the coordinates of $R$ are:
$$R = \left(\frac{k(8) + 1(2)}{k + 1}, \frac{k(0) + 1(-3)}{k + 1}, \frac{k(10) + 1(4)}{k + 1}\right) = \left(\frac{8k + 2}{k + 1}, \frac{-3}{k + 1}, \frac{10k + 4}{k + 1}\right)$$
• Given that the x-coordinate of $R$ is $4$:
$$\frac{8k + 2}{k + 1} = 4$$
$$8k + 2 = 4(k + 1) = 4k + 4$$
$$4k = 2 \implies \mathbf{k = \frac{1}{2}}$$ (ratio $1 : 2$)
• Substituting $k = \frac{1}{2}$ to find the $y$ and $z$ coordinates of $R$:
$$y = \frac{-3}{\frac{1}{2} + 1} = \frac{-3}{3/2} = -3 \times \frac{2}{3} = \mathbf{-2}$$
$$z = \frac{10(1/2) + 4}{1/2 + 1} = \frac{5 + 4}{3/2} = \frac{9}{3/2} = 9 \times \frac{2}{3} = \mathbf{6}$$
• Hence, the coordinates of point $R$ are $\mathbf{(4, -2, 6)}$.

Question 6
Misc Exercise
If $A$ and $B$ be the points $(3, 4, 5)$ and $(-1, 3, -7)$, respectively, find the equation of the set of points $P$ such that $PA^2 + PB^2 = k^2$, where $k$ is a constant.
[4 Marks]
✅ CBSE Step-by-Step Solution
• Let the coordinates of point $P$ be $(x, y, z)$.
• Using the 3D distance squared formula:
$$PA^2 = (x - 3)^2 + (y - 4)^2 + (z - 5)^2$$
$$= (x^2 - 6x + 9) + (y^2 - 8y + 16) + (z^2 - 10z + 25)$$
$$= x^2 + y^2 + z^2 - 6x - 8y - 10z + 50$$
$$PB^2 = (x - (-1))^2 + (y - 3)^2 + (z - (-7))^2 = (x + 1)^2 + (y - 3)^2 + (z + 7)^2$$
$$= (x^2 + 2x + 1) + (y^2 - 6y + 9) + (z^2 + 14z + 49)$$
$$= x^2 + y^2 + z^2 + 2x - 6y + 14z + 59$$
• Summing $PA^2 + PB^2$:
$$PA^2 + PB^2 = (x^2 + y^2 + z^2 - 6x - 8y - 10z + 50) + (x^2 + y^2 + z^2 + 2x - 6y + 14z + 59)$$
$$= 2x^2 + 2y^2 + 2z^2 - 4x - 14y + 4z + 109$$
• Given $PA^2 + PB^2 = k^2$:
$$2x^2 + 2y^2 + 2z^2 - 4x - 14y + 4z + 109 = k^2$$
$$\mathbf{2x^2 + 2y^2 + 2z^2 - 4x - 14y + 4z + 109 - k^2 = 0}$$
• This is the equation of the set of points $P$ (representing a sphere).

Question 7
Misc Exercise
In a right-angled triangle $ABC$, right-angled at $B$, the vertices are $A(0, 4, 1)$ and $C(2, 3, -1)$. If the vertex $B$ is $(1, 2, 3)$, verify Pythagoras theorem for the triangle.
[3 Marks]
✅ CBSE Step-by-Step Solution
• Given vertices $A(0, 4, 1), B(1, 2, 3), C(2, 3, -1)$ with right angle at $B$.
• To verify Pythagoras theorem, we must check if $AB^2 + BC^2 = AC^2$.
• Calculate $AB^2$:
$$AB^2 = (1 - 0)^2 + (2 - 4)^2 + (3 - 1)^2 = 1^2 + (-2)^2 + 2^2 = 1 + 4 + 4 = 9$$
• Calculate $BC^2$:
$$BC^2 = (2 - 1)^2 + (3 - 2)^2 + (-1 - 3)^2 = 1^2 + 1^2 + (-4)^2 = 1 + 1 + 16 = 18$$
• Calculate $AC^2$:
$$AC^2 = (2 - 0)^2 + (3 - 4)^2 + (-1 - 1)^2 = 2^2 + (-1)^2 + (-2)^2 = 4 + 1 + 4 = 9$$
(Note: With $A(0, 4, 1), B(1, 2, 3), C(2, 3, -1)$, we have $AB^2 + AC^2 = 9 + 9 = 18 = BC^2$, indicating right angle at $A$, so $BC$ is hypotenuse).
• Testing $AB^2 + AC^2 = 9 + 9 = 18 = BC^2$.
• Since the sum of squares of two sides equals the square of the longest side ($BC^2 = 18$), the converse of Pythagoras theorem holds.
• Hence, $\triangle ABC$ is a right-angled triangle and Pythagoras theorem is verified.
