📘 Core Formulas & Progression Theorems

Arithmetic Progression (A.P.):
• General term: $a_n = a + (n - 1)d$.
• Sum of $n$ terms: $S_n = \dfrac{n}{2}[2a + (n - 1)d] = \dfrac{n}{2}(a + l)$.
• Arithmetic Mean (A.M.): $A = \dfrac{a + b}{2}$.
• Insertion of $n$ A.M.s: $d = \dfrac{b - a}{n + 1}$.
Geometric Progression (G.P.):
• General term: $a_n = a r^{n - 1}$.
• Sum of $n$ terms: $S_n = \dfrac{a(1 - r^n)}{1 - r} = \dfrac{a(r^n - 1)}{r - 1}$ ($r \ne 1$).
• Geometric Mean (G.M.): $G = \sqrt{ab}$.
• Fundamental Inequality: $A \ge G$ for any positive real numbers $a, b$.

Question 5
Exercise 8.2
In an A.P., if $p^{\text{th}}$ term is $\dfrac{1}{q}$ and $q^{\text{th}}$ term is $\dfrac{1}{p}$, prove that the sum of first $pq$ terms is $\dfrac{1}{2}(pq + 1)$, where $p \ne q$.
[4 Marks]
✅ CBSE Step-by-Step Solution
• Let first term be $a$ and common difference be $d$.
• Given:
$$a_p = a + (p - 1)d = \frac{1}{q} \quad \dots (1)$$
$$a_q = a + (q - 1)d = \frac{1}{p} \quad \dots (2)$$
• Subtracting (2) from (1):
$$(p - q)d = \frac{1}{q} - \frac{1}{p} = \frac{p - q}{pq}$$
Since $p \ne q$, we can divide by $(p - q)$ to get $d = \frac{1}{pq}$.
• Substituting $d = \frac{1}{pq}$ into (1):
$$a + (p - 1)\frac{1}{pq} = \frac{1}{q} \implies a + \frac{1}{q} - \frac{1}{pq} = \frac{1}{q} \implies a = \frac{1}{pq}$$
• Now, the sum of first $pq$ terms is:
$$S_{pq} = \frac{pq}{2}[2a + (pq - 1)d] = \frac{pq}{2}\left[\frac{2}{pq} + \frac{pq - 1}{pq}\right]$$
$$= \frac{pq}{2}\left[\frac{pq + 1}{pq}\right] = \mathbf{\frac{1}{2}(pq + 1)}$$
• Hence proved.

If $\dfrac{a + bx}{a - bx} = \dfrac{b + cx}{b - cx} = \dfrac{c + dx}{c - dx} \; (x \ne 0)$, then show that $a, b, c$ and $d$ are in G.P.

Question 13 (Misc)
Misc Exercise
Let $S$ be the sum, $P$ the product and $R$ the sum of reciprocals of $n$ terms in a G.P. Prove that $P^2 R^n = S^n$.
[4 Marks]
✅ CBSE Step-by-Step Solution
• Let the G.P. terms be $a, ar, ar^2, \dots, ar^{n - 1}$.
• $S = a + ar + \dots + ar^{n - 1} = \frac{a(r^n - 1)}{r - 1}$.
• $P = a \cdot ar \dots ar^{n - 1} = a^n r^{n(n - 1)/2} \implies P^2 = a^{2n} r^{n(n - 1)}$.
• $R = \frac{1}{a} + \frac{1}{ar} + \dots + \frac{1}{ar^{n - 1}} = \frac{1}{a}\left[\frac{1 - (1/r)^n}{1 - (1/r)}\right] = \frac{1}{a}\left[\frac{r^n - 1}{r^n} \cdot \frac{r}{r - 1}\right] = \frac{r^n - 1}{a r^{n - 1}(r - 1)}$.
• Now evaluate $P^2 R^n$:
$$P^2 R^n = [a^{2n} r^{n(n - 1)}] \times \left[\frac{r^n - 1}{a r^{n - 1}(r - 1)}\right]^n$$
$$= [a^{2n} r^{n(n - 1)}] \times \frac{(r^n - 1)^n}{a^n r^{n(n - 1)} (r - 1)^n}$$
$$= a^{2n - n} \frac{(r^n - 1)^n}{(r - 1)^n} = a^n \left[\frac{r^n - 1}{r - 1}\right]^n = \left[\frac{a(r^n - 1)}{r - 1}\right]^n = \mathbf{S^n}$$
• Hence proved.

Question 14 (Misc)

If $a, b, c, d$ are in G.P., prove that $(a^n + b^n), (b^n + c^n), (c^n + d^n)$ are in G.P.
[3 Marks]
✅ CBSE Step-by-Step Solution
• Since $a, b, c, d$ are in G.P., let $b = ar, c = ar^2, d = ar^3$.
• Evaluate each of the three terms:
- 1st term: $a^n + b^n = a^n + a^n r^n = a^n(1 + r^n)$
- 2nd term: $b^n + c^n = a^n r^n + a^n r^{2n} = a^n r^n(1 + r^n)$
- 3rd term: $c^n + d^n = a^n r^{2n} + a^n r^{3n} = a^n r^{2n}(1 + r^n)$
• Taking ratios of consecutive terms:
$$\frac{b^n + c^n}{a^n + b^n} = \frac{a^n r^n(1 + r^n)}{a^n(1 + r^n)} = r^n$$
$$\frac{c^n + d^n}{b^n + c^n} = \frac{a^n r^{2n}(1 + r^n)}{a^n r^n(1 + r^n)} = r^n$$
• Since the ratio between consecutive terms is constant ($r^n$), the terms $(a^n + b^n), (b^n + c^n), (c^n + d^n)$ are in G.P.
• Hence proved.
