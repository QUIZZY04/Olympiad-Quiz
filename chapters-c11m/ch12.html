Question 7
Exercise 12.1
Evaluate: $\lim_{x \to 2} \frac{3x^2 - x - 10}{x^2 - 4}$
[2 Marks]
✅ CBSE Step-by-Step Solution
• Direct substitution gives $\frac{3(4) - 2 - 10}{4 - 4} = \frac{0}{0}$, an indeterminate form.
• Factorizing numerator and denominator:
- Numerator: $3x^2 - x - 10 = 3x^2 - 6x + 5x - 10 = 3x(x - 2) + 5(x - 2) = (x - 2)(3x + 5)$
- Denominator: $x^2 - 4 = (x - 2)(x + 2)$
• Since $x \to 2 \implies x \neq 2$, cancel the common factor $(x - 2)$:
$$\lim_{x \to 2} \frac{(x - 2)(3x + 5)}{(x - 2)(x + 2)} = \lim_{x \to 2} \frac{3x + 5}{x + 2}$$
• Evaluating the limit:
$$\frac{3(2) + 5}{2 + 2} = \frac{6 + 5}{4} = \mathbf{\frac{11}{4}}$$

Question 8
Exercise 12.1
Evaluate: $\lim_{x \to 3} \frac{x^4 - 81}{2x^2 - 5x - 3}$
[2 Marks]
✅ CBSE Step-by-Step Solution
• At $x = 3$, $\frac{81 - 81}{18 - 15 - 3} = \frac{0}{0}$ (indeterminate form).
• Factorizing:
- Numerator: $x^4 - 81 = (x^2 - 9)(x^2 + 9) = (x - 3)(x + 3)(x^2 + 9)$
- Denominator: $2x^2 - 5x - 3 = 2x^2 - 6x + x - 3 = 2x(x - 3) + 1(x - 3) = (x - 3)(2x + 1)$
• Canceling common factor $(x - 3)$ ($x \neq 3$):
$$\lim_{x \to 3} \frac{(x + 3)(x^2 + 9)}{2x + 1}$$
• Substituting $x = 3$:
$$\frac{(3 + 3)(3^2 + 9)}{2(3) + 1} = \frac{6(9 + 9)}{6 + 1} = \frac{6(18)}{7} = \mathbf{\frac{108}{7}}$$

Question 10
Exercise 12.1
Evaluate: $\lim_{z \to 1} \frac{z^{1/3} - 1}{z^{1/6} - 1}$
[2 Marks]
✅ CBSE Step-by-Step Solution
• Direct substitution gives $\frac{0}{0}$.
• Divide numerator and denominator by $(z - 1)$:
$$\lim_{z \to 1} \frac{\frac{z^{1/3} - 1^{1/3}}{z - 1}}{\frac{z^{1/6} - 1^{1/6}}{z - 1}}$$ • Applying standard identity $\lim_{z \to 1} \frac{z^n - 1^n}{z - 1} = n(1)^{n-1} = n$:
- Numerator limit $= \frac{1}{3}(1)^{\frac{1}{3} - 1} = \frac{1}{3}$
- Denominator limit $= \frac{1}{6}(1)^{\frac{1}{6} - 1} = \frac{1}{6}$
• Thus:
$$\text{Limit} = \frac{1/3}{1/6} = \frac{1}{3} \times \frac{6}{1} = \mathbf{2}$$

Question 12
Exercise 12.1
Evaluate: $\lim_{x \to -2} \frac{\frac{1}{x} + \frac{1}{2}}{x + 2}$
[2 Marks]
✅ CBSE Step-by-Step Solution
• Direct substitution gives $\frac{-1/2 + 1/2}{-2 + 2} = \frac{0}{0}$.
• Simplifying the numerator:
$$\frac{1}{x} + \frac{1}{2} = \frac{2 + x}{2x} = \frac{x + 2}{2x}$$
• Substituting into the limit:
$$\lim_{x \to -2} \frac{\frac{x + 2}{2x}}{x + 2} = \lim_{x \to -2} \frac{x + 2}{2x(x + 2)}$$
• Canceling common factor $(x + 2)$ ($x \neq -2$):
$$\lim_{x \to -2} \frac{1}{2x} = \frac{1}{2(-2)} = \mathbf{-\frac{1}{4}}$$

Question 13
Exercise 12.1
Evaluate: $\lim_{x \to 0} \frac{\sin ax}{bx}$
[2 Marks]
✅ CBSE Step-by-Step Solution
• Rewriting expression to use $\lim_{\theta \to 0} \frac{\sin \theta}{\theta} = 1$:
$$\frac{\sin ax}{bx} = \frac{\sin ax}{ax} \cdot \frac{ax}{bx} = \frac{a}{b} \left(\frac{\sin ax}{ax}\right)$$
• As $x \to 0$, $ax \to 0$.
• Therefore:
$$\lim_{x \to 0} \frac{\sin ax}{bx} = \frac{a}{b} \lim_{ax \to 0} \left(\frac{\sin ax}{ax}\right) = \frac{a}{b} (1) = \mathbf{\frac{a}{b}}$$

Question 17
Exercise 12.1
Evaluate: $\lim_{x \to 0} \frac{\cos 2x - 1}{\cos x - 1}$
[2 Marks]
✅ CBSE Step-by-Step Solution
• Direct substitution gives $\frac{0}{0}$.
• Using trigonometric half-angle identities:
$$1 - \cos 2x = 2\sin^2 x \implies \cos 2x - 1 = -2\sin^2 x$$
$$1 - \cos x = 2\sin^2 \left(\frac{x}{2}\right) \implies \cos x - 1 = -2\sin^2 \left(\frac{x}{2}\right)$$
• Substituting into the limit:
$$\lim_{x \to 0} \frac{-2\sin^2 x}{-2\sin^2(x/2)} = \lim_{x \to 0} \frac{\sin^2 x}{\sin^2(x/2)}$$
• Dividing and multiplying by $x^2$ and $(x/2)^2$:
$$= \lim_{x \to 0} \frac{\left(\frac{\sin x}{x}\right)^2 \cdot x^2}{\left(\frac{\sin(x/2)}{x/2}\right)^2 \cdot \frac{x^2}{4}} = \frac{(1)^2}{\frac{1}{4} (1)^2} = \mathbf{4}$$
CBSE Marking Scheme Rubric (Session 2026–27)
Applying half-angle identities $1 - \cos 2\theta = 2\sin^2 \theta$1 Mark
Evaluating limit to obtain $4$1 Mark

Question 21
Exercise 12.1
Evaluate: $\lim_{x \to 0} (\csc x - \cot x)$
[2 Marks]
✅ CBSE Step-by-Step Solution
• Express in terms of sine and cosine:
$$\csc x - \cot x = \frac{1}{\sin x} - \frac{\cos x}{\sin x} = \frac{1 - \cos x}{\sin x}$$
• Using half-angle identities $1 - \cos x = 2\sin^2(x/2)$ and $\sin x = 2\sin(x/2)\cos(x/2)$:
$$\frac{1 - \cos x}{\sin x} = \frac{2\sin^2(x/2)}{2\sin(x/2)\cos(x/2)} = \frac{\sin(x/2)}{\cos(x/2)} = \tan\left(\frac{x}{2}\right)$$
• As $x \to 0$:
$$\lim_{x \to 0} \tan\left(\frac{x}{2}\right) = \tan 0 = \mathbf{0}$$

Question 23
Exercise 12.1
Find $\lim_{x \to 0} f(x)$ and $\lim_{x \to 1} f(x)$, where $f(x) = \begin{cases} 2x + 3, & x \le 0 \\ 3(x + 1), & x > 0 \end{cases}$
[3 Marks]
✅ CBSE Step-by-Step Solution
• Part 1: At $x = 0$:
- Left hand limit (LHL): $\lim_{x \to 0^-} f(x) = \lim_{x \to 0^-} (2x + 3) = 2(0) + 3 = 3$
- Right hand limit (RHL): $\lim_{x \to 0^+} f(x) = \lim_{x \to 0^+} 3(x + 1) = 3(0 + 1) = 3$
Since $\text{LHL} = \text{RHL} = 3$, $\mathbf{\lim_{x \to 0} f(x) = 3}$.

• Part 2: At $x = 1$:
Since $x = 1 > 0$, in an open neighborhood around $x = 1$, $f(x) = 3(x + 1)$:
$$\lim_{x \to 1} f(x) = \lim_{x \to 1} 3(x + 1) = 3(1 + 1) = \mathbf{6}$$

Question 28
Exercise 12.1
Suppose $f(x) = \begin{cases} a + bx, & x < 1 \\ 4, & x = 1 \\ b - ax, & x > 1 \end{cases}$ and if $\lim_{x \to 1} f(x) = f(1)$, what are possible values of $a$ and $b$?
[3 Marks]
✅ CBSE Step-by-Step Solution
• Given $f(1) = 4$.
• For $\lim_{x \to 1} f(x) = f(1)$, we must have $\text{LHL} = \text{RHL} = f(1) = 4$.
• Left Hand Limit (LHL):
$$\lim_{x \to 1^-} f(x) = \lim_{x \to 1^-} (a + bx) = a + b(1) = a + b$$
So $a + b = 4 \quad \dots (1)$
• Right Hand Limit (RHL):
$$\lim_{x \to 1^+} f(x) = \lim_{x \to 1^+} (b - ax) = b - a(1) = b - a$$
So $b - a = 4 \quad \dots (2)$
• Adding equations $(1)$ and $(2)$:
$$(a + b) + (b - a) = 4 + 4 \implies 2b = 8 \implies \mathbf{b = 4}$$
• Substituting $b = 4$ into $(1)$:
$$a + 4 = 4 \implies \mathbf{a = 0}$$
• Therefore, the values are $\mathbf{a = 0}$ and $\mathbf{b = 4}$.
CBSE Marking Scheme Rubric (Session 2026–27)
Equating LHL to $4 \implies a + b = 4$1 Mark
Equating RHL to $4 \implies b - a = 4$1 Mark
Solving linear system for $a = 0, b = 4$1 Mark

Question 30
Exercise 12.1
If $f(x) = \begin{cases} |x| + 1, & x < 0 \\ 0, & x = 0 \\ |x| - 1, & x > 0 \end{cases}$. For what value(s) of $a$ does $\lim_{x \to a} f(x)$ exist?
[3 Marks]
✅ CBSE Step-by-Step Solution
• We analyze the limit for three cases: $a = 0$, $a < 0$, and $a > 0$.
• Case 1: $a = 0$:
- LHL: $\lim_{x \to 0^-} f(x) = \lim_{x \to 0^-} (|x| + 1) = \lim_{x \to 0^-} (-x + 1) = 0 + 1 = 1$
- RHL: $\lim_{x \to 0^+} f(x) = \lim_{x \to 0^+} (|x| - 1) = \lim_{x \to 0^+} (x - 1) = 0 - 1 = -1$
Since $\text{LHL} \neq \text{RHL}$, $\lim_{x \to 0} f(x)$ does not exist.

• Case 2: $a < 0$:
In a neighborhood of $a$, $x < 0$, so $f(x) = -x + 1$, which is a polynomial. Thus $\lim_{x \to a} f(x) = -a + 1$, which exists.

• Case 3: $a > 0$:
In a neighborhood of $a$, $x > 0$, so $f(x) = x - 1$, which is a polynomial. Thus $\lim_{x \to a} f(x) = a - 1$, which exists.

• Conclusion: $\lim_{x \to a} f(x)$ exists for all real numbers $a \neq 0$.

Question 31
Exercise 12.1
If the function $f(x)$ satisfies $\lim_{x \to 1} \frac{f(x) - 2}{x^2 - 1} = \pi$, evaluate $\lim_{x \to 1} f(x)$.
[2 Marks]
✅ CBSE Step-by-Step Solution
• Given $\lim_{x \to 1} \frac{f(x) - 2}{x^2 - 1} = \pi$.
• As $x \to 1$, the denominator $x^2 - 1 \to 1^2 - 1 = 0$.
• For the quotient limit to exist and be finite (equal to $\pi$), the numerator limit must also approach $0$:
$$\lim_{x \to 1} [f(x) - 2] = \lim_{x \to 1} \left[\frac{f(x) - 2}{x^2 - 1} \cdot (x^2 - 1)\right]$$
$$= \left(\lim_{x \to 1} \frac{f(x) - 2}{x^2 - 1}\right) \cdot \left(\lim_{x \to 1} (x^2 - 1)\right) = \pi \cdot 0 = 0$$
• Therefore:
$$\lim_{x \to 1} [f(x) - 2] = 0 \implies \lim_{x \to 1} f(x) - 2 = 0 \implies \mathbf{\lim_{x \to 1} f(x) = 2}$$

Question 32

If $f(x) = \begin{cases} mx^2 + n, & x < 0 \\ nx + m, & 0 \le x \le 1 \\ nx^3 + m, & x > 1 \end{cases}$. For what integers $m$ and $n$ does both $\lim_{x \to 0} f(x)$ and $\lim_{x \to 1} f(x)$ exist?
[3 Marks]
✅ CBSE Step-by-Step Solution
• Condition 1: For $\lim_{x \to 0} f(x)$ to exist:
- LHL at $x = 0$: $\lim_{x \to 0^-} (mx^2 + n) = m(0) + n = n$
- RHL at $x = 0$: $\lim_{x \to 0^+} (nx + m) = n(0) + m = m$
For the limit to exist: $\text{LHL} = \text{RHL} \implies \mathbf{m = n}$.

• Condition 2: For $\lim_{x \to 1} f(x)$ to exist:
- LHL at $x = 1$: $\lim_{x \to 1^-} (nx + m) = n(1) + m = m + n$
- RHL at $x = 1$: $\lim_{x \to 1^+} (nx^3 + m) = n(1)^3 + m = m + n$
Here $\text{LHL} = \text{RHL} = m + n$ for all values of $m$ and $n$.

Question 4
Exercise 12.2
Find the derivative of the following functions from first principle:
(i) $x^3 - 27$
(ii) $(x - 1)(x - 2)$
(iii) $\frac{1}{x^2}$
(iv) $\frac{x + 1}{x - 1}$
[4 Marks]
✅ CBSE Step-by-Step Solution
• By First Principle of Derivatives:
$$f'(x) = \lim_{h \to 0} \frac{f(x + h) - f(x)}{h}$$
• (i) $f(x) = x^3 - 27$:
$$f'(x) = \lim_{h \to 0} \frac{((x+h)^3 - 27) - (x^3 - 27)}{h} = \lim_{h \to 0} \frac{x^3 + 3x^2 h + 3xh^2 + h^3 - x^3}{h}$$
$$= \lim_{h \to 0} (3x^2 + 3xh + h^2) = \mathbf{3x^2}$$
• (ii) $f(x) = (x - 1)(x - 2) = x^2 - 3x + 2$:
$$f'(x) = \lim_{h \to 0} \frac{((x+h)^2 - 3(x+h) + 2) - (x^2 - 3x + 2)}{h}$$
$$= \lim_{h \to 0} \frac{x^2 + 2xh + h^2 - 3x - 3h + 2 - x^2 + 3x - 2}{h} = \lim_{h \to 0} \frac{2xh + h^2 - 3h}{h} = \lim_{h \to 0} (2x + h - 3) = \mathbf{2x - 3}$$
• (iii) $f(x) = \frac{1}{x^2}$:
$$f'(x) = \lim_{h \to 0} \frac{\frac{1}{(x+h)^2} - \frac{1}{x^2}}{h} = \lim_{h \to 0} \frac{x^2 - (x+h)^2}{h x^2 (x+h)^2} = \lim_{h \to 0} \frac{-2xh - h^2}{h x^2 (x+h)^2} = \lim_{h \to 0} \frac{-2x - h}{x^2 (x+h)^2} = \mathbf{-\frac{2}{x^3}}$$
• (iv) $f(x) = \frac{x + 1}{x - 1}$:
$$f'(x) = \lim_{h \to 0} \frac{\frac{x+h+1}{x+h-1} - \frac{x+1}{x-1}}{h} = \lim_{h \to 0} \frac{(x+h+1)(x-1) - (x+1)(x+h-1)}{h(x+h-1)(x-1)}$$
$$= \lim_{h \to 0} \frac{-2h}{h(x+h-1)(x-1)} = \lim_{h \to 0} \frac{-2}{(x+h-1)(x-1)} = \mathbf{-\frac{2}{(x - 1)^2}}$$

For the function $f(x) = \frac{x^{100}}{100} + \frac{x^{99}}{99} + \dots + \frac{x^2}{2} + x + 1$, prove that $f'(1) = 100 f'(0)$.
[3 Marks]
✅ CBSE Step-by-Step Solution
• Differentiating each term of $f(x)$ with respect to $x$ using $\frac{d}{dx}(x^n) = n x^{n-1}$:
$$f'(x) = \frac{100 x^{99}}{100} + \frac{99 x^{98}}{99} + \dots + \frac{2x}{2} + 1 + 0$$
$$f'(x) = x^{99} + x^{98} + \dots + x + 1$$
• Evaluating $f'(1)$:
$$f'(1) = 1^{99} + 1^{98} + \dots + 1 + 1$$
This is a sum of $1$ repeated $100$ times (powers $x^1$ to $x^{99}$ plus the constant $1$):
$$f'(1) = 100$$
• Evaluating $f'(0)$:
$$f'(0) = 0^{99} + 0^{98} + \dots + 0 + 1 = 1$$
• Comparing the two values:
$$f'(1) = 100 = 100(1) = 100 f'(0)$$
• Hence, $\mathbf{f'(1) = 100 f'(0)}$. (Hence Proved).

Question 10
Exercise 12.2
Find the derivative of $\cos x$ from first principle.
[3 Marks]
✅ CBSE Step-by-Step Solution
• Let $f(x) = \cos x$.
• By First Principle of derivative:
$$f'(x) = \lim_{h \to 0} \frac{f(x + h) - f(x)}{h} = \lim_{h \to 0} \frac{\cos(x + h) - \cos x}{h}$$
• Using identity $\cos C - \cos D = -2\sin\left(\frac{C + D}{2}\right)\sin\left(\frac{C - D}{2}\right)$:
$$\cos(x + h) - \cos x = -2\sin\left(x + \frac{h}{2}\right)\sin\left(\frac{h}{2}\right)$$
• Substituting into the limit:
$$f'(x) = \lim_{h \to 0} \frac{-2\sin\left(x + \frac{h}{2}\right)\sin\left(\frac{h}{2}\right)}{h}$$
$$= -\lim_{h \to 0} \sin\left(x + \frac{h}{2}\right) \cdot \lim_{h/2 \to 0} \left(\frac{\sin(h/2)}{h/2}\right)$$
• Since $\lim_{h \to 0} \sin(x + h/2) = \sin x$ and $\lim_{h/2 \to 0} \frac{\sin(h/2)}{h/2} = 1$:
$$f'(x) = -\sin x \cdot 1 = \mathbf{-\sin x}$$
• Hence, $\frac{d}{dx}(\cos x) = -\sin x$.

Question 1
Misc Exercise
Find the derivative of the following functions from first principle:
(i) $-x$
(ii) $(-x)^{-1}$
(iii) $\sin(x + 1)$
(iv) $\cos\left(x - \frac{\pi}{8}\right)$
[4 Marks]
✅ CBSE Step-by-Step Solution
• Formula from first principle: $f'(x) = \lim_{h \to 0} \frac{f(x + h) - f(x)}{h}$.

• (i) $f(x) = -x$:
$$f'(x) = \lim_{h \to 0} \frac{-(x + h) - (-x)}{h} = \lim_{h \to 0} \frac{-x - h + x}{h} = \lim_{h \to 0} \frac{-h}{h} = \mathbf{-1}$$
• (ii) $f(x) = (-x)^{-1} = -\frac{1}{x}$:
$$f'(x) = \lim_{h \to 0} \frac{-\frac{1}{x+h} - \left(-\frac{1}{x}\right)}{h} = \lim_{h \to 0} \frac{\frac{1}{x} - \frac{1}{x+h}}{h} = \lim_{h \to 0} \frac{x+h - x}{h x(x+h)} = \lim_{h \to 0} \frac{h}{h x(x+h)} = \mathbf{\frac{1}{x^2}}$$
• (iii) $f(x) = \sin(x + 1)$:
$$f'(x) = \lim_{h \to 0} \frac{\sin(x + h + 1) - \sin(x + 1)}{h}$$
Using $\sin C - \sin D = 2\cos\left(\frac{C+D}{2}\right)\sin\left(\frac{C-D}{2}\right)$:
$$= \lim_{h \to 0} \frac{2\cos\left(x + 1 + \frac{h}{2}\right)\sin\left(\frac{h}{2}\right)}{h} = \lim_{h \to 0} \cos\left(x + 1 + \frac{h}{2}\right) \cdot \lim_{h/2 \to 0} \frac{\sin(h/2)}{h/2} = \mathbf{\cos(x + 1)}$$
• (iv) $f(x) = \cos\left(x - \frac{\pi}{8}\right)$:
$$f'(x) = \lim_{h \to 0} \frac{\cos\left(x + h - \frac{\pi}{8}\right) - \cos\left(x - \frac{\pi}{8}\right)}{h}$$
Using $\cos C - \cos D = -2\sin\left(\frac{C+D}{2}\right)\sin\left(\frac{C-D}{2}\right)$:
$$= \lim_{h \to 0} \frac{-2\sin\left(x - \frac{\pi}{8} + \frac{h}{2}\right)\sin\left(\frac{h}{2}\right)}{h} = -\lim_{h \to 0} \sin\left(x - \frac{\pi}{8} + \frac{h}{2}\right) \cdot 1 = \mathbf{-\sin\left(x - \frac{\pi}{8}\right)}$$
