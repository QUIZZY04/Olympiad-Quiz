📘 Key Formulas & Combinatorial Theorems

Counting Principles & Factorials:
• Multiplication Principle: Event A in $m$ ways and Event B in $n$ ways $\implies m \times n$ ways.
• Factorial: $n! = n(n - 1)(n - 2) \cdots 3 \cdot 2 \cdot 1$, with $0! = 1$ and $1! = 1$.
• Permutations of distinct items: $^n P_r = \dfrac{n!}{(n - r)!}$.
• Permutations with repeated items: $\dfrac{n!}{p_1! p_2! \cdots p_k!}$.
Combinations & Identities:
• Selection formula: $^n C_r = \dfrac{n!}{r!(n - r)!}$.
• Fundamental relation: $^n P_r = r! \times ^n C_r$.
• Complementary combination: $^n C_r = ^n C_{n - r}$.
• Equality rule: $^n C_x = ^n C_y \implies x = y \text{ or } x + y = n$.
• Pascal's Identity: $^n C_r + ^n C_{r - 1} = ^{n + 1}C_r$.

(i) repetition of the digits is allowed?
(ii) repetition of the digits is not allowed?

- Hundreds place can be filled by any of the $5$ digits (5 ways).
- Tens place can be filled by any of the $5$ digits (5 ways).
- Units place can be filled by any of the $5$ digits (5 ways).
- By Fundamental Principle of Multiplication:
$$\text{Total 3-digit numbers} = 5 \times 5 \times 5 = \mathbf{125}$$
• (ii) When repetition of digits is not allowed:
- Hundreds place can be filled in $5$ ways.
- Tens place can be filled by any of the remaining $4$ digits (4 ways).
- Units place can be filled by any of the remaining $3$ digits (3 ways).
- By Fundamental Principle of Multiplication:
$$\text{Total 3-digit numbers} = 5 \times 4 \times 3 = \mathbf{60}$$

Find $n$ if $^{n - 1}P_3 : ^n P_4 = 1 : 9$.
[2 Marks]
✅ CBSE Step-by-Step Solution
• Given ratio:
$$\frac{^{n - 1}P_3}{^n P_4} = \frac{1}{9}$$

$$^{n - 1}P_3 = \frac{(n - 1)!}{((n - 1) - 3)!} = \frac{(n - 1)!}{(n - 4)!}$$

$$\frac{\frac{(n - 1)!}{(n - 4)!}}{\frac{n!}{(n - 4)!}} = \frac{(n - 1)!}{n!} = \frac{1}{9}$$
• Since $n! = n(n - 1)!$:
$$\frac{(n - 1)!}{n(n - 1)!} = \frac{1}{n} = \frac{1}{9}$$
$$n = \mathbf{9}$$

Question 7
Exercise 6.3
Find $r$ if
(i) $^5 P_r = 2 \times ^6 P_{r - 1}$
(ii) $^5 P_r = ^6 P_{r - 1}$.
[4 Marks]
✅ CBSE Step-by-Step Solution
• (i) Given: $^5 P_r = 2 \times ^6 P_{r - 1}$
$$\frac{5!}{(5 - r)!} = 2 \times \frac{6!}{(6 - (r - 1))!} = 2 \times \frac{6!}{(7 - r)!}$$
$$\frac{5!}{(5 - r)!} = 2 \times \frac{6 \times 5!}{(7 - r)(6 - r)(5 - r)!}$$
$$1 = \frac{12}{(7 - r)(6 - r)} \implies (7 - r)(6 - r) = 12$$
• Factoring $12$ into consecutive integers ($4 \times 3$):
$$7 - r = 4 \implies r = 3$$
(Also $(r - 3)(r - 10) = 0$, but $r \le 5$, so $r = 10$ is rejected). Thus, $\mathbf{r = 3}$.

• (ii) Given: $^5 P_r = ^6 P_{r - 1}$
$$\frac{5!}{(5 - r)!} = \frac{6!}{(7 - r)!} = \frac{6 \times 5!}{(7 - r)(6 - r)(5 - r)!}$$
$$1 = \frac{6}{(7 - r)(6 - r)} \implies (7 - r)(6 - r) = 6$$
• Consecutive factors of $6$ ($3 \times 2$):
$$7 - r = 3 \implies r = 4$$
(Or $r^2 - 13r + 36 = 0 \implies (r - 4)(r - 9) = 0$; $r \le 5 \implies r = 4$). Thus, $\mathbf{r = 4}$.

$$\frac{^{2n}C_3}{^n C_3} = \frac{\frac{2n(2n - 1)(2n - 2)}{3!}}{\frac{n(n - 1)(n - 2)}{3!}} = \frac{2n(2n - 1) \times 2(n - 1)}{n(n - 1)(n - 2)} = \frac{4(2n - 1)}{n - 2}$$
• Equating to $12$:
$$\frac{4(2n - 1)}{n - 2} = 12 \implies \frac{2n - 1}{n - 2} = 3$$
$$2n - 1 = 3(n - 2) = 3n - 6 \implies n = \mathbf{5}$$

• (ii) Given: $^{2n}C_3 : ^n C_3 = 11 : 1$
$$\frac{4(2n - 1)}{n - 2} = 11$$
$$4(2n - 1) = 11(n - 2)$$
$$8n - 4 = 11n - 22$$
$$11n - 8n = 22 - 4 \implies 3n = 18 \implies n = \mathbf{6}$$
