Question 1
Exercise 10.1
Find the equation of the circle with centre $(0, 2)$ and radius $2$.
[2 Marks]
✅ CBSE Step-by-Step Solution
• The standard equation of a circle with centre $(h, k)$ and radius $r$ is:
$$(x - h)^2 + (y - k)^2 = r^2$$
• Given $h = 0, k = 2$, and $r = 2$.
• Substituting the given values:
$$(x - 0)^2 + (y - 2)^2 = 2^2$$
$$x^2 + (y^2 - 4y + 4) = 4$$
$$x^2 + y^2 - 4y = 0$$
• Hence, the required equation of the circle is $\mathbf{x^2 + y^2 - 4y = 0}$.

Question 3
Exercise 10.1
Find the equation of the circle with centre $\left(\frac{1}{2}, \frac{1}{4}\right)$ and radius $\frac{1}{12}$.
[2 Marks]
✅ CBSE Step-by-Step Solution
• Centre $(h, k) = \left(\frac{1}{2}, \frac{1}{4}\right)$, radius $r = \frac{1}{12}$.
• The standard equation of the circle is:
$$\left(x - \frac{1}{2}\right)^2 + \left(y - \frac{1}{4}\right)^2 = \left(\frac{1}{12}\right)^2$$
• Expanding each term:
$$\left(x^2 - x + \frac{1}{4}\right) + \left(y^2 - \frac{y}{2} + \frac{1}{16}\right) = \frac{1}{144}$$
$$x^2 + y^2 - x - \frac{1}{2}y + \frac{4 + 1}{16} = \frac{1}{144}$$
$$x^2 + y^2 - x - \frac{1}{2}y + \frac{5}{16} = \frac{1}{144}$$
• Multiplying the entire equation by $144$ (LCM of $16, 2, 144$):
$$144x^2 + 144y^2 - 144x - 72y + 9(5) = 1$$
$$144x^2 + 144y^2 - 144x - 72y + 45 - 1 = 0$$
$$144x^2 + 144y^2 - 144x - 72y + 44 = 0$$
• Dividing throughout by $4$:
$$\mathbf{36x^2 + 36y^2 - 36x - 18y + 11 = 0}$$

Find the equation of the circle with centre $(-a, -b)$ and radius $\sqrt{a^2 - b^2}$.
[2 Marks]
✅ CBSE Step-by-Step Solution
• Given centre $(h, k) = (-a, -b)$ and radius $r = \sqrt{a^2 - b^2}$.
• Equation of the circle:
$$(x - (-a))^2 + (y - (-b))^2 = \left(\sqrt{a^2 - b^2}\right)^2$$
$$(x + a)^2 + (y + b)^2 = a^2 - b^2$$
• Expanding the terms:
$$(x^2 + 2ax + a^2) + (y^2 + 2by + b^2) = a^2 - b^2$$
$$x^2 + y^2 + 2ax + 2by + a^2 + b^2 - a^2 + b^2 = 0$$
$$x^2 + y^2 + 2ax + 2by + 2b^2 = 0$$
• Hence, the required equation is $\mathbf{x^2 + y^2 + 2ax + 2by + 2b^2 = 0}$.

[2 Marks]

• Given equation: $2x^2 + 2y^2 - x = 0$.
• Dividing the entire equation by $2$ to make coefficients of $x^2$ and $y^2$ equal to $1$:

• Comparing with $(x - h)^2 + (y - k)^2 = r^2$:
$$h = \frac{1}{4}, \quad k = 0, \quad r = \frac{1}{4}$$

Centre = $\mathbf{\left(\frac{1}{4}, 0\right)}$

Question 10
Exercise 10.1
Find the equation of the circle passing through the points $(4, 1)$ and $(6, 5)$ and whose centre is on the line $4x + y = 16$.
[4 Marks]
✅ CBSE Step-by-Step Solution
• Let the equation of the circle be $(x - h)^2 + (y - k)^2 = r^2$, where centre is $(h, k)$ and radius is $r$.
• Since it passes through $(4, 1)$:
$$(4 - h)^2 + (1 - k)^2 = r^2 \quad \dots (1)$$
• Since it passes through $(6, 5)$:
$$(6 - h)^2 + (5 - k)^2 = r^2 \quad \dots (2)$$
• Equating $(1)$ and $(2)$ since both equal $r^2$:
$$(4 - h)^2 + (1 - k)^2 = (6 - h)^2 + (5 - k)^2$$
$$16 - 8h + h^2 + 1 - 2k + k^2 = 36 - 12h + h^2 + 25 - 10k + k^2$$
$$-8h - 2k + 17 = -12h - 10k + 61$$
$$4h + 8k = 44 \implies h + 2k = 11 \quad \dots (3)$$
• The centre $(h, k)$ lies on the line $4x + y = 16$:
$$4h + k = 16 \implies k = 16 - 4h \quad \dots (4)$$
• Substitute $(4)$ into $(3)$:
$$h + 2(16 - 4h) = 11 \implies h + 32 - 8h = 11$$
$$-7h = -21 \implies \mathbf{h = 3}$$
$$k = 16 - 4(3) = 16 - 12 \implies \mathbf{k = 4}$$
• Finding radius $r^2$ using $(1)$:
$$r^2 = (4 - 3)^2 + (1 - 4)^2 = 1^2 + (-3)^2 = 1 + 9 = 10$$
• Equation of the circle:
$$(x - 3)^2 + (y - 4)^2 = 10$$
$$x^2 - 6x + 9 + y^2 - 8y + 16 = 10$$
$$\mathbf{x^2 + y^2 - 6x - 8y + 15 = 0}$$

Question 11
Exercise 10.1
Find the equation of the circle passing through the points $(2, 3)$ and $(-1, 1)$ and whose centre is on the line $x - 3y - 11 = 0$.
[4 Marks]
✅ CBSE Step-by-Step Solution
• Let the centre be $(h, k)$ and radius be $r$.
• Passing through $(2, 3)$:
$$(2 - h)^2 + (3 - k)^2 = r^2 \quad \dots (1)$$
• Passing through $(-1, 1)$:
$$(-1 - h)^2 + (1 - k)^2 = r^2 \implies (h + 1)^2 + (k - 1)^2 = r^2 \quad \dots (2)$$
• Equating $(1)$ and $(2)$:
$$(2 - h)^2 + (3 - k)^2 = (h + 1)^2 + (k - 1)^2$$
$$4 - 4h + h^2 + 9 - 6k + k^2 = h^2 + 2h + 1 + k^2 - 2k + 1$$
$$-4h - 6k + 13 = 2h - 2k + 2$$
$$-6h - 4k + 11 = 0 \implies 6h + 4k = 11 \quad \dots (3)$$
• Centre $(h, k)$ lies on $x - 3y - 11 = 0$:
$$h - 3k = 11 \implies h = 3k + 11 \quad \dots (4)$$
• Substituting $(4)$ into $(3)$:
$$6(3k + 11) + 4k = 11$$
$$18k + 66 + 4k = 11 \implies 22k = -55 \implies \mathbf{k = -\frac{5}{2}}$$ • Then $h = 3\left(-\frac{5}{2}\right) + 11 = -\frac{15}{2} + \frac{22}{2} = \mathbf{\frac{7}{2}}$.
• Finding radius squared $r^2$:
$$r^2 = \left(2 - \frac{7}{2}\right)^2 + \left(3 - \left(-\frac{5}{2}\right)\right)^2 = \left(-\frac{3}{2}\right)^2 + \left(\frac{11}{2}\right)^2 = \frac{9}{4} + \frac{121}{4} = \frac{130}{4} = \frac{65}{2}$$
• Equation of the circle:
$$\left(x - \frac{7}{2}\right)^2 + \left(y + \frac{5}{2}\right)^2 = \frac{130}{4}$$
$$x^2 - 7x + \frac{49}{4} + y^2 + 5y + \frac{25}{4} = \frac{130}{4}$$
$$x^2 + y^2 - 7x + 5y + \frac{74 - 130}{4} = 0$$
$$x^2 + y^2 - 7x + 5y - \frac{56}{4} = 0$$
$$\mathbf{x^2 + y^2 - 7x + 5y - 14 = 0}$$

Question 12
Exercise 10.1
Find the equation of the circle with radius $5$ whose centre lies on x-axis and passes through the point $(2, 3)$.
[3 Marks]
✅ CBSE Step-by-Step Solution
• Since the centre lies on the x-axis, its coordinates are $(h, 0)$.
• Given radius $r = 5$, and circle passes through $(2, 3)$.
• Distance from centre $(h, 0)$ to point $(2, 3)$ is equal to radius $5$:
$$(2 - h)^2 + (3 - 0)^2 = 5^2$$
$$(2 - h)^2 + 9 = 25$$
$$(2 - h)^2 = 16$$
$$2 - h = \pm 4$$
• Case 1: $2 - h = 4 \implies h = -2$. Centre is $(-2, 0)$.
Equation: $(x - (-2))^2 + (y - 0)^2 = 5^2 \implies \mathbf{(x + 2)^2 + y^2 = 25} \implies \mathbf{x^2 + y^2 + 4x - 21 = 0}$
• Case 2: $2 - h = -4 \implies h = 6$. Centre is $(6, 0)$.
Equation: $(x - 6)^2 + (y - 0)^2 = 5^2 \implies \mathbf{(x - 6)^2 + y^2 = 25} \implies \mathbf{x^2 + y^2 - 12x + 11 = 0}$
• Thus, there are two such circles:
$$\mathbf{x^2 + y^2 + 4x - 21 = 0 \quad \text{and} \quad x^2 + y^2 - 12x + 11 = 0}$$

Question 13
Exercise 10.1
Find the equation of the circle passing through $(0, 0)$ and making intercepts $a$ and $b$ on the coordinate axes.
[3 Marks]
✅ CBSE Step-by-Step Solution
• The circle passes through $(0, 0)$ and has x-intercept $a$ and y-intercept $b$.
• Therefore, the circle passes through points $O(0, 0), A(a, 0)$, and $B(0, b)$.
• Since $\angle AOB = 90^\circ$ (angle between coordinate axes), the chord $AB$ subtends a right angle at the origin.
• By the diameter form theorem of a circle, $AB$ is a diameter of the circle.
• The equation of a circle on the line segment joining $(x_1, y_1) = (a, 0)$ and $(x_2, y_2) = (0, b)$ as diameter is:
$$(x - x_1)(x - x_2) + (y - y_1)(y - y_2) = 0$$
$$(x - a)(x - 0) + (y - 0)(y - b) = 0$$
$$x(x - a) + y(y - b) = 0$$
$$\mathbf{x^2 + y^2 - ax - by = 0}$$
• (Alternatively, centre is $(a/2, b/2)$ and radius is $\sqrt{a^2 + b^2}/2$).

Question 15
Exercise 10.1
Does the point $(-2.5, 3.5)$ lie inside, outside or on the circle $x^2 + y^2 = 25$?
[2 Marks]
✅ CBSE Step-by-Step Solution
• The equation of the circle is $x^2 + y^2 = 25$, which has centre at $(0, 0)$ and radius $r = 5$ ($r^2 = 25$).
• The position of a point $(x_1, y_1)$ with respect to $x^2 + y^2 = r^2$ is determined by the distance $d^2 = x_1^2 + y_1^2$ compared with $r^2$:
- If $d^2 < r^2$, point lies inside the circle.
- If $d^2 = r^2$, point lies on the circle.
- If $d^2 > r^2$, point lies outside the circle.
• Here $(x_1, y_1) = (-2.5, 3.5)$:
$$d^2 = (-2.5)^2 + (3.5)^2 = 6.25 + 12.25 = 18.5$$
• Comparing $d^2$ with $r^2$:
$$18.5 < 25 \implies d^2 < r^2$$
• Since $18.5 < 25$, the point $(-2.5, 3.5)$ lies inside the circle.

An arch is in the form of a semi-ellipse. It is $8\text{ m}$ wide and $2\text{ m}$ high at the centre. Find the height of the arch at a point $1.5\text{ m}$ from one end.
[4 Marks]
✅ CBSE Step-by-Step Solution
• Let the centre of the ellipse be at origin $(0, 0)$ and the horizontal base along the x-axis.
• Width of the semi-ellipse $= 8\text{ m} \implies 2a = 8 \implies a = 4$.
• Height at the centre $= 2\text{ m} \implies b = 2$.
• The equation of the semi-ellipse is:
$$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 \implies \frac{x^2}{16} + \frac{y^2}{4} = 1$$
• A point $1.5\text{ m}$ from one end ($x = 4$) has distance from origin:
$$x = 4 - 1.5 = 2.5\text{ m} = \frac{5}{2}\text{ m}$$
• Finding height $y$ at $x = 2.5$:
$$\frac{(2.5)^2}{16} + \frac{y^2}{4} = 1 \implies \frac{6.25}{16} + \frac{y^2}{4} = 1$$
$$\frac{y^2}{4} = 1 - \frac{6.25}{16} = \frac{9.75}{16}$$
$$y^2 = \frac{4 \times 9.75}{16} = \frac{9.75}{4} = 2.4375$$
$$y = \sqrt{2.4375} \approx \mathbf{1.56\text{ m}}$$

A rod of length $12\text{ cm}$ moves with its ends always touching the coordinate axes. Determine the equation of the locus of a point $P$ on the rod, which is $3\text{ cm}$ from the end in contact with the x-axis.
[4 Marks]
✅ CBSE Step-by-Step Solution
• Let $AB$ be the rod of length $12\text{ cm}$ with end $A(a, 0)$ on the x-axis and end $B(0, b)$ on the y-axis.
• In right triangle $OAB$:
$$a^2 + b^2 = 12^2 = 144 \quad \dots (1)$$
• Point $P(x, y)$ lies on $AB$ such that $AP = 3\text{ cm}$.
• Since total length $AB = 12\text{ cm}$, we have $PB = 12 - 3 = 9\text{ cm}$.
• Thus $P$ divides the segment $AB$ internally in the ratio $AP : PB = 3 : 9 = 1 : 3$.
• By section formula:
$$x = \frac{1(0) + 3(a)}{1 + 3} = \frac{3a}{4} \implies a = \frac{4x}{3}$$
$$y = \frac{1(b) + 3(0)}{1 + 3} = \frac{b}{4} \implies b = 4y$$
• Substituting $a$ and $b$ into $(1)$:
$$\left(\frac{4x}{3}\right)^2 + (4y)^2 = 144$$
$$\frac{16x^2}{9} + 16y^2 = 144$$
• Dividing throughout by $144$ ($16/144 = 1/9$):
$$\frac{x^2}{81} + \frac{y^2}{9} = 1$$
• Thus, the locus of point $P$ is an ellipse with equation $\mathbf{\frac{x^2}{81} + \frac{y^2}{9} = 1}$.
