Question 1
Exercise 4.1
Express the given complex number in the form $a + ib$: $(5i)\left(-\dfrac{3}{5}i\right)$.
[2 Marks]
✅ CBSE Step-by-Step Solution
• Multiply the numerical coefficients and the imaginary unit $i$:
$$(5i)\left(-\frac{3}{5}i\right) = 5 \times \left(-\frac{3}{5}\right) \times (i \times i) = -3 \times i^2$$
• Since $i^2 = -1$:
$$= -3 \times (-1) = 3$$
• Express in standard $a + ib$ form ($a = 3, b = 0$):
$$\mathbf{3 + 0i}$$

Question 2
Exercise 4.1
Express the given complex number in the form $a + ib$: $i^9 + i^{19}$.
[2 Marks]
✅ CBSE Step-by-Step Solution

Integral Powers of $i$: Since $i^4 = 1$, higher powers of $i$ are evaluated by dividing the exponent by 4.

• Evaluate $i^9$:
$$i^9 = i^{4 \times 2 + 1} = (i^4)^2 \times i = (1)^2 \times i = i$$
• Evaluate $i^{19}$:
$$i^{19} = i^{4 \times 4 + 3} = (i^4)^4 \times i^3 = (1)^4 \times (-i) = -i$$
• Add the two results:
$$i^9 + i^{19} = i + (-i) = 0$$
• Express in $a + ib$ form:
$$\mathbf{0 + 0i}$$

Question 3

[2 Marks]
✅ CBSE Step-by-Step Solution
• Write with positive exponent:
$$i^{-39} = \frac{1}{i^{39}}$$
• Divide 39 by 4: $39 = 4 \times 9 + 3$:
$$i^{39} = (i^4)^9 \times i^3 = (1)^9 \times (-i) = -i$$
• Substitute back and rationalize:
$$i^{-39} = \frac{1}{-i} = -\frac{1}{i} = -\frac{i}{i^2} = -\frac{i}{-1} = i$$
• In $a + ib$ form:
$$\mathbf{0 + 1i}$$

$$\text{Real part} = \frac{1 - 243}{27} = -\frac{242}{27}$$
$$\text{Imaginary part} = 1 - 27 = -26$$
$$\mathbf{-\frac{242}{27} - 26i}$$

Question 11
Exercise 4.1
Find the multiplicative inverse of the complex number: $4 - 3i$.
[2 Marks]
✅ CBSE Step-by-Step Solution

Multiplicative Inverse Formula: For $z = a + ib$, $z^{-1} = \dfrac{\bar{z}}{|z|^2} = \dfrac{a - ib}{a^2 + b^2}$.

• Given $z = 4 - 3i$:
$$\bar{z} = 4 + 3i$$
$$|z|^2 = 4^2 + (-3)^2 = 16 + 9 = 25$$
• Compute $z^{-1}$:
$$z^{-1} = \frac{\bar{z}}{|z|^2} = \frac{4 + 3i}{25} = \mathbf{\frac{4}{25} + \frac{3}{25}i}$$
Verification: $(4 - 3i)\left(\frac{4 + 3i}{25}\right) = \frac{16 - 9i^2}{25} = \frac{16 + 9}{25} = 1$.

$$\dfrac{(3 + i\sqrt{5})(3 - i\sqrt{5})}{(\sqrt{3} + \sqrt{2}i) - (\sqrt{3} - i\sqrt{2})}$$
[3 Marks]
✅ CBSE Step-by-Step Solution
• Simplify Numerator:

• In $a + ib$ form:
$$\mathbf{0 - \frac{7\sqrt{2}}{2}i}$$

Question 2

Solve the equation: $2x^2 + x + 1 = 0$.
[2 Marks]
✅ CBSE Step-by-Step Solution

Quadratic Formula: For $ax^2 + bx + c = 0$, $x = \dfrac{-b \pm \sqrt{D}}{2a}$, where discriminant $D = b^2 - 4ac$.

• Comparing with $ax^2 + bx + c = 0$: $a = 2, \, b = 1, \, c = 1$.
• Discriminant:
$$D = b^2 - 4ac = 1^2 - 4(2)(1) = 1 - 8 = -7 < 0$$
• Therefore, roots are complex conjugates:
$$\sqrt{D} = \sqrt{-7} = i\sqrt{7}$$
$$x = \frac{-1 \pm i\sqrt{7}}{2(2)} = \mathbf{\frac{-1 \pm i\sqrt{7}}{4}}$$

$$= -(1 + 3i - 3 - i) = -(-2 + 2i) = \mathbf{2 - 2i}$$

Question 2
Miscellaneous Exercise
For any two complex numbers $z_1$ and $z_2$, prove that $\text{Re}(z_1 z_2) = \text{Re } z_1 \text{ Re } z_2 - \text{Im } z_1 \text{ Im } z_2$.
[3 Marks]
✅ CBSE Step-by-Step Solution
• Let $z_1 = x_1 + iy_1$ and $z_2 = x_2 + iy_2$, where $x_1, x_2, y_1, y_2 \in \mathbb{R}$.
By definition:
$$\text{Re } z_1 = x_1, \quad \text{Im } z_1 = y_1$$
$$\text{Re } z_2 = x_2, \quad \text{Im } z_2 = y_2$$

• Multiply $z_1$ and $z_2$:
$$z_1 z_2 = (x_1 + iy_1)(x_2 + iy_2) = x_1 x_2 + ix_1 y_2 + iy_1 x_2 + i^2 y_1 y_2$$
Since $i^2 = -1$:
$$z_1 z_2 = (x_1 x_2 - y_1 y_2) + i(x_1 y_2 + x_2 y_1)$$

• Extract the Real part of the product:
$$\text{Re}(z_1 z_2) = x_1 x_2 - y_1 y_2$$
Substitute back $x_1 = \text{Re } z_1, x_2 = \text{Re } z_2, y_1 = \text{Im } z_1, y_2 = \text{Im } z_2$:
$$\mathbf{\text{Re}(z_1 z_2) = \text{Re } z_1 \text{ Re } z_2 - \text{Im } z_1 \text{ Im } z_2}$$
Hence proved.

Take modulus on both sides:
$$|x - iy| = \left|\sqrt{\frac{a - ib}{c - id}}\right| = \sqrt{\left|\frac{a - ib}{c - id}\right|} = \sqrt{\frac{|a - ib|}{|c - id|}}$$
• Since $|x - iy| = \sqrt{x^2 + y^2}$, $|a - ib| = \sqrt{a^2 + b^2}$, and $|c - id| = \sqrt{c^2 + d^2}$:
$$\sqrt{x^2 + y^2} = \sqrt{\frac{\sqrt{a^2 + b^2}}{\sqrt{c^2 + d^2}}} = \left(\frac{a^2 + b^2}{c^2 + d^2}\right)^{1/4}$$
• Raise both sides to the power 4:
$$\left(\sqrt{x^2 + y^2}\right)^4 = \left[\left(\frac{a^2 + b^2}{c^2 + d^2}\right)^{1/4}\right]^4$$
$$\mathbf{(x^2 + y^2)^2 = \frac{a^2 + b^2}{c^2 + d^2}}$$
Hence proved.

Question 10
Miscellaneous Exercise
If $(x + iy)^3 = u + iv$, then show that $\dfrac{u}{x} + \dfrac{v}{y} = 4(x^2 - y^2)$.
[3 Marks]
✅ CBSE Step-by-Step Solution
• Given: $(x + iy)^3 = u + iv$.

• Expand LHS using binomial formula $(a + b)^3 = a^3 + 3a^2 b + 3ab^2 + b^3$ with $a = x, b = iy$:
$$(x + iy)^3 = x^3 + 3x^2(iy) + 3x(iy)^2 + (iy)^3$$
$$= x^3 + 3ix^2 y + 3x(-y^2) - iy^3$$

$$u = x^3 - 3xy^2 = x(x^2 - 3y^2) \implies \mathbf{\frac{u}{x} = x^2 - 3y^2}$$

$$\frac{u}{x} + \frac{v}{y} = (x^2 - 3y^2) + (3x^2 - y^2) = 4x^2 - 4y^2 = \mathbf{4(x^2 - y^2)}$$

Question 11
Miscellaneous Exercise
If $\alpha$ and $\beta$ are different complex numbers with $|\beta| = 1$, then find $\left|\dfrac{\beta - \alpha}{1 - \bar{\alpha}\beta}\right|$.
[4 Marks]
✅ CBSE Step-by-Step Solution

Property: For any complex number $z$, $|z|^2 = z \bar{z}$.

• Let $E = \left|\dfrac{\beta - \alpha}{1 - \bar{\alpha}\beta}\right|$. Compute $E^2$:
$$E^2 = \left(\frac{\beta - \alpha}{1 - \bar{\alpha}\beta}\right) \overline{\left(\frac{\beta - \alpha}{1 - \bar{\alpha}\beta}\right)} = \left(\frac{\beta - \alpha}{1 - \bar{\alpha}\beta}\right) \left(\frac{\bar{\beta} - \bar{\alpha}}{1 - \alpha\bar{\beta}}\right)$$
• Expand Numerator:
$$(\beta - \alpha)(\bar{\beta} - \bar{\alpha}) = \beta\bar{\beta} - \beta\bar{\alpha} - \alpha\bar{\beta} + \alpha\bar{\alpha} = |\beta|^2 - \beta\bar{\alpha} - \alpha\bar{\beta} + |\alpha|^2$$
Since $|\beta| = 1 \implies |\beta|^2 = 1$:
$$\text{Numerator} = 1 - \beta\bar{\alpha} - \alpha\bar{\beta} + |\alpha|^2$$

• Expand Denominator:
$$(1 - \bar{\alpha}\beta)(1 - \alpha\bar{\beta}) = 1 - \alpha\bar{\beta} - \bar{\alpha}\beta + \alpha\bar{\alpha}\beta\bar{\beta}$$
Since $\alpha\bar{\alpha} = |\alpha|^2$ and $\beta\bar{\beta} = |\beta|^2 = 1$:
$$\text{Denominator} = 1 - \alpha\bar{\beta} - \bar{\alpha}\beta + |\alpha|^2(1) = 1 - \alpha\bar{\beta} - \bar{\alpha}\beta + |\alpha|^2$$

• Notice that $\text{Numerator} = \text{Denominator}$!
$$E^2 = \frac{1 - \beta\bar{\alpha} - \alpha\bar{\beta} + |\alpha|^2}{1 - \beta\bar{\alpha} - \alpha\bar{\beta} + |\alpha|^2} = 1$$
• Since modulus is always non-negative ($E \ge 0$):
$$\mathbf{E = \left|\frac{\beta - \alpha}{1 - \bar{\alpha}\beta}\right| = 1}$$
