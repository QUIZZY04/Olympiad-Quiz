NCERT Exercise 1.1: Sets Definition, Belongs to Symbol, Roster & Set-Builder Forms
Question 1
Exercise 1.1
Which of the following are sets? Justify your answer.
(i) The collection of all the months of a year beginning with the letter J.
(ii) The collection of ten most talented writers of India.
(iii) A team of eleven best-cricket batsmen of the world.
(iv) The collection of all boys in your class.
(v) The collection of all natural numbers less than 100.
(vi) A collection of novels written by the writer Munshi Prem Chand.
(vii) The collection of all even integers.
(viii) The collection of questions in this Chapter.
(ix) A collection of most dangerous animals of the world.
[3 Marks]
✅ CBSE Step-by-Step Solution

Concept Definition: A set is a well-defined collection of distinct objects. That means there must exist an unambiguous, universal rule to determine whether any given object belongs to the collection or not.

• (i) Months of a year beginning with 'J': {January, June, July}. The collection is well-defined and identical for everyone. It is a set.

• (ii) Ten most talented writers of India: The criterion "most talented" is subjective, vague, and varies from person to person. It is not a set.

• (iii) Team of eleven best-cricket batsmen of the world: The definition of "best batsmen" is subjective and non-measurable. It is not a set.

• (iv) Collection of all boys in your class: The membership is clearly defined, identifiable, and verifiable. It is a set.

• (v) Collection of all natural numbers less than 100: {1, 2, 3, ..., 99} is precisely determined. It is a set.

• (vi) Collection of novels written by Munshi Prem Chand: The exact bibliographic list of novels by Prem Chand is definite and historical. It is a set.

• (vii) Collection of all even integers: {..., −4, −2, 0, 2, 4, ...} is mathematically well-defined. It is a set.

• (viii) Collection of questions in this Chapter: Finite, numbered, and fixed in the textbook. It is a set.

• (ix) Collection of most dangerous animals of the world: "Dangerous" is subjective and depends on individual perspectives. It is not a set.

Exercise 1.1
Write the following sets in the set-builder form:
(i) {3, 6, 9, 12}
(ii) {2, 4, 8, 16, 32}
(iii) {5, 25, 125, 625}
(iv) {2, 4, 6, ...}

[3 Marks]
✅ CBSE Step-by-Step Solution

Set-Builder Form: Characterising the common property satisfied by all elements in the set.

• (i) {3, 6, 9, 12}: Multiples of 3 up to $3 \times 4$:
$$\mathbf{\{x : x = 3n, \, n \in \mathbb{N} \text{ and } 1 \le n \le 4\}}$$
• (ii) {2, 4, 8, 16, 32}: Powers of 2 from $2^1$ to $2^5$:
$$\mathbf{\{x : x = 2^n, \, n \in \mathbb{N} \text{ and } 1 \le n \le 5\}}$$
• (iii) {5, 25, 125, 625}: Powers of 5 from $5^1$ to $5^4$:
$$\mathbf{\{x : x = 5^n, \, n \in \mathbb{N} \text{ and } 1 \le n \le 4\}}$$
• (iv) {2, 4, 6, ...}: Set of even natural numbers:
$$\mathbf{\{x : x \text{ is an even natural number}\} \quad \text{or} \quad \{x : x = 2n, \, n \in \mathbb{N}\}}$$
• (v) {1, 4, 9, ..., 100}: Squares of natural numbers up to $10^2$ ($1^2, 2^2, ..., 10^2$):
$$\mathbf{\{x : x = n^2, \, n \in \mathbb{N} \text{ and } 1 \le n \le 10\}}$$

NCERT Exercise 1.2: Empty Set, Finite & Infinite Sets, Equal Sets
Question 1
Exercise 1.2
Which of the following are examples of the null set?
(i) Set of odd natural numbers divisible by 2.
(ii) Set of even prime numbers.
(iii) {x : x is a natural number, x < 5 and x > 7}.
(iv) {y : y is a point common to any two parallel lines}.
[2 Marks]
✅ CBSE Step-by-Step Solution

Definition: A set containing no elements is called the empty set, null set, or void set, denoted by $\phi$ or $\{\}$.

• (i) Odd natural numbers divisible by 2: By definition, no odd number is divisible by 2. The set contains no elements.
Hence, it is a null set.

• (ii) Set of even prime numbers: The number $2$ is an even prime number. So the set is $\{2\} \ne \phi$.
Hence, it is not a null set.

• (iii) {x : x ∈ N, x < 5 and x > 7}: No natural number can simultaneously be less than 5 and greater than 7.
Hence, it is a null set.

• (iv) Points common to two parallel lines: Parallel lines never intersect by definition; they have no points in common.
Hence, it is a null set.

Exercise 1.2
Which of the following sets are finite or infinite?
(i) The set of months of a year.
(ii) {1, 2, 3, ...}
(iii) {1, 2, 3, ..., 99, 100}
(iv) The set of positive integers greater than 100.
(v) The set of prime numbers less than 99.
[2.5 Marks]
✅ CBSE Step-by-Step Solution

Definitions: A set is finite if it contains a definite count of elements (or is empty). Otherwise, it is infinite.

• (i) Set of months of a year: Exactly 12 months. Definite count $\rightarrow$ Finite set.
• (ii) {1, 2, 3, ...}: Natural numbers continue indefinitely without bound $\rightarrow$ Infinite set.
• (iii) {1, 2, 3, ..., 99, 100}: Exactly 100 elements $\rightarrow$ Finite set.
• (iv) Positive integers greater than 100: {101, 102, 103, ...} has no upper bound $\rightarrow$ Infinite set.
• (v) Prime numbers less than 99: Primes {2, 3, 5, 7, ..., 97} is a definite count (25 primes) $\rightarrow$ Finite set.

Question 3
Exercise 1.2
State whether each of the following set is finite or infinite:
(i) The set of lines which are parallel to the x-axis.
(ii) The set of letters in the English alphabet.
(iii) The set of numbers which are multiple of 5.
(iv) The set of animals living on the earth.
(v) The set of circles passing through the origin (0,0).
[2.5 Marks]
✅ CBSE Step-by-Step Solution
• (i) Lines parallel to the x-axis: In the Cartesian plane, infinitely many horizontal lines $y = c$ (for every real $c$) can be drawn. $\rightarrow$ Infinite set.

• (ii) Letters in the English alphabet: Exactly 26 letters (A to Z). $\rightarrow$ Finite set.

• (iii) Numbers which are multiples of 5: {..., −15, −10, −5, 0, 5, 10, 15, ...} has no beginning or end. $\rightarrow$ Infinite set.

• (iv) Animals living on the earth: Although the number is extremely large, the count of living animals at any given instant is a finite whole number. $\rightarrow$ Finite set.

• (v) Circles passing through origin (0, 0): Circles with center $(h, k)$ and radius $r = \sqrt{h^2+k^2}$ can be drawn for any choice of center $(h, k) \in \mathbb{R}^2$. There are infinitely many such circles. $\rightarrow$ Infinite set.

Question 4
Exercise 1.2
In the following, state whether A = B or not:
(i) A = {a, b, c, d}, B = {d, c, b, a}
(ii) A = {4, 8, 12, 16}, B = {8, 4, 16, 18}
(iii) A = {2, 4, 6, 8, 10}, B = {x : x is positive even integer and x ≤ 10}
(iv) A = {x : x is a multiple of 10}, B = {10, 15, 20, 25, 30, ...}
[2 Marks]
✅ CBSE Step-by-Step Solution

Rule of Equality: Two sets $A$ and $B$ are equal ($A = B$) if and only if every element of $A$ is in $B$ and every element of $B$ is in $A$. Order of elements does not matter.

• (i) A = {a, b, c, d}, B = {d, c, b, a}: Both sets contain exactly the same four elements. Yes, A = B.

• (ii) A = {4, 8, 12, 16}, B = {8, 4, 16, 18}: $12 \in A$ but $12 \notin B$, and $18 \in B$ but $18 \notin A$. No, A ≠ B.

• (iii) A = {2, 4, 6, 8, 10}, B = {x : x is positive even integer and x ≤ 10}: The positive even integers $\le 10$ are $\{2, 4, 6, 8, 10\}$. Exactly identical. Yes, A = B.

• (iv) A = {10, 20, 30, 40, ...}, B = {10, 15, 20, 25, ...}: $15 \in B$ but $15 \notin A$ (since 15 is not a multiple of 10). No, A ≠ B.

Question 5
Exercise 1.2
Are the following pair of sets equal? Give reasons.
(i) A = {2, 3}, B = {x : x is solution of x² + 5x + 6 = 0}
(ii) A = {x : x is a letter in the word FOLLOW}, B = {y : y is a letter in the word WOLF}
[2 Marks]
✅ CBSE Step-by-Step Solution
• (i) Pair A = {2, 3} and B:
Solve quadratic equation: $x^2 + 5x + 6 = 0$
$\implies (x + 2)(x + 3) = 0 \implies x = -2 \text{ or } x = -3$.
Thus, $B = \{-2, -3\}$.
Since $2 \in A$ but $2 \notin B$, and $-2 \in B$ but $-2 \notin A$, A ≠ B.

• (ii) Pair A and B:
Letters in 'FOLLOW': $A = \{F, O, L, W\}$.
Letters in 'WOLF': $B = \{W, O, L, F\}$.
Since both sets contain precisely the same four elements ${F, O, L, W}$, A = B.

NCERT Exercise 1.3: Subsets, Proper Subsets, Power Sets, Intervals of Real Numbers, Universal Sets
Question 1
Exercise 1.3
Make correct statements by filling in the symbols ⊂ or ⊄ in the blank spaces:
(i) {2, 3, 4} ___ {1, 2, 3, 4, 5}
(ii) {a, b, c} ___ {b, c, d}
(iii) {x : x is a student of Class XI of your school} ___ {x : x is student of your school}
(iv) {x : x is a circle in the plane} ___ {x : x is a circle in the same plane with radius 1 unit}
(v) {x : x is a triangle in a plane} ___ {x : x is a rectangle in the plane}
(vi) {x : x is an equilateral triangle in a plane} ___ {x : x is a triangle in the same plane}
(vii) {x : x is an even natural number} ___ {x : x is an integer}
[3 Marks]
✅ CBSE Step-by-Step Solution

Subset Condition: $A \subset B$ if every element of $A$ is also an element of $B$. If at least one element of $A$ is not in $B$, then $A \not\subset B$.

• (i) {2, 3, 4} ⊂ {1, 2, 3, 4, 5}  (all elements 2, 3, 4 belong to the RHS)
• (ii) {a, b, c} ⊄ {b, c, d}  (element $a$ does not belong to RHS)
• (iii) {Student of Class XI} ⊂ {Student of your school}  (every Class XI student is a school student)
• (iv) {Circle in plane} ⊄ {Circle with radius 1 unit}  (a circle can have radius 2, 3, etc., not in RHS)
• (v) {Triangle in plane} ⊄ {Rectangle in plane}  (triangles are 3-sided, rectangles are 4-sided)
• (vi) {Equilateral triangle in plane} ⊂ {Triangle in same plane}  (every equilateral triangle is a triangle)
• (vii) {Even natural numbers} ⊂ {Integers}  ({2, 4, 6, ...} is a subset of {..., -2, -1, 0, 1, 2, ...})

Question 2
Exercise 1.3
Examine whether the following statements are true or false:
(i) {a, b} ⊄ {b, c, a}
(ii) {a, e} ⊂ {x : x is a vowel in English alphabet}
(iii) {1, 2, 3} ⊂ {1, 3, 5}
(iv) {a} ⊂ {a, b, c}
(v) {a} ∈ {a, b, c}
(vi) {x : x is an even natural number less than 6} ⊂ {x : x is a natural number which divides 36}
[3 Marks]
✅ CBSE Step-by-Step Solution
• (i) {a, b} ⊄ {b, c, a}: Both $a, b$ belong to ${b, c, a}$, so ${a, b} \subset \{b, c, a\}$. Hence, statement is False.

• (ii) {a, e} ⊂ {vowels}: English vowels are ${a, e, i, o, u}$. Since $a, e$ are vowels, the statement is True.

• (iii) {1, 2, 3} ⊂ {1, 3, 5}: The element $2 \in \{1, 2, 3\}$ but $2 \notin \{1, 3, 5\}$. Hence, statement is False.

• (iv) {a} ⊂ {a, b, c}: Element $a$ belongs to ${a, b, c}$. Hence, subset relation is True.

• (v) {a} ∈ {a, b, c}: The elements of ${a, b, c}$ are letters $a, b, c$, not the set ${a}$. Hence, statement is False ($a \in \{a, b, c\}$, but $\{a\} \notin \{a, b, c\}$).

• (vi) LHS: Even natural numbers less than 6 = ${2, 4}$.
RHS: Natural numbers dividing 36 = ${1, 2, 3, 4, 6, 9, 12, 18, 36}$.
Since $2 \in \text{RHS}$ and $4 \in \text{RHS}$, ${2, 4} \subset \text{RHS}$. Statement is True.

Question 3
Exercise 1.3
Let A = {1, 2, {3, 4}, 5}. Which of the following statements are incorrect and why?
(i) {3, 4} ⊂ A           (ii) {3, 4} ∈ A            (iii) {{3, 4}} ⊂ A
(iv) 1 ∈ A                 (v) 1 ⊂ A                   (vi) {1, 2, 5} ⊂ A
(vii) {1, 2, 5} ∈ A       (viii) {1, 2, 3} ⊂ A        (ix) Φ ∈ A
(x) Φ ⊂ A                  (xi) {Φ} ⊂ A
[4 Marks]
✅ CBSE Step-by-Step Solution

Key Concept: The elements of set $A$ are: $1$, $2$, the set ${3, 4}$, and $5$.

• (i) {3, 4} ⊂ A: Incorrect. ${3, 4}$ is an element of $A$, so ${3, 4} \in A$. For it to be a subset, its members 3 and 4 must belong to $A$, but $3 \notin A$ and $4 \notin A$.

• (ii) {3, 4} ∈ A: Correct. ${3, 4}$ is directly an element of $A$.

• (iii) {{3, 4}} ⊂ A: Correct. The element of this singleton set is ${3, 4}$, which is in $A$.

• (iv) 1 ∈ A: Correct. 1 is an element of $A$.

• (v) 1 ⊂ A: Incorrect. An element cannot be a subset; only a set enclosed in braces like ${1} \subset A$.

• (vi) {1, 2, 5} ⊂ A: Correct. Since $1, 2, 5 \in A$.

• (vii) {1, 2, 5} ∈ A: Incorrect. ${1, 2, 5}$ is a subset, not an element of $A$.

• (viii) {1, 2, 3} ⊂ A: Incorrect. $3$ is not an element of $A$ (it is inside ${3, 4}$).

• (ix) Φ ∈ A: Incorrect. $\phi$ is not an element listed inside $A$.

• (x) Φ ⊂ A: Correct. The empty set $\phi$ is a subset of every set.

• (xi) {Φ} ⊂ A: Incorrect. For ${\phi} \subset A$, we must have $\phi \in A$, which is false.

Question 4
Exercise 1.3
Write down all the subsets of the following sets:
(i) {a}
(ii) {a, b}
(iii) {1, 2, 3}
(iv) Φ
[2 Marks]
✅ CBSE Step-by-Step Solution

Theorem: A set containing $n$ elements has exactly $2^n$ subsets.

• (i) {a}: $n = 1 \implies 2^1 = 2$ subsets:
Φ, {a}
