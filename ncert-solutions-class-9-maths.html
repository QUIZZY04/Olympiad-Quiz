Exercise 1.1
Q1
Is zero a rational number? Can you write it in the form p/q, where p and q are integers and q ≠ 0?
1 Mark
✅ CBSE Standard Answer

Yes, zero is a rational number.

A rational number is any number that can be expressed in the form p/q, where p and q are integers and q ≠ 0. Zero can be written as:

0 = 0/1 = 0/2 = 0/3 = 0/(−5) etc.

In each case, p = 0 (an integer) and q ≠ 0 (a non-zero integer). Therefore zero fully satisfies the definition of a rational number. Hence, 0 is a rational number.

Note: The set of rational numbers includes all integers (since any integer n = n/1), all fractions p/q, and zero.

Q4
State whether the following statements are true or false. Give reasons: (i) Every natural number is a whole number. (ii) Every integer is a whole number. (iii) Every rational number is a whole number.
3 Marks
✅ CBSE Standard Answer

(i) TRUE. Natural numbers = {1, 2, 3, 4, …} and Whole numbers = {0, 1, 2, 3, 4, …}. Every natural number is included within the set of whole numbers. The set of natural numbers is a proper subset of whole numbers. The only difference is that 0 is a whole number but not a natural number.

(ii) FALSE. Integers include negative numbers: {…, −3, −2, −1, 0, 1, 2, 3, …}. Whole numbers only include {0, 1, 2, 3, …} — no negatives. Since negative integers (e.g., −1, −5) are NOT whole numbers, not every integer is a whole number. Counter-example: −3 is an integer but not a whole number.

(iii) FALSE. Rational numbers include fractions (e.g., 1/2, −3/4, 7/5) and negative numbers. Whole numbers = {0, 1, 2, 3, …}. Most rational numbers (fractions like 1/2, and all negative rationals) are NOT whole numbers. Counter-example: 3/4 is rational but NOT a whole number.

Exercise 1.2
Q1
State whether the following statements are true or false. Justify your answers. (i) Every irrational number is a real number. (ii) Every point on the number line is of the form √m, where m is a natural number. (iii) Every real number is an irrational number.
3 Marks
✅ CBSE Standard Answer

(i) TRUE. The set of real numbers is composed of both rational numbers and irrational numbers: Real Numbers = Rationals ∪ Irrationals. Since irrational numbers (like √2, √3, π, e) are all part of the real number system by definition, every irrational number is necessarily a real number.

(ii) FALSE. Every point on the number line represents a real number, but real numbers include negative numbers and fractions that cannot be expressed as √m (where m is natural). For instance, −2 cannot be written as √m for any natural m (since √m ≥ 0 always). Also, 1/2 = √(1/4) but 1/4 is not a natural number. Hence, the statement is false.

(iii) FALSE. Real numbers include BOTH rational and irrational numbers. Rational numbers such as 2, −3, 1/2, 0.75 are all real numbers but they are NOT irrational. For example, 5 is a real number, and 5 = 5/1 is rational — so it is not irrational. Therefore, not every real number is irrational.

Q2
Are the square roots of all positive integers irrational? If not, give an example of the square root of a number that is a rational number.
1 Mark
✅ CBSE Standard Answer

No. The square roots of all positive integers are NOT necessarily irrational.

When a positive integer is a perfect square, its square root is a rational number (in fact, a natural number). Examples:

  • √4 = 2 — rational (and a natural number)
  • √9 = 3 — rational
  • √16 = 4, √25 = 5, √100 = 10 — all rational

Only the square roots of non-perfect-square positive integers (like √2, √3, √5, √7, √10, …) are irrational — they have non-terminating, non-repeating decimal expansions.

Exercise 1.3
Q1
Write the following in decimal form and say what kind of decimal expansion each has: (i) 36/100 (ii) 1/11 (iii) 4⅛ (iv) 3/13 (v) 2/11 (vi) 329/400
3 Marks
✅ CBSE Standard Answer

(i) 36/100 = 0.36 — Terminating decimal. (Denominator 100 = 2² × 5², only prime factors 2 and 5.)

(ii) 1/11 = 0.090909… = 0.0̄9̄ — Non-terminating repeating decimal. Block "09" repeats indefinitely.

(iii) 4⅛ = 33/8 = 4.125 — Terminating decimal. (Denominator 8 = 2³, only prime factor 2.)

(iv) 3/13 = 0.230769230769… = 0.2̄3̄0̄7̄6̄9̄ — Non-terminating repeating decimal. Block "230769" repeats.

(v) 2/11 = 0.181818… = 0.1̄8̄ — Non-terminating repeating decimal. Block "18" repeats.

(vi) 329/400 = 0.8225 — Terminating decimal. (400 = 2⁴ × 5², only prime factors 2 and 5.)

Key rule: A rational number p/q (in lowest terms) has a terminating decimal if and only if the denominator q has no prime factors other than 2 and 5.

Exercise 1.5 — Rationalization & Laws of Exponents
Q1
Classify the following numbers as rational or irrational: (i) 2 − √5 (ii) (3 + √23) − √23 (iii) 2√7/7√7 (iv) 1/√2 (v) 2π
5 Marks
✅ CBSE Standard Answer

(i) 2 − √5: √5 is irrational. Difference of a rational number (2) and an irrational number (√5) is always irrational. → Irrational

(ii) (3 + √23) − √23 = 3: The irrational parts cancel. Result = 3, which is a rational number. → Rational

(iii) 2√7/7√7 = 2/7: The √7 in numerator and denominator cancel each other out. Result = 2/7, a rational number. → Rational

(iv) 1/√2: Since √2 is irrational, its reciprocal 1/√2 is also irrational. The decimal expansion of 1/√2 = 0.7071… is non-terminating and non-repeating. → Irrational

(v) 2π: π is a well-known irrational number. A non-zero rational number (2) multiplied by an irrational number (π) always gives an irrational result. → Irrational

Q5
Rationalise the denominators of the following: (i) 1/√7 (ii) 1/(√7 − √6) (iii) 1/(√5 + √2) (iv) 1/(√7 − 2)
4 Marks
✅ CBSE Standard Answer

(i) Multiply numerator and denominator by √7:

1/√7 × √7/√7 = √7/7

(ii) Multiply by conjugate (√7 + √6):

1/(√7−√6) × (√7+√6)/(√7+√6) = (√7+√6)/(7−6) = √7 + √6

(iii) Multiply by conjugate (√5 − √2):

1/(√5+√2) × (√5−√2)/(√5−√2) = (√5−√2)/(5−2) = (√5−√2)/3

(iv) Multiply by conjugate (√7 + 2):

1/(√7−2) × (√7+2)/(√7+2) = (√7+2)/(7−4) = (√7+2)/3

Q1. A school has a square garden with area 50 m². The principal wants to fence all four sides.
(a) Find the side length. Is it rational or irrational?
(b) Find the perimeter (total fencing needed).
(c) If fencing costs ₹200 per metre, find the total cost.

Q3. If a = 2 + √3, find a − 1/a. Is the result rational or irrational?
a = 2 + √3

a − 1/a = (2+√3) − (2−√3) = 2√3

Exercise 2.1
Q1
Which of the following expressions are polynomials in one variable, and which are not? State reasons: (i) 4x² − 3x + 7 (ii) y² + √2 (iii) 3√t + t√2 (iv) y + 2/y (v) x¹⁰ + y³ + t⁵⁰
5 Marks
✅ CBSE Standard Answer

A polynomial in one variable has only non-negative integer powers of that variable.

(i) 4x² − 3x + 7: Powers of x are 2, 1, 0 — all non-negative integers. → Polynomial in one variable x ✓

(ii) y² + √2: Power of y is 2 (non-negative integer); √2 is a constant (degree 0). → Polynomial in one variable y ✓

(iii) 3√t + t√2 = 3t^(1/2) + √2·t: The term 3√t = 3t^(1/2) has exponent 1/2, which is NOT a non-negative integer. → NOT a polynomial ✗

(iv) y + 2/y = y + 2y⁻¹: The term 2/y has exponent −1 (negative integer), which violates the polynomial condition. → NOT a polynomial ✗

(v) x¹⁰ + y³ + t⁵⁰: All exponents are non-negative integers, but there are three different variables (x, y, t). → NOT a polynomial in one variable (it is a polynomial in three variables) ✗

Q4
Find the zero of the polynomial in each case: (i) p(x) = x + 5 (ii) p(x) = x − 5 (iii) p(x) = 2x + 5 (iv) p(x) = 3x − 2 (v) p(x) = 3x (vi) p(x) = ax, a ≠ 0 (vii) p(x) = cx + d, c ≠ 0
4 Marks
✅ CBSE Standard Answer

A zero of a polynomial p(x) is a value of x for which p(x) = 0. We set p(x) = 0 and solve for x.

(i) x + 5 = 0 → x = −5

(ii) x − 5 = 0 → x = 5

(iii) 2x + 5 = 0 → 2x = −5 → x = −5/2

(iv) 3x − 2 = 0 → 3x = 2 → x = 2/3

(v) 3x = 0 → x = 0

(vi) ax = 0, a ≠ 0 → x = 0

(vii) cx + d = 0 → cx = −d → x = −d/c (the zero of any linear polynomial cx + d is −d/c)

Exercise 2.3 — Remainder Theorem
Q1
Find the remainder when x³ + 3x² + 3x + 1 is divided by: (i) x + 1 (ii) x − 1/2 (iii) x (iv) x + π (v) 5 + 2x
5 Marks
✅ CBSE Standard Answer

Let p(x) = x³ + 3x² + 3x + 1. Note: p(x) = (x + 1)³ — a perfect cube.

By the Remainder Theorem: when p(x) is divided by (x − a), remainder = p(a).

(i) x + 1 → a = −1:

p(−1) = (−1)³ + 3(−1)² + 3(−1) + 1 = −1 + 3 − 3 + 1 = 0

(ii) x − 1/2 → a = 1/2:

p(1/2) = 1/8 + 3/4 + 3/2 + 1 = 1/8 + 6/8 + 12/8 + 8/8 = 27/8

(iii) x → a = 0:

p(0) = 0 + 0 + 0 + 1 = 1

(iv) x + π → a = −π:

p(−π) = −π³ + 3π² − 3π + 1 = (1 − π)³

(v) 5 + 2x → a = −5/2:

p(−5/2) = −125/8 + 75/4 − 15/2 + 1 = −125/8 + 150/8 − 60/8 + 8/8 = −27/8

Exercise 2.4 — Factor Theorem
Q1
Determine which of the following polynomials has (x + 1) as a factor: (i) x³ + x² + x + 1 (ii) x⁴ + x³ + x² + x + 1 (iii) x⁴ + 3x³ + 3x² + x + 1 (iv) x³ − x² − (2 + √2)x + √2
4 Marks
✅ CBSE Standard Answer

Factor Theorem: (x + 1) is a factor of p(x) ⟺ p(−1) = 0.

(i) p(−1) = −1 + 1 − 1 + 1 = 0 → (x + 1) IS a factor ✓

(ii) p(−1) = 1 − 1 + 1 − 1 + 1 = 1 ≠ 0 → (x + 1) is NOT a factor ✗

(iii) p(−1) = 1 − 3 + 3 − 1 + 1 = 1 ≠ 0 → (x + 1) is NOT a factor ✗

(iv) p(−1) = −1 − 1 + (2 + √2) + √2 = −2 + 2 + √2 + √2 = 2√2 ≠ 0 → (x + 1) is NOT a factor ✗

Only polynomial (i) has (x + 1) as a factor. In fact, x³ + x² + x + 1 = x²(x + 1) + 1(x + 1) = (x + 1)(x² + 1).

Q16
If x + y + z = 0, show that x³ + y³ + z³ = 3xyz.
3 Marks
✅ CBSE Standard Answer

We know the algebraic identity:

x³ + y³ + z³ − 3xyz = (x + y + z)(x² + y² + z² − xy − yz − zx)

Given: x + y + z = 0. Substituting on the right side:

x³ + y³ + z³ − 3xyz = 0 × (x² + y² + z² − xy − yz − zx) = 0

Therefore:

x³ + y³ + z³ = 3xyz   ✓ Proved

NCERT Exercise 3.1 & 3.2 — CBSE Marking Scheme 2026-27

Exercise 3.1
Q1
How will you describe the position of a table lamp on your study table to another person?
2 Marks
✅ CBSE Standard Answer

To describe the position of a table lamp on a study table, we need two reference lines (axes) and two measurements (coordinates):

  1. Choose one corner of the table as the reference point (origin).
  2. Measure the horizontal distance from the origin along one edge — say, 25 cm. This is the x-coordinate (abscissa).
  3. Measure the perpendicular distance from the opposite edge — say, 30 cm. This is the y-coordinate (ordinate).
  4. The position is described as the ordered pair (25 cm, 30 cm).

This is the fundamental idea of the Cartesian coordinate system: any point in a plane is uniquely identified by an ordered pair (x, y) measured from a fixed origin along two perpendicular axes.

This method was introduced by René Descartes and forms the basis of Coordinate Geometry, which connects algebra and geometry.

✅ CBSE Standard Answer

(i) The horizontal line is called the x-axis (also called abscissa axis) and the vertical line is called the y-axis (also called ordinate axis). Together, they are referred to as the coordinate axes.

  • First Quadrant (I): x > 0 and y > 0 (both positive)
  • Second Quadrant (II): x < 0 and y > 0 (x negative, y positive)
  • Third Quadrant (III): x < 0 and y < 0 (both negative)
  • Fourth Quadrant (IV): x > 0 and y < 0 (x positive, y negative)

(iii) The x-axis and y-axis intersect at the Origin, denoted by O. Its coordinates are (0, 0).

Exercise 4.2
Q1
Which one of the following options is true, and why? y = 3x + 5 has (i) a unique solution (ii) only two solutions (iii) infinitely many solutions
2 Marks
✅ CBSE Standard Answer

Option (iii): Infinitely many solutions — This is true.

Reason: A linear equation in two variables like y = 3x + 5 has infinitely many solutions. For every real value assigned to x, there is exactly one corresponding value of y, giving a solution pair (x, y). Since x can be any real number, there are infinitely many such pairs.

NCERT Exercise 5.1 & 5.2 — CBSE Marking Scheme 2026-27

Exercise 5.1
Q1
Which of the following statements are true and which are false? Give reasons: (i) Only one line can pass through a single point. (ii) There are an infinite number of lines which pass through two distinct points. (iii) A terminated line can be produced indefinitely on both sides. (iv) If two circles are equal, then their radii are equal. (v) In the given figure, if AB = PQ and PQ = XY, then AB = XY.
5 Marks
✅ CBSE Standard Answer

(i) FALSE. Infinitely many lines can pass through a single point. According to Euclid's postulates, a unique line passes through two distinct points — not just one. Through any single given point, we can draw lines in all possible directions.

(ii) FALSE. According to Euclid's first postulate: "A straight line may be drawn from any one point to any other point." This unique line through two distinct points is exactly ONE, not infinite. It is impossible to draw two different straight lines through the same two points.

(iii) TRUE. This is Euclid's second postulate: "A terminated line can be produced indefinitely." A terminated line (line segment) can be extended infinitely in both directions, making it a full straight line.

(iv) TRUE. Two circles are equal if and only if they completely coincide (superimpose on each other), which happens only when their radii are identical. This follows from Euclid's fourth axiom: "Things which coincide with one another are equal to one another."

(v) TRUE. By Euclid's first axiom: "Things which are equal to the same thing are equal to one another." AB = PQ and PQ = XY. Since both AB and XY are equal to the same thing PQ, it follows that AB = XY. (This is the transitive property of equality.)

Exercise 5.2
Q1
How would you rewrite Euclid's fifth postulate so that it would be easier to understand?
3 Marks
✅ CBSE Standard Answer

Original Euclid's Fifth Postulate: "If a straight line falling on two straight lines makes the interior angles on the same side of it taken together less than two right angles, then the two straight lines, if produced indefinitely, meet on that side on which the sum of angles is less than two right angles."

Simplified / Equivalent Version (Playfair's Axiom):

"For every line l and for every point P not lying on l, there exists a unique line m passing through P and parallel to l."

Key Consequences of the Fifth Postulate:

  • Two distinct lines cannot be parallel to each other AND intersect (they are either parallel OR they meet at exactly one point).
  • If a transversal intersects two parallel lines, the co-interior (same-side interior) angles are supplementary (sum = 180°).
  • The angle sum of a triangle is exactly 180° in Euclidean geometry.

This postulate distinguishes Euclidean geometry from non-Euclidean geometries (e.g., Spherical geometry, where no parallel lines exist; Hyperbolic geometry, where infinitely many parallels exist).
