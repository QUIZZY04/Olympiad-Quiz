Chapter 1: What's in a Name?

Letter Counting, Name Grids, Number Names & Comparing Quantities | CBSE Session 2026–27

Core Pedagogical Competencies & Concepts
  • Counting letters in names and organizing data into frequency tables.
  • Comparing lengths of names: identifying longest and shortest names.
  • Finding names starting or ending with the same letter.
  • Representing quantities using tally marks and bar-like grid representations.

All Textbook Exercises & In-Text Tasks (22 Questions)

Q1 Textbook Exercise • Letter Counting
Write down the names of four of your classmates. Count the number of letters in each name. Which name is the longest, which is the shortest, and what is the difference between the two?
[3 Marks]
✅ Step-by-Step Solution & Working
Step-by-Step Solution:
1. Suppose we choose 4 classmates: Ravi, Ananya, Aarav, and Dharmendra.
2. Counting letters in each:
• Ravi: R-A-V-I = 4 letters
• Ananya: A-N-A-N-Y-A = 6 letters
• Aarav: A-A-R-A-V = 5 letters
• Dharmendra: D-H-A-R-M-E-N-D-R-A = 10 letters
3. Longest name: Dharmendra (10 letters)
4. Shortest name: Ravi (4 letters)
5. Difference: 10 - 4 = 6 letters.
CBSE Step-by-Step Marking Scheme
Correct letter count for all 4 names 1.5 M
Identifying longest, shortest, and difference 1.5 M
Q2 Classroom Activity • Alphabet Hunt
In a class of 20 children, 5 names start with the letter 'A', 3 with 'R', 4 with 'S', and 8 with other letters. How many names start with 'A', 'R', or 'S' altogether? What fraction of names start with 'A'?
[3 Marks]
✅ Step-by-Step Solution & Working
Given:
• Total children = 20
• Names starting with 'A' = 5
• Names starting with 'R' = 3
• Names starting with 'S' = 4

Calculation:
• Total names starting with 'A', 'R', or 'S' = 5 + 3 + 4 = 12 names.
• Fraction of names starting with 'A' = 5 out of 20 = 5/20 = 1/4 (one-fourth).
CBSE Step-by-Step Marking Scheme
Correct addition of name categories (5+3+4 = 12) 1.5 M
Correct fraction identification (5/20 = 1/4) 1.5 M

Q4 Animal Team Game • Comparing Length of Names
In the Animal Team Game, the captain of Team 1 has the longest name and the captain of Team 2 has the shortest name. Given the list of animals: Elephant (8 letters), Ox (2 letters), Tiger (5 letters), and Deer (4 letters):
(a) Who is the captain of Team 1 and Team 2?
(b) Can you name an animal with an even longer name than Team 1's captain?
[3 Marks]
✅ Step-by-Step Solution & Working
Step-by-Step Solution:
(a) Identifying Captains:
• Elephant: E-L-E-P-H-A-N-T = 8 letters (Longest)
• Ox: O-X = 2 letters (Shortest)
• Team 1 Captain: Elephant (8 letters)
• Team 2 Captain: Ox (2 letters)

(b) Animal with Longer Name:
• Yes! Crocodile (C-R-O-C-O-D-I-L-E = 9 letters) or Hippopotamus (H-I-P-P-O-P-O-T-A-M-U-S = 12 letters) has a longer name than Elephant.
CBSE Step-by-Step Marking Scheme
Correct identification of Elephant and Ox as captains 1.5 M
Valid example of animal with >8 letters (e.g., Crocodile/Hippopotamus) 1.5 M
Q5 Textbook Discussion • Comparing Names
Mahesh and Kartik are comparing the number of letters in their names.
(a) Count the letters in 'Mahesh' and 'Kartik'.
(b) Who has a longer name, or are they equal?
(c) If their friend 'Venkatanarasimha' joins them, how many more letters does this name have than Mahesh?
[3 Marks]
✅ Step-by-Step Solution & Working
Step-by-Step Solution:
(a) Counting Letters:
• M-A-H-E-S-H = 6 letters
• K-A-R-T-I-K = 6 letters

(b) Comparison:
• Both names have exactly 6 letters. Neither is longer; they are equal in length.

(c) Extra Letters:
• V-E-N-K-A-T-A-N-A-R-A-S-I-M-H-A = 16 letters.
• Difference = 16 - 6 = 10 more letters.
CBSE Step-by-Step Marking Scheme
Correct counts for Mahesh (6) and Kartik (6) 1.0 M
Correct equality conclusion 1.0 M
Correct difference calculation (16 - 6 = 10) 1.0 M

Q7 Number Names Mountain Climb • Spelling Length
In the number climb from 1 to 99, count the letters in the spelling of each number name (do not count hyphens):
(a) 'Seventy-eight'
(b) 'Ninety-three'
(c) 'Twenty-two'
Which of these three has the maximum number of letters, and which has the minimum?
[3 Marks]
✅ Step-by-Step Solution & Working
Letter Counting:
• (a) Seventy-eight: S-E-V-E-N-T-Y (7) + E-I-G-H-T (5) = 12 letters.
• (b) Ninety-three: N-I-N-E-T-Y (6) + T-H-R-E-E (5) = 11 letters.
• (c) Twenty-two: T-W-E-N-T-Y (6) + T-W-O (3) = 9 letters.

Conclusion:
• Maximum letters: Seventy-eight (12 letters)
• Minimum letters: Twenty-two (9 letters).
CBSE Step-by-Step Marking Scheme
Accurate letter count for all three number names (12, 11, 9) 1.5 M
Correct identification of maximum (78) and minimum (22) 1.5 M

Q11 Dot Grid Name Art • Symmetry in Letters
Look at the letters in the name 'M O M':
(a) How many letters are in this name?
(b) Which of these letters have vertical symmetry?
(c) What happens if you read the name backwards from right to left?
[3 Marks]
✅ Step-by-Step Solution & Working
Analysis of 'M O M':
• (a) Letter count: M-O-M = 3 letters.
• (b) Vertical symmetry: Both 'M' and 'O' have vertical lines of symmetry. So all letters in MOM have vertical symmetry.
• (c) Reading backwards: M - O - M spelt backwards is still MOM. A word that reads the same forwards and backwards is called a palindrome.
CBSE Step-by-Step Marking Scheme
Correct letter count (3) 1.0 M
Identifying vertical symmetry of M and O 1.0 M
Noting palindrome property (reads same backwards) 1.0 M

Q18 Review Exercise • True or False on Names
State True or False with reasons:
(a) 'RAMESH' and 'SURESH' have the same number of letters.
(b) 'INDIA' has more consonants than vowels.
(c) The word 'SUN' has the same number of letters as the number 3.
[3 Marks]
✅ Step-by-Step Solution & Working
Verification:
• (a) True. R-A-M-E-S-H has 6 letters and S-U-R-E-S-H has 6 letters.
• (b) False. In 'INDIA', vowels are I, I, A (3 vowels) and consonants are N, D (2 consonants). Vowels are more than consonants.
• (c) True. S-U-N has 3 letters, which equals the number 3.
CBSE Step-by-Step Marking Scheme
Part (a) True with reason (6 = 6) 1.0 M
Part (b) False with reason (3 vowels > 2 consonants) 1.0 M
Part (c) True with reason (3 letters = 3) 1.0 M
Q19 HOTS • Secret Code by Name Length
A teacher created a code where each student's secret passcode is the number of letters in their first name multiplied by 10.
(a) What is the passcode for 'KAVITA'?
(b) What is the passcode for 'OM'?
(c) If a student has passcode 80, how many letters are in that student's name? Give an example of such a name.
[3 Marks]
✅ Step-by-Step Solution & Working
Decoding the Passcode:
• (a) KAVITA: 6 letters → Passcode = 6 × 10 = 60.
• (b) OM: 2 letters → Passcode = 2 × 10 = 20.
• (c) Student with passcode 80:
Letters = 80 ÷ 10 = 8 letters.
Example name: PRIYANKA or PRASHANT (8 letters).
CBSE Step-by-Step Marking Scheme
Part (a) 60 1.0 M
Part (b) 20 1.0 M
Part (c) 8 letters with valid 8-letter name 1.0 M

Library Badge Code Challenge

The school librarian gives each child a library code based on their name: 10 points for each letter in the first name plus 5 points for each vowel (A, E, I, O, U).

Analytical Task: Calculate the total library badge score for 'KAVITA'. How many vowels are in her name, and what is her final code value?
Evaluation & Model Answer:
1. Name: K-A-V-I-T-A contains 6 letters.
2. Letter points = 6 × 10 = 60 points.
3. Vowels in KAVITA: A, I, A = 3 vowels.
4. Vowel bonus points = 3 × 5 = 15 points.
5. Total library badge score = 60 + 15 = 75 points.
Rubric: 1M letter points + 1M vowel identification + 1M final calculation.
