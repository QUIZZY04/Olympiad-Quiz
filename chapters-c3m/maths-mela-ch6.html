Chapter 6: House of Hundreds – I

Place Value (Hundreds, Tens, Ones), 3-Digit Numbers, Abacus & Expansion | CBSE Session 2026–27

Core Pedagogical Competencies & Concepts
  • Building 3-digit numbers using 100-flats, 10-rods, and 1-units (Dienes blocks).
  • Reading and representing numbers up to 500 on a 3-spike abacus.
  • Writing standard form, expanded form, and number words up to 500.
  • Ordering and comparing 3-digit numbers using greater than (>) and less than (<).

Q1 Place Value Exploration • 3-Digit Numbers
What is the place value and face value of the underlined digit in each: (a) 472, (b) 309, (c) 258?
[3 Marks]
✅ Step-by-Step Solution & Working
Values:
• (a) 472: The digit 7 is in the Tens place.
Face Value = 7, Place Value = 7 × 10 = 70.

• (b) 309: The digit 3 is in the Hundreds place.
Face Value = 3, Place Value = 3 × 100 = 300.

• (c) 258: The digit 8 is in the Ones place.
Face Value = 8, Place Value = 8 × 1 = 8.
CBSE Step-by-Step Marking Scheme
Correct face values for all three digits 1.5 M
Correct place values according to positional weight 1.5 M

Q3 Forming Numbers • Greatest & Smallest
Using the digits 4, 0, and 7 without repeating any digit: (a) Write the greatest 3-digit number. (b) Write the smallest 3-digit number. Explain why 0 cannot be in the hundreds place.
[3 Marks]
✅ Step-by-Step Solution & Working
Analysis:
• (a) Greatest 3-digit number: Arrange digits in descending order → 740.
• (b) Smallest 3-digit number: We cannot put 0 at the start because 047 is only a 2-digit number (47). The smallest non-zero digit is 4, followed by 0, then 7 → 407.
• Explanation: Placing 0 in the hundreds place means there are zero hundreds, reducing the number to tens and ones (a 2-digit number).
CBSE Step-by-Step Marking Scheme
Correct greatest number (740) 1.0 M
Correct smallest number (407) 1.0 M
Valid mathematical reason regarding leading zero 1.0 M
Q4 Arrow Cards Assembly • Place Value
Using arrow cards for Hundreds, Tens, and Ones:
(a) Assemble the cards 400, 70, and 6. What 3-digit number is formed?
(b) Write the number formed in words.
(c) If you replace the card '70' with '30', what is the new number, and how much did the value decrease?
[3 Marks]
✅ Step-by-Step Solution & Working
Step-by-Step Solution:
(a) Arrow Card Assembly:
• 400 + 70 + 6 = 476.

(b) Number Name:
• Four hundred seventy-six.

(c) Value Decrease:
• New number = 400 + 30 + 6 = 436.
• Decrease in value = 476 - 436 = 40 (or 70 - 30 = 40).
CBSE Step-by-Step Marking Scheme
Correct number formation (476) 1.0 M
Correct number name in words 1.0 M
Correct new number (436) and decrease (40) 1.0 M
Q5 Abacus Representation • 3-Digit Numbers
An abacus has three spikes: Hundreds (H), Tens (T), and Ones (O).
(a) If there are 3 green beads on H, 5 yellow beads on T, and 2 blue beads on O, write the number.
(b) How many total beads are on the abacus?
(c) If 2 beads are removed from the Tens spike and added to the Hundreds spike, what new number is formed?
[3 Marks]
✅ Step-by-Step Solution & Working
Step-by-Step Solution:
(a) Number on Abacus:
• Hundreds = 3, Tens = 5, Ones = 2.
• Number = 352.

(b) Total Beads:
• 3 + 5 + 2 = 10 beads.

(c) New Number:
• New Hundreds = 3 + 2 = 5 Hundreds.
• New Tens = 5 - 2 = 3 Tens.
• Ones remain = 2 Ones.
• New number = 532.
CBSE Step-by-Step Marking Scheme
Correct initial number (352) 1.0 M
Correct total beads (10) 1.0 M
Correct transformation to new number (532) 1.0 M

Q12 HOTS & Puzzle • Logical Reasoning
Mathematical Riddle from House of Hundreds – I: I am a number. Double me, then add 10, and you will get 120. What number am I? Verify your answer.
[3 Marks]
✅ Step-by-Step Solution & Working
Step-by-Step Algebraic Verification:
1. Let the unknown number be N.
2. Condition: (2 × N) + 10 = 120.
3. Subtract 10 from both sides: 2 × N = 110.
4. Divide by 2: N = 55.
5. Verification: Double of 55 is 110, plus 10 gives 120. Correct!
CBSE Step-by-Step Marking Scheme
Formulating statement: 2N + 10 = 120 1.5 M
Final number N = 55 with verification 1.5 M

🌟 NEP 2020 Competency-Based Case Study

School Tree Plantation Drive

During Van Mahotsav, Class 3 students planted saplings: Section A planted 148 saplings, Section B planted 175 saplings, and Section C planted 126 saplings.

Analytical Task: How many saplings did the three sections plant altogether? If the school target was 500 saplings, how many more are needed?
Evaluation & Model Answer:
1. Total saplings planted = 148 + 175 + 126.
• 148 + 175 = 323.
• 323 + 126 = 449 saplings.
2. Total planted = 449 saplings.
3. Target = 500 saplings.
• Shortfall = 500 - 449 = 51 saplings.
Rubric: 1.5M addition of 3 numbers + 1.5M subtraction from 500 target.
