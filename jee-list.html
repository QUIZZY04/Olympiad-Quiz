  • Marking Scheme for Single Correct Option:
    • Full Marks: +3 If only the correct option is chosen.
    • Zero Marks: 0 If none of the options is chosen (i.e. the question is unanswered).
    • Negative Marks: -1 In all other cases.
  • Marking Scheme for Multiple Correct Options:
    • Full Marks: +4 If only (all) the correct option(s) is(are) chosen.
    • Partial Marks: +1 For each correct option chosen, provided NO incorrect option is chosen.
    • Zero Marks: 0 If none of the options is chosen (i.e. the question is unanswered).
    • Negative Marks: -2 In all other cases (e.g., if any incorrect option is selected).
