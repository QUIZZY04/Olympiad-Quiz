Q2
Express y in terms of x for 3x + 2y = 12. Use this to check whether (2, 3) is a solution.
3 Marks
✓ Suggested Step-by-Step Solution
3x + 2y = 12 → 2y = 12 − 3x → y = (12 − 3x)/2
At x = 2: y = (12 − 6)/2 = 6/2 = 3
Since y = 3 when x = 2, the point (2, 3) satisfies the equation. ✓ It is a solution.

📝 Case Study & Real-Life Modeling
Student Startup Economics (Break-Even Line): A student startup manufactures recycled notebooks. Their fixed monthly operational cost is ₹3,000, and variable production cost is ₹25 per notebook. They sell each notebook for ₹65.
(a) Write the total cost equation C(x) and total revenue equation R(x) for x notebooks.
(b) Set up the linear equation in two variables for the break-even point where Revenue = Cost.
(c) How many notebooks must they sell to break even?
(a) Total Cost: C(x) = 25x + 3000. Total Revenue: R(x) = 65x.
(b) Break-even occurs when R(x) = C(x) ⟹ 65x = 25x + 3000 ⟹ 40x - 3000 = 0 (or 40x - y = 0 where y is cost/revenue).
(c) Solving: 40x = 3000 ⟹ x = 3000 / 40 = 75 notebooks. They must sell 75 notebooks to break even.
🧠 HOTS & Assertion-Reasoning
Assertion (A): The graph of every linear equation ax + by + c = 0 (where a and b are not both zero) is a straight line.
Reason (R): Every point (x, y) whose coordinates satisfy the equation lies on this line, and every point on the line satisfies the equation.
Choose: (a) Both A and R are true and R is the correct explanation. (b) Both A and R are true, but R is not correct explanation. (c) A is true, R is false. (d) A is false, R is true.
Correct Choice: (a) Both A and R are true and R is the correct explanation.
Explanation: A linear algebraic relation between two variables defines a 1-dimensional manifold with constant slope, corresponding to Euclid's geometric definition of a straight line.
