Exercise Set 4.1 — Standard Algebraic Identities
Q1
Expand using appropriate identity: (i) (x + 4)²  (ii) (2a − 3b)²  (iii) (x + 5)(x − 5)
3 Marks
✓ Suggested Step-by-Step Solution
(i) (x+4)² = x² + 2(x)(4) + 4² = x² + 8x + 16 [Using (a+b)² = a²+2ab+b²]
(ii) (2a−3b)² = (2a)² − 2(2a)(3b) + (3b)² = 4a² − 12ab + 9b²
(iii) (x+5)(x−5) = x² − 5² = x² − 25 [Using (a+b)(a−b) = a²−b²]
Suggested Marks Distribution

Q2

(iii) 103 × 97 = (100+3)(100−3) = 100² − 3² = 10000 − 9 = 9991

Exercise Set 4.2 — Factorisation using Identities
Q1
Factorise: (i) x² − 9  (ii) 4a² − 25b²  (iii) x² + 6x + 9  (iv) 9y² − 12y + 4
4 Marks
✓ Suggested Step-by-Step Solution
(i) x² − 9 = x² − 3² = (x+3)(x−3)
(ii) 4a² − 25b² = (2a)² − (5b)² = (2a+5b)(2a−5b)
(iii) x² + 6x + 9 = x² + 2(x)(3) + 3² = (x+3)²
(iv) 9y² − 12y + 4 = (3y)² − 2(3y)(2) + 2² = (3y−2)²
Suggested Marks Distribution
Each correct factorisation with identity (×4)1 Mark each
Q2
If x + 1/x = 5, find the value of x² + 1/x².
3 Marks
✓ Suggested Step-by-Step Solution
Given: x + 1/x = 5
Step 1: Square both sides: (x + 1/x)² = 5² = 25
Step 2: x² + 2(x)(1/x) + 1/x² = 25 → x² + 2 + 1/x² = 25
Step 3: x² + 1/x² = 25 − 2 = 23
Suggested Marks Distribution
Squaring both sides correctly1 Mark
Expanding using identity1 Mark
Final answer x² + 1/x² = 231 Mark

📝 Case Study & Real-Life Modeling
Architectural Space Planning & Identities: An architect designs a modular pavilion with square base of side (x + y). Later, a storage corridor of width 2 units is attached so total dimensions become (x + y + 2) by (x + y - 2).
(a) Use standard algebraic identity to find the expanded expression for the area.
(b) If x + y = 10 meters, find the total floor area.
(c) Verify your answer using numerical substitution.
(a) Using identity (A + B)(A - B) = A² - B² where A = (x + y) and B = 2:
Area = (x + y)² - 2² = x² + 2xy + y² - 4.
(b) If x + y = 10 m: Area = (10)² - 4 = 100 - 4 = 96 m².
(c) Direct substitution: (10 + 2)(10 - 2) = 12 × 8 = 96 m². The results match perfectly.
🧠 HOTS & Assertion-Reasoning
Assertion (A): If a + b + c = 0, then a³ + b³ + c³ = 3abc.
Reason (R): a³ + b³ + c³ - 3abc = (a + b + c)(a² + b² + c² - ab - bc - ca).
Choose: (a) Both A and R are true and R is the correct explanation. (b) Both A and R are true, but R is not correct explanation. (c) A is true, R is false. (d) A is false, R is true.
Correct Choice: (a) Both A and R are true and R is the correct explanation.
Explanation: If (a + b + c) = 0, then the product (a + b + c)(a² + b² + c² - ab - bc - ca) vanishes to 0. Transposing -3abc yields a³ + b³ + c³ = 3abc.
