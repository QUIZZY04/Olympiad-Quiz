Exercise 4.1
Q1
The cost of a notebook is twice the cost of a pen. Write a linear equation in two variables to represent this statement. (Take the cost of a notebook to be ₹ x and that of a pen to be ₹ y).
2 Marks
✅ CBSE Standard Answer
Step 1: Define variables:
Let the cost of one notebook be ₹ x.
Let the cost of one pen be ₹ y.
Step 2: Formulate algebraic equation:
According to the given condition:
Cost of notebook = 2 × (Cost of pen)
x = 2y
Step 3: Standard form ax + by + c = 0:
Subtracting 2y from both sides:
x - 2y + 0 = 0 (or 1·x - 2·y + 0 = 0).

Final Answer: The linear equation in two variables is x - 2y = 0.

Q2
Express the following linear equations in the form ax + by + c = 0 and indicate the values of a, b and c in each case:
(i) 2x + 3y = 9.35̄
(ii) x - y/5 - 10 = 0
(iii) -2x + 3y = 6
(iv) x = 3y
(v) 2x = -5y
(vi) 3x + 2 = 0
(vii) y - 2 = 0
(viii) 5 = 2x
4 Marks
✅ CBSE Standard Answer

Concept: The general standard form of a linear equation in two variables is ax + by + c = 0, where a, b, c are real numbers and a, b are not both zero (a² + b² ≠ 0).

(i) 2x + 3y = 9.35̄:
Rearranging: 2x + 3y - 9.35̄ = 0.
Comparing with ax + by + c = 0: a = 2, b = 3, c = -9.35̄.
(ii) x - y/5 - 10 = 0:
Can be written as: 1·x + (-1/5)·y + (-10) = 0.
Comparing: a = 1, b = -1/5 (or -0.2), c = -10.
(iii) -2x + 3y = 6:
Rearranging: -2x + 3y - 6 = 0 (or 2x - 3y + 6 = 0).
Comparing: a = -2, b = 3, c = -6 (or a = 2, b = -3, c = 6).
(iv) x = 3y:
Rearranging: 1·x - 3·y + 0 = 0.
Comparing: a = 1, b = -3, c = 0.
(v) 2x = -5y:
Rearranging: 2x + 5y + 0 = 0.
Comparing: a = 2, b = 5, c = 0.
(vi) 3x + 2 = 0:
Writing in two variables: 3x + 0·y + 2 = 0.
Comparing: a = 3, b = 0, c = 2.
(vii) y - 2 = 0:
Writing in two variables: 0·x + 1·y - 2 = 0.
Comparing: a = 0, b = 1, c = -2.
(viii) 5 = 2x:
Rearranging: 2x + 0·y - 5 = 0 (or -2x + 0·y + 5 = 0).
Comparing: a = 2, b = 0, c = -5.

Exercise 4.2
Q1
Which one of the following options is true, and why?
y = 3x + 5 has:
(i) a unique solution,
(ii) only two solutions,
(iii) infinitely many solutions.
2 Marks
✅ CBSE Standard Answer

Answer: (iii) infinitely many solutions.

Reason / Justification:
1. The given equation y = 3x + 5 is a linear equation in two variables.
2. Geometrically, every linear equation in two variables represents a straight line in the Cartesian plane.
3. Every point (x, y) lying on this straight line is a solution of the equation.
4. For any arbitrarily chosen real value of x, there exists a corresponding unique real value of y = 3x + 5.
Since there are infinitely many real values that x can take, there exist infinitely many pairs (x, y) that satisfy the equation.

Q2
Write four solutions for each of the following equations:
(i) 2x + y = 7
(ii) πx + y = 9
(iii) x = 4y
3 Marks
✅ CBSE Standard Answer
(i) 2x + y = 7 ⟹ y = 7 - 2x:
• If x = 0: y = 7 - 0 = 7 ⟹ Solution 1: (0, 7)
• If x = 1: y = 7 - 2(1) = 5 ⟹ Solution 2: (1, 5)
• If x = 2: y = 7 - 2(2) = 3 ⟹ Solution 3: (2, 3)
• If x = 3: y = 7 - 2(3) = 1 ⟹ Solution 4: (3, 1)
(ii) πx + y = 9 ⟹ y = 9 - πx:
• If x = 0: y = 9 - 0 = 9 ⟹ Solution 1: (0, 9)
• If x = 1: y = 9 - π(1) = 9 - π ⟹ Solution 2: (1, 9 - π)
• If x = 2: y = 9 - 2π ⟹ Solution 3: (2, 9 - 2π)
• If x = 9/π: y = 9 - π(9/π) = 0 ⟹ Solution 4: (9/π, 0)
(iii) x = 4y:
• If y = 0: x = 4(0) = 0 ⟹ Solution 1: (0, 0)
• If y = 1: x = 4(1) = 4 ⟹ Solution 2: (4, 1)
• If y = 2: x = 4(2) = 8 ⟹ Solution 3: (8, 2)
• If y = -1: x = 4(-1) = -4 ⟹ Solution 4: (-4, -1)

Q3
Check which of the following are solutions of the equation x - 2y = 4 and which are not:
(i) (0, 2)
(ii) (2, 0)
(iii) (4, 0)
(iv) (√2, 4√2)
(v) (1, 1)
3 Marks
✅ CBSE Standard Answer

Verification Principle: A point (x, y) is a solution if substituting its coordinates into LHS (x - 2y) yields RHS (4).

(i) (0, 2): LHS = 0 - 2(2) = 0 - 4 = -4 ≠ 4 (RHS).
⟹ (0, 2) is NOT a solution.

(ii) (2, 0): LHS = 2 - 2(0) = 2 - 0 = 2 ≠ 4 (RHS).
⟹ (2, 0) is NOT a solution.

(iii) (4, 0): LHS = 4 - 2(0) = 4 - 0 = 4 = RHS.
⟹ (4, 0) IS a solution.

(iv) (√2, 4√2): LHS = √2 - 2(4√2) = √2 - 8√2 = -7√2 ≠ 4 (RHS).
⟹ (√2, 4√2) is NOT a solution.

(v) (1, 1): LHS = 1 - 2(1) = 1 - 2 = -1 ≠ 4 (RHS).
⟹ (1, 1) is NOT a solution.

Q4
Find the value of k, if x = 2, y = 1 is a solution of the equation 2x + 3y = k.
2 Marks
✅ CBSE Standard Answer
Given:
Equation: 2x + 3y = k.
Given solution: x = 2 and y = 1.
Step-by-step Evaluation:
Since (2, 1) is a solution, it must satisfy the equation:
2(2) + 3(1) = k
4 + 3 = k
k = 7

Final Answer: The value of k is 7.

📝 Case Study Question
Auto-Rickshaw Fare Structure: In a city, the auto-rickshaw fare consists of a fixed charge of ₹ 25 for the first kilometer and ₹ 12 for each subsequent kilometer. Let the total distance covered be x km and total fare paid be ₹ y.
(a) Write a linear equation in two variables representing this relation.
(b) Find the fare paid for a ride of 15 km.
(c) If a passenger paid ₹ 205, what distance did they travel?
(a) For first km fare is ₹ 25, remaining distance is (x - 1) km at ₹ 12/km.
Total fare y = 25 + 12(x - 1) = 25 + 12x - 12 = 12x + 13.
Linear equation in standard form: 12x - y + 13 = 0.
(b) For x = 15 km: y = 12(15) + 13 = 180 + 13 = ₹ 193.
(c) When y = 205: 12x + 13 = 205 ⟹ 12x = 192 ⟹ x = 16 km.
🧠 HOTS
HOTS Problem: The graph of linear equation 2x + 3y = 12 cuts the x-axis at point P and the y-axis at point Q. Find the coordinates of P and Q, and calculate the area of the triangle formed by this line with the coordinate axes.
1. At x-axis, y = 0 ⟹ 2x + 0 = 12 ⟹ x = 6. So P(6, 0).
2. At y-axis, x = 0 ⟹ 0 + 3y = 12 ⟹ y = 4. So Q(0, 4).
3. Triangle OPQ is right-angled at origin O(0,0) with base OP = 6 units and height OQ = 4 units.
Area of ΔOPQ = 1/2 × Base × Height = 1/2 × 6 × 4 = 12 square units.
