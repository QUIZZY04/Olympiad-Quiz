Exercise 3.1
Q1
How will you describe the position of a table lamp on your study table to another person?
2 Marks
✅ CBSE Standard Answer

Method (CBSE Standard):

To uniquely specify the position of the table lamp on a rectangular study table, we consider the tabletop as a plane and use two mutually perpendicular reference lines:
  1. Choose any one corner of the tabletop as the reference point (origin, O).
  2. Let the shorter edge of the table passing through O represent the y-axis (vertical reference line) and the longer edge represent the x-axis (horizontal reference line).
  3. Measure the perpendicular distance of the lamp from the longer edge (y-coordinate) — say, 30 cm.
  4. Measure the perpendicular distance of the lamp from the shorter edge (x-coordinate) — say, 25 cm.
  5. Now, the exact location of the table lamp is uniquely given by the ordered pair (25, 30) (or (30, 25) depending on which edge is designated as the x-axis).

Mathematical Principle: This illustrates the fundamental concept of the Cartesian Coordinate System introduced by René Descartes: any point in a two-dimensional plane is uniquely determined by an ordered pair of numbers (x, y) representing perpendicular distances from two fixed perpendicular axes.

Q2
(Street Plan): A city has two main roads which cross each other at the centre of the city. These two roads are along the North-South direction and East-West direction. All other streets of the city run parallel to these roads and are 200 m apart. There are 5 streets in each direction. Using 1 cm = 200 m, draw a model of the city on your notebook. Represent the roads/streets by single lines.
There are many cross-streets in your model. A particular cross-street is made by two streets, one running in the North-South direction and another in the East-West direction. Each cross-street is referred to in the following manner: If the 2nd street running in the North-South direction and 5th in the East-West direction meet at some crossing, then we will call this cross-street (2, 5). Using this convention, find:
(i) How many cross-streets can be referred to as (4, 3)?
(ii) How many cross-streets can be referred to as (3, 4)?
3 Marks
✅ CBSE Standard Answer

Representation and Analysis:

Model Formulation:
• Let the East-West main road be the horizontal line (x-axis) and North-South main road be the vertical line (y-axis). The intersection is origin (0, 0).
• 5 streets running North-South are vertical lines x = 1, 2, 3, 4, 5.
• 5 streets running East-West are horizontal lines y = 1, 2, 3, 4, 5.
• A cross-street is designated by the ordered pair (Street_{NS}, Street_{EW}).
(i) How many cross-streets can be referred to as (4, 3)?
The cross-street (4, 3) is formed by the intersection of the 4th North-South street and the 3rd East-West street.
Since two distinct straight lines intersect at exactly one point, there is only one unique cross-street referred to as (4, 3).
(ii) How many cross-streets can be referred to as (3, 4)?
The cross-street (3, 4) is formed by the intersection of the 3rd North-South street and the 4th East-West street.
By the same principle of intersection of two unique lines, there is only one unique cross-street referred to as (3, 4).
Note: The cross-streets (4, 3) and (3, 4) are distinct points because coordinates in the Cartesian plane form an ordered pair where order matters ((a, b) ≠ (b, a) when a ≠ b).

Exercise 3.2
Q1
Write the answer of each of the following questions:
(i) What is the name of horizontal and the vertical lines drawn to determine the position of any point in the Cartesian plane?
(ii) What is the name of each part of the plane formed by these two lines?
(iii) Write the name of the point where these two lines intersect.
3 Marks
✅ CBSE Standard Answer
(i) Name of the horizontal and vertical lines:
• The horizontal reference line is called the x-axis.
• The vertical reference line is called the y-axis.
Together, they are termed the coordinate axes.
(ii) Name of each part of the plane formed by these two lines:
The coordinate axes divide the Cartesian plane into four equal regions called Quadrants:
• Quadrant I: (+x, +y)
• Quadrant II: (-x, +y)
• Quadrant III: (-x, -y)
• Quadrant IV: (+x, -y)
(iii) Point where the two lines intersect:
The point of intersection of the x-axis and y-axis is called the Origin, denoted by the letter O with coordinates (0, 0).

Exercise 3.3 (Plotting Points in the Cartesian Plane)
Q1
In which quadrant or on which axis do each of the points (-2, 4), (3, -1), (-1, 0), (1, 2) and (-3, -5) lie? Verify your answer by locating them on the Cartesian plane.
3 Marks
✅ CBSE Standard Answer

Rule of Signs for Quadrants:
• Quadrant I: x > 0, y > 0 (+, +)
• Quadrant II: x < 0, y > 0 (-, +)
• Quadrant III: x < 0, y < 0 (-, -)
• Quadrant IV: x > 0, y < 0 (+, -)
• On x-axis: y = 0; On y-axis: x = 0

Analysis of given points:
1. Point (-2, 4): Here x = -2 < 0 (negative) and y = 4 > 0 (positive).
⟹ Lies in Quadrant II.

2. Point (3, -1): Here x = 3 > 0 (positive) and y = -1 < 0 (negative).
⟹ Lies in Quadrant IV.

3. Point (-1, 0): Here x = -1 and y = 0.
⟹ Since y-coordinate is 0, it lies on the negative x-axis.

4. Point (1, 2): Here x = 1 > 0 (positive) and y = 2 > 0 (positive).
⟹ Lies in Quadrant I.

5. Point (-3, -5): Here x = -3 < 0 (negative) and y = -5 < 0 (negative).
⟹ Lies in Quadrant III.

📝 Case Study Question
Robotics & GPS Navigation: A warehouse automated guided vehicle (AGV) moves on a flat grid floor. Its docking station is at origin O(0, 0). It moves to pickup point P(3, 4), then to drop-off point Q(-2, 4), and then to recharging point R(-2, -3).
(a) In which quadrant does pickup point P lie?
(b) What is the distance between pickup point P(3, 4) and drop-off point Q(-2, 4)?
(c) Describe the path segment from Q(-2, 4) to R(-2, -3) in relation to the axes.
(a) Point P(3, 4) has both coordinates positive (x > 0, y > 0), so it lies in Quadrant I.
(b) Both P and Q have the same y-coordinate (y = 4). Therefore, the distance between them is horizontal: |3 - (-2)| = |3 + 2| = 5 units.
(c) Both Q and R have the same x-coordinate (x = -2). Thus the line segment QR is parallel to the y-axis (vertical path) of length |4 - (-3)| = 7 units.
🧠 HOTS
Problem: Three vertices of a rectangle ABCD are A(3, 1), B(-3, 1), and C(-3, -3). Plot these points, find the coordinates of the fourth vertex D, and calculate the area of the rectangle.
1. Length AB = |3 - (-3)| = 6 units (horizontal along y=1).
2. Breadth BC = |1 - (-3)| = 4 units (vertical along x=-3).
3. For rectangle ABCD, vertex D must have the same x-coordinate as A (x = 3) and same y-coordinate as C (y = -3).
⟹ Coordinates of D are (3, -3).
4. Area of rectangle ABCD = Length × Breadth = 6 × 4 = 24 square units.
