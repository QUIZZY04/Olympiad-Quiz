Express 0.̄3̄ (0.333...) as a fraction in simplest form.
3 Marks
✓ Suggested Step-by-Step Solution
Let x = 0.3333...
Step 1: Multiply both sides by 10: 10x = 3.3333...
Step 2: Subtract: 10x − x = 3.333... − 0.333... → 9x = 3
Step 3: x = 3/9 = 1/3

Q3
Show that √2 is irrational.
4 Marks
✓ Suggested Step-by-Step Solution

Proof by contradiction:

Assume √2 is rational. Then √2 = p/q where p, q are integers, q ≠ 0, and HCF(p, q) = 1.
Step 1: Squaring both sides: 2 = p²/q² → p² = 2q². So p² is even → p is even.
Step 2: Let p = 2m. Then (2m)² = 2q² → 4m² = 2q² → q² = 2m². So q² is even → q is even.
Contradiction: Both p and q are even, so HCF(p,q) ≥ 2. But HCF(p,q) = 1. This contradicts our assumption.

Conclusion: √2 is irrational.

📝 Case Study & Real-Life Modeling
Precision Engineering & Real Number Expansions: A precision laser cutting machine works with tolerances measured in rational fractions and irrational square roots. An engineer models a component with dimension d = 3.142857142857... mm and diagonal D = √8 mm.
(a) Express d in p/q form.
(b) State whether diagonal D is rational or irrational and find its simplest radical form.
(c) Is the sum d + D rational or irrational?
(a) d has a 6-digit repeating block: 3.142857... = 3 + 142857/999999 = 3 + 1/7 = 22/7 mm.
(b) D = √8 = √(4 × 2) = 2√2 mm. Since 2 is a non-square integer, √2 is irrational, so D is irrational.
(c) d is rational and D is irrational. The sum of a rational and an irrational number is always irrational. Therefore, d + D is irrational.
🧠 HOTS & Assertion-Reasoning
Assertion (A): Between any two distinct rational numbers, there exist infinitely many rational and irrational numbers.
Reason (R): The set of real numbers satisfies the completeness and density property on the number line.
Choose: (a) Both A and R are true and R is the correct explanation. (b) Both A and R are true, but R is not correct explanation. (c) A is true, R is false. (d) A is false, R is true.
Correct Choice: (a) Both A and R are true and R is the correct explanation.
Explanation: Density property ensures that for any a < b, the arithmetic mean (a+b)/2 provides an intermediate rational number, which can be repeated indefinitely. The real number continuum guarantees uncountably many numbers between any interval.
