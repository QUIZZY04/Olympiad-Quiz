Exercise Set 2.1 — Polynomials and Linear Expressions
Q1
Which of the following are polynomials? (i) 2x + 3  (ii) x² − 5  (iii) 3/x + 1  (iv) √x + 2  (v) 7
5 Marks
✓ CBSE Standard Answer

A polynomial has non-negative integer exponents for all variables.

(i) 2x + 3: Exponent of x is 1. Yes, polynomial (linear).
(ii) x² − 5: Exponent is 2. Yes, polynomial (quadratic).
(iii) 3/x + 1: Written as 3x⁻¹ + 1; exponent is −1 (negative). Not a polynomial.
(iv) √x + 2: Written as x¹∕²; exponent is 1/2 (fraction). Not a polynomial.
(v) 7: Constant = 7x⁰; exponent 0. Yes, polynomial (constant).

Q2
What does the graph of a linear polynomial always look like? How many zeros can it have?
2 Marks
✓ CBSE Standard Answer

The graph of a linear polynomial p(x) = ax + b (where a ≠ 0) is always a straight line.

A linear polynomial has exactly one zero — the x-coordinate of the point where the line crosses the x-axis (i.e., where y = 0).

📝 Case Study & Real-Life Modeling
App-Based Cab Fare Modeling (Linear Polynomials): In a metropolitan city, a cab aggregator charges a fixed base booking fee of ₹40 plus ₹15 per kilometer traveled. Let x denote the distance in kilometers and C(x) denote the total fare.
(a) Formulate the fare as a linear polynomial C(x).
(b) Find the fare for a trip of 12 km.
(c) Find the zero of the polynomial C(x) and state whether it has physical significance.
(a) Linear polynomial: C(x) = 15x + 40 (degree 1).
(b) For x = 12 km: C(12) = 15(12) + 40 = 180 + 40 = ₹220.
(c) Zero of C(x): 15x + 40 = 0 ⟹ 15x = -40 ⟹ x = -40/15 = -8/3 ≈ -2.67 km. Since distance cannot be negative, this zero has mathematical validity but no physical significance for a real cab ride.
🧠 HOTS & Assertion-Reasoning
Assertion (A): Every linear polynomial in one variable ax + b (where a ≠ 0) has exactly one unique zero.
Reason (R): A polynomial of degree n can have at most n distinct real zeros, and a linear polynomial has degree 1.
Choose: (a) Both A and R are true and R is the correct explanation. (b) Both A and R are true but R is not the correct explanation. (c) A is true, R is false. (d) A is false, R is true.
Correct Choice: (a) Both A and R are true and R is the correct explanation.
Explanation: Setting ax + b = 0 with a ≠ 0 yields x = -b/a. Since a and b are fixed constants, -b/a is unique. This is directly substantiated by the Fundamental Theorem of Algebra (Reason R).
