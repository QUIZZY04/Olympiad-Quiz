Exercise 2.1
Q1
Which of the following expressions are polynomials in one variable and which are not? State reasons for your answer:
(i) 4x² - 3x + 7
(ii) y² + √2
(iii) 3√t + t√2
(iv) y + 2/y
(v) x¹⁰ + y³ + t⁵⁰
3 Marks
✅ CBSE Standard Answer

Definition of Polynomial in One Variable: An algebraic expression in variable x is a polynomial if all exponents of the variable are whole numbers (0, 1, 2, 3, ...) and only a single variable is present.

(i) 4x² - 3x + 7:
The powers of variable x are 2, 1, and 0 (for constant 7). All powers are whole numbers and only one variable x is present.
Answer: Yes, it is a polynomial in one variable (x).
(ii) y² + √2:
The power of variable y is 2, which is a whole number. The constant √2 is a real number.
Answer: Yes, it is a polynomial in one variable (y).
(iii) 3√t + t√2:
Here 3√t = 3t^(1/2). The exponent of t is 1/2, which is not a whole number.
Answer: No, it is not a polynomial because exponent 1/2 is not a whole number.
(iv) y + 2/y:
Rewriting: y + 2y⁻¹. The exponent of the second term is -1, which is an integer but not a whole number.
Answer: No, it is not a polynomial because exponent -1 is not a whole number.
(v) x¹⁰ + y³ + t⁵⁰:
All exponents (10, 3, 50) are whole numbers, so it is a polynomial, but it contains three different variables (x, y, t).
Answer: No, it is not a polynomial in one variable (it is a polynomial in three variables).

(ii) 2 - x² + x³:
Term containing x² is -1 · x².

Coefficient of x² = π/2
(iv) √2x - 1:
There is no term containing x². We can rewrite the expression as 0 · x² + √2x - 1.
Coefficient of x² = 0

(iii) 5t - √7
(iv) 3
2 Marks
✅ CBSE Standard Answer

Degree = 3 (Cubic polynomial)

The variable t has exponent 1 (5t¹).
Degree = 1 (Linear polynomial)
(iv) 3:
3 is a non-zero constant polynomial, which can be written as 3x⁰.
Degree = 0 (Constant polynomial)

Q1
Find the value of the polynomial 5x - 4x² + 3 at:
(i) x = 0
(ii) x = -1
(iii) x = 2
3 Marks
✅ CBSE Standard Answer

Let p(x) = 5x - 4x² + 3 = -4x² + 5x + 3.

(i) At x = 0:
p(0) = 5(0) - 4(0)² + 3 = 0 - 0 + 3 = 3.
Answer: 3
(ii) At x = -1:
p(-1) = 5(-1) - 4(-1)² + 3 = -5 - 4(1) + 3 = -5 - 4 + 3 = -9 + 3 = -6.
Answer: -6
(iii) At x = 2:
p(2) = 5(2) - 4(2)² + 3 = 10 - 4(4) + 3 = 10 - 16 + 3 = -3.
Answer: -3

Q3
Verify whether the following are zeroes of the polynomial, indicated against them:
(i) p(x) = 3x + 1, x = -1/3
(ii) p(x) = 5x - π, x = 4/5
(iii) p(x) = x² - 1, x = 1, -1
(iv) p(x) = (x + 1)(x - 2), x = -1, 2
(v) p(x) = x², x = 0
(vi) p(x) = lx + m, x = -m/l
(vii) p(x) = 3x² - 1, x = -1/√3, 2/√3
(viii) p(x) = 2x + 1, x = 1/2
4 Marks
✅ CBSE Standard Answer

Principle: A real number c is a zero of polynomial p(x) if and only if p(c) = 0.

(i) p(-1/3) = 3(-1/3) + 1 = -1 + 1 = 0 ⟹ Yes, x = -1/3 is a zero.
(ii) p(4/5) = 5(4/5) - π = 4 - π ≠ 0 ⟹ No, x = 4/5 is not a zero.
(iii) p(1) = 1² - 1 = 0 and p(-1) = (-1)² - 1 = 1 - 1 = 0 ⟹ Yes, both 1 and -1 are zeroes.
(iv) p(-1) = (-1+1)(-1-2) = 0(-3) = 0 and p(2) = (2+1)(2-2) = 3(0) = 0 ⟹ Yes, both -1 and 2 are zeroes.
(v) p(0) = 0² = 0 ⟹ Yes, x = 0 is a zero.
(vi) p(-m/l) = l(-m/l) + m = -m + m = 0 ⟹ Yes, x = -m/l is a zero.
(vii) For x = -1/√3: p(-1/√3) = 3(-1/√3)² - 1 = 3(1/3) - 1 = 1 - 1 = 0 (Zero).
For x = 2/√3: p(2/√3) = 3(2/√3)² - 1 = 3(4/3) - 1 = 4 - 1 = 3 ≠ 0 (Not a zero).
(viii) p(1/2) = 2(1/2) + 1 = 1 + 1 = 2 ≠ 0 ⟹ No, x = 1/2 is not a zero.

Exercise 2.3 (Factor Theorem & Factorisation)
Q1
Determine which of the following polynomials has (x + 1) a factor:
(i) x³ + x² + x + 1
(ii) x⁴ + x³ + x² + x + 1
(iii) x⁴ + 3x³ + 3x² + x + 1
(iv) x³ - x² - (2 + √2)x + √2
4 Marks
✅ CBSE Standard Answer

Factor Theorem: (x + 1) is a factor of p(x) if and only if p(-1) = 0 (since zero of x + 1 = 0 is x = -1).

(i) p(x) = x³ + x² + x + 1:
p(-1) = (-1)³ + (-1)² + (-1) + 1 = -1 + 1 - 1 + 1 = 0.
Since p(-1) = 0, (x + 1) is a factor.
(ii) p(x) = x⁴ + x³ + x² + x + 1:
p(-1) = (-1)⁴ + (-1)³ + (-1)² + (-1) + 1 = 1 - 1 + 1 - 1 + 1 = 1 ≠ 0.
Since p(-1) ≠ 0, (x + 1) is not a factor.
(iii) p(x) = x⁴ + 3x³ + 3x² + x + 1:
p(-1) = (-1)⁴ + 3(-1)³ + 3(-1)² + (-1) + 1 = 1 - 3 + 3 - 1 + 1 = 1 ≠ 0.
Since p(-1) ≠ 0, (x + 1) is not a factor.
(iv) p(x) = x³ - x² - (2 + √2)x + √2:
p(-1) = (-1)³ - (-1)² - (2 + √2)(-1) + √2
= -1 - 1 + (2 + √2) + √2 = -2 + 2 + 2√2 = 2√2 ≠ 0.
Since p(-1) = 2√2 ≠ 0, (x + 1) is not a factor.

p(1) = 1² + 1 + k = 0 ⟹ 2 + k = 0 ⟹ k = -2.

Answer: k = √2 - 1

p(1) = k(1)² - 3(1) + k = 0 ⟹ k - 3 + k = 0 ⟹ 2k - 3 = 0 ⟹ 2k = 3 ⟹ k = 3/2.
Answer: k = 3/2

Q4
Factorise by splitting the middle term:
(i) 12x² - 7x + 1
(ii) 2x² + 7x + 3
(iii) 6x² + 5x - 6
(iv) 3x² - x - 4
4 Marks
✅ CBSE Standard Answer

Method: For quadratic ax² + bx + c, find two numbers p and q such that p + q = b and p × q = ac.

(i) 12x² - 7x + 1:
Here a × c = 12 × 1 = 12 and b = -7. Two numbers with product 12 and sum -7 are -3 and -4.
12x² - 4x - 3x + 1 = 4x(3x - 1) - 1(3x - 1) = (3x - 1)(4x - 1).
Answer: (3x - 1)(4x - 1)
(ii) 2x² + 7x + 3:
Here a × c = 2 × 3 = 6 and b = 7. Two numbers with product 6 and sum 7 are 6 and 1.
2x² + 6x + x + 3 = 2x(x + 3) + 1(x + 3) = (x + 3)(2x + 1).
Answer: (x + 3)(2x + 1)
(iii) 6x² + 5x - 6:
Here a × c = 6 × (-6) = -36 and b = 5. Numbers: 9 and -4 (9 × (-4) = -36, 9 + (-4) = 5).
6x² + 9x - 4x - 6 = 3x(2x + 3) - 2(2x + 3) = (2x + 3)(3x - 2).
Answer: (2x + 3)(3x - 2)
(iv) 3x² - x - 4:
Here a × c = 3 × (-4) = -12 and b = -1. Numbers: -4 and 3.
3x² + 3x - 4x - 4 = 3x(x + 1) - 4(x + 1) = (x + 1)(3x - 4).
Answer: (x + 1)(3x - 4)

Q5
Factorise cubic polynomials:
(i) x³ - 2x² - x + 2
(ii) x³ - 3x² - 9x - 5
(iii) x³ + 13x² + 32x + 20
(iv) 2y³ + y² - 2y - 1
5 Marks
✅ CBSE Standard Answer
(i) x³ - 2x² - x + 2:
Grouping terms: x²(x - 2) - 1(x - 2) = (x - 2)(x² - 1) = (x - 2)(x - 1)(x + 1).
Answer: (x - 1)(x + 1)(x - 2)
(ii) p(x) = x³ - 3x² - 9x - 5:
Factors of constant term -5 are ±1, ±5.
Test x = -1: p(-1) = (-1)³ - 3(-1)² - 9(-1) - 5 = -1 - 3 + 9 - 5 = 0. So (x + 1) is a factor.
Dividing p(x) by (x + 1):
x³ - 3x² - 9x - 5 = (x + 1)(x² - 4x - 5).
Factorising quadratic: x² - 4x - 5 = (x - 5)(x + 1).
Answer: (x + 1)²(x - 5)
(iii) p(x) = x³ + 13x² + 32x + 20:
Factors of 20 are ±1, ±2, ±4, ±5, ±10, ±20. Since all coefficients are positive, trial roots must be negative.
Test x = -1: p(-1) = -1 + 13 - 32 + 20 = 0. So (x + 1) is a factor.
Dividing by (x + 1): quotient is x² + 12x + 20.
Factorising: x² + 12x + 20 = (x + 2)(x + 10).
Answer: (x + 1)(x + 2)(x + 10)
(iv) 2y³ + y² - 2y - 1:
Grouping terms: y²(2y + 1) - 1(2y + 1) = (2y + 1)(y² - 1) = (2y + 1)(y - 1)(y + 1).
Answer: (2y + 1)(y - 1)(y + 1)

⚡ Assertion & Reason
Assertion (A): The polynomial p(x) = x⁴ - 16 has exactly two real zeroes.
Reason (R): A polynomial of degree n can have at most n zeroes.
Choose: (a) Both A and R are true and R is the correct explanation of A. (b) Both A and R are true but R is not the correct explanation of A. (c) A is true, R is false. (d) A is false, R is true.
Answer: (b) Both A and R are true but R is not the correct explanation of A.
Explanation: x⁴ - 16 = (x² - 4)(x² + 4) = (x - 2)(x + 2)(x² + 4). Real zeroes are x = 2 and x = -2 (since x² + 4 = 0 gives no real roots). So (A) is true. Reason (R) is a standard theorem and true, but it doesn't explain why specifically two are real.
