Exercise Set 8.1 — Arithmetic Progressions
Q1
Identify whether the following are APs. If yes, find the common difference: (i) 2, 5, 8, 11, ...  (ii) 1, 4, 9, 16, ...  (iii) 10, 7, 4, 1, ...
3 Marks
✓ Suggested Step-by-Step Solution
(i) 2, 5, 8, 11: Differences = 3, 3, 3 (constant). Yes, AP. Common difference d = 3
(ii) 1, 4, 9, 16: Differences = 3, 5, 7 (not constant). Not an AP.
(iii) 10, 7, 4, 1: Differences = −3, −3, −3 (constant). Yes, AP. Common difference d = −3

Q1
A savings plan starts with ₹500 in month 1 and increases by ₹200 each month. How much will be saved in month 12? What is the total savings over 12 months?
4 Marks
✓ Suggested Step-by-Step Solution
a = 500, d = 200, n = 12.
Month 12: a₁₂ = 500 + (12−1)×200 = 500 + 2200 = ₹2700
Total savings: S₁₂ = (12/2)[2×500 + 11×200] = 6[1000 + 2200] = 6×3200 = ₹19,200

📝 Case Study & Real-Life Modeling
Solar Energy Deployment Trends (Sequences): A clean energy initiative installs 120 rooftop solar units in Month 1. Due to increased subsidies, they install 25 additional units each consecutive month (145 in Month 2, 170 in Month 3, and so on).
(a) Identify the type of sequence and state its first term a and common difference d.
(b) How many solar units will be installed in Month 12?
(c) Find the total number of solar units installed during the first year (12 months).
(a) It forms an Arithmetic Progression (AP) with first term a = 120 and common difference d = 25.
(b) Month 12: a₁₂ = a + (12 - 1)d = 120 + 11(25) = 120 + 275 = 395 units.
(c) Total units in year 1: S₁₂ = (12/2)[2a + (12 - 1)d] = 6[2(120) + 275] = 6[240 + 275] = 6 × 515 = 3,090 solar units.
🧠 HOTS & Assertion-Reasoning
Assertion (A): The n-th term of any Arithmetic Progression is a linear expression in n of the form an = pn + q.
Reason (R): In an AP, an = a + (n - 1)d = dn + (a - d), where the coefficient of n is the common difference d.
Choose: (a) Both A and R are true and R is the correct explanation. (b) Both A and R are true, but R is not correct explanation. (c) A is true, R is false. (d) A is false, R is true.
Correct Choice: (a) Both A and R are true and R is the correct explanation.
Explanation: Expanding an = a + (n-1)d yields dn + (a-d). Here d and (a-d) are constants, making an a linear polynomial in n.
