  • The countdown timer at the top right of screen will display the remaining time available for you to complete the examination. When the timer reaches zero, the examination will end by itself.
  • There are multiple types of questions: Single Correct Option, Multiple Correct Options, and Numerical Value Type.
  • Marking Scheme for Single Correct Option:
    • Full Marks: +3 If only the correct option is chosen.
    • Zero Marks: 0 If none of the options is chosen (i.e. the question is unanswered).
    • Negative Marks: -1 In all other cases.
  • Marking Scheme for Multiple Correct Options:
    • Full Marks: +4 If only (all) the correct option(s) is(are) chosen.
    • Partial Marks: +1 For each correct option chosen, provided NO incorrect option is chosen.
    • Zero Marks: 0 If none of the options is chosen (i.e. the question is unanswered).
    • Negative Marks: -2 In all other cases (e.g., if any incorrect option is selected).
  • Marking Scheme for Numerical Value Type:
    • Full Marks: +3 If the entered numerical value is correct.
    • Zero Marks: 0 If unanswered or incorrectly answered (no negative marking).
  • You can mark questions for review using the Mark for Review & Next button to revisit them later.
  • To change your answer, you can select another option, or click Clear Response to remove your selection.
  • STRICT RULE: Do NOT refresh the page or switch browser tabs. Doing so may cause you to lose your progress and auto-submit the exam.
