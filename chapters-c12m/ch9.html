Q1
Exercise 9.1 (Verbatim)
Determine order and degree (if defined) of each of the following differential equations:
(i) $\frac{d^4y}{dx^4} + \sin(y''') = 0$
(ii) $y' + 5y = 0$
(iii) $\left(\frac{ds}{dt}\right)^4 + 3s\frac{d^2s}{dt^2} = 0$
(iv) $\left(\frac{d^2y}{dx^2}\right)^2 + \cos\left(\frac{dy}{dx}\right) = 0$
(v) $\frac{d^2y}{dx^2} = \cos 3x + \sin 3x$
[5 Marks]
✅ CBSE Step-by-Step Mathematical Solution

Detailed Analysis of Order & Degree:

  1. (i) $\frac{d^4y}{dx^4} + \sin(y''') = 0$:
    • The highest order derivative is $\frac{d^4y}{dx^4}$, which is of order 4. → Order = 4.
    • The equation is not a polynomial equation in derivatives because of the term $\sin(y''')$. → Degree is NOT DEFINED.
  2. (ii) $y' + 5y = 0$:
    • Highest derivative is $\frac{dy}{dx}$ (order 1). → Order = 1.
    • The highest power of $\frac{dy}{dx}$ is 1. → Degree = 1.
  3. (iii) $\left(\frac{ds}{dt}\right)^4 + 3s\frac{d^2s}{dt^2} = 0$:
    • The highest order derivative present is $\frac{d^2s}{dt^2}$. → Order = 2.
    • The power of $\frac{d^2s}{dt^2}$ is 1 (the power 4 is on the first derivative, which does not govern degree). → Degree = 1.
  4. (iv) $\left(\frac{d^2y}{dx^2}\right)^2 + \cos\left(\frac{dy}{dx}\right) = 0$:
    • Highest order derivative is $\frac{d^2y}{dx^2}$. → Order = 2.
    • Because of the term $\cos(dy/dx)$, the equation cannot be written as a polynomial in derivatives. → Degree is NOT DEFINED.
  5. (v) $\frac{d^2y}{dx^2} = \cos 3x + \sin 3x$:
    • Highest order derivative is $\frac{d^2y}{dx^2}$. → Order = 2.
    • It is a polynomial equation in derivatives of degree 1 (the trig functions involve only independent variable $x$, which is allowed). → Degree = 1.

(iii) Order = 2, Degree = 11 Mark

Q2
Exercise 9.2 (Verbatim)
(i) Verify that the function $y = e^x + 1$ is a solution of the differential equation $y'' - y' = 0$.
(ii) Verify that $y = \sqrt{1 + x^2}$ is a solution of the differential equation $y' = \frac{xy}{1 + x^2}$.
(iii) Verify that $xy = \log y + C$ is a solution of the differential equation $y' = \frac{y^2}{1 - xy} \; (xy \neq 1)$.
[3 Marks]
✅ CBSE Step-by-Step Mathematical Solution

(i) $y = e^x + 1$:

  • $y' = \frac{d}{dx}(e^x + 1) = e^x$.
  • $y'' = \frac{d}{dx}(e^x) = e^e = e^x$.
  • $\text{LHS} = y'' - y' = e^x - e^x = 0 = \text{RHS}$.
  • Hence verified.

(ii) $y = \sqrt{1 + x^2}$:

Differentiating with respect to $x$: $$y' = \frac{1}{2\sqrt{1 + x^2}} \cdot (2x) = \frac{x}{\sqrt{1 + x^2}}$$ Multiply numerator and denominator by $\sqrt{1 + x^2}$: $$y' = \frac{x\sqrt{1 + x^2}}{(\sqrt{1 + x^2})^2} = \frac{xy}{1 + x^2} = \text{RHS}$$ Hence verified.

(iii) $xy = \log y + C$:

Differentiating with respect to $x$ using product rule: $$x \frac{dy}{dx} + y(1) = \frac{1}{y} \frac{dy}{dx}$$ Collect terms with $\frac{dy}{dx}$: $$y = \frac{1}{y} \frac{dy}{dx} - x \frac{dy}{dx} = \left( \frac{1}{y} - x \right) \frac{dy}{dx} = \left( \frac{1 - xy}{y} \right) \frac{dy}{dx}$$ Cross-multiplying: $$y' = \frac{dy}{dx} = \frac{y^2}{1 - xy}$$ Hence verified.

(ii) Differentiating √(1+x²) and expressing as xy/(1+x²)1 Mark
(iii) Implicit differentiation of xy = log y + C yielding y' = y²/(1 - xy)1 Mark
Q3
Exercise 9.3 (Verbatim)
Find the general solution of the differential equations:
(i) $\frac{dy}{dx} = \frac{1 - \cos x}{1 + \cos x}$
(ii) $\sec^2 x \tan y \, dx + \sec^2 y \tan x \, dy = 0$
[4 Marks]
✅ CBSE Step-by-Step Mathematical Solution

(i) $\frac{dy}{dx} = \frac{1 - \cos x}{1 + \cos x}$:

Using half-angle trigonometric formulas: $$1 - \cos x = 2\sin^2(x/2) \quad \text{and} \quad 1 + \cos x = 2\cos^2(x/2)$$ $$\frac{dy}{dx} = \frac{2\sin^2(x/2)}{2\cos^2(x/2)} = \tan^2(x/2) = \sec^2(x/2) - 1$$ Separating variables: $$dy = [\sec^2(x/2) - 1] \, dx$$ Integrating both sides: $$\int dy = \int [\sec^2(x/2) - 1] \, dx$$ $$y = \frac{\tan(x/2)}{1/2} - x + C = \mathbf{2\tan(x/2) - x + C}$$

(ii) $\sec^2 x \tan y \, dx + \sec^2 y \tan x \, dy = 0$:

Dividing the entire equation by $\tan x \tan y$: $$\frac{\sec^2 x}{\tan x} \, dx + \frac{\sec^2 y}{\tan y} \, dy = 0$$ Integrating both sides: $$\int \frac{\sec^2 x}{\tan x} \, dx + \int \frac{\sec^2 y}{\tan y} \, dy = C_1$$ Since $\frac{d}{dx}(\tan x) = \sec^2 x$, this is of the form $\int \frac{f'(u)}{f(u)} \, du = \log|f(u)|$: $$\log|\tan x| + \log|\tan y| = \log C$$ $$\log|\tan x \tan y| = \log C$$ $$\mathbf{\tan x \tan y = C}$$

(i) Half-angle conversion to sec²(x/2) - 11 Mark
(i) Integrating to get y = 2 tan(x/2) - x + C1 Mark
(ii) Dividing by tan x tan y to separate variables1 Mark
(ii) Integrating to log|tan x| + log|tan y| = log C => tan x tan y = C1 Mark
Q4
Exercise 9.3 (Verbatim)
(i) Find the general solution of the differential equation $\frac{dy}{dx} = \sin^{-1} x$.
(ii) Find the particular solution of the differential equation $(x^3 + x^2 + x + 1)\frac{dy}{dx} = 2x^2 + x$, given that $y = 1$ when $x = 0$.
[5 Marks]
✅ CBSE Step-by-Step Mathematical Solution

(i) $\frac{dy}{dx} = \sin^{-1} x$:

$$dy = (\sin^{-1} x) \, dx \implies y = \int (\sin^{-1} x \cdot 1) \, dx$$ Integrating by parts: $u = \sin^{-1} x, \; v = 1$: $$y = (\sin^{-1} x) x - \int \frac{1}{\sqrt{1 - x^2}} \cdot x \, dx$$ For the second integral, let $1 - x^2 = t \implies -2x \, dx = dt \implies x \, dx = -\frac{dt}{2}$: $$\int \frac{x}{\sqrt{1 - x^2}} \, dx = -\frac{1}{2} \int t^{-1/2} \, dt = -\sqrt{t} = -\sqrt{1 - x^2}$$ $$y = x\sin^{-1} x - (-\sqrt{1 - x^2}) + C = \mathbf{x\sin^{-1} x + \sqrt{1 - x^2} + C}$$

(ii) Particular Solution:

$$\frac{dy}{dx} = \frac{2x^2 + x}{x^3 + x^2 + x + 1} = \frac{2x^2 + x}{x^2(x + 1) + 1(x + 1)} = \frac{2x^2 + x}{(x^2 + 1)(x + 1)}$$ Resolving into partial fractions: $$\frac{2x^2 + x}{(x^2 + 1)(x + 1)} = \frac{A}{x + 1} + \frac{Bx + C}{x^2 + 1}$$ $$2x^2 + x = A(x^2 + 1) + (Bx + C)(x + 1)$$
  • Put $x = -1$: $2(-1)^2 + (-1) = A(1 + 1) \implies 1 = 2A \implies A = \frac{1}{2}$.
  • Equating coefficient of $x^2$: $A + B = 2 \implies \frac{1}{2} + B = 2 \implies B = \frac{3}{2}$.
  • Put $x = 0$: $0 = A(1) + C(1) \implies C = -A = -\frac{1}{2}$.
Thus: $$dy = \left[ \frac{1/2}{x + 1} + \frac{3/2 x - 1/2}{x^2 + 1} \right] dx = \left[ \frac{1}{2(x + 1)} + \frac{3}{4}\frac{2x}{x^2 + 1} - \frac{1}{2}\frac{1}{x^2 + 1} \right] dx$$ Integrating: $$y = \frac{1}{2}\log|x + 1| + \frac{3}{4}\log(x^2 + 1) - \frac{1}{2}\tan^{-1} x + C$$

Apply initial condition $y = 1$ when $x = 0$:

$$1 = \frac{1}{2}\log(1) + \frac{3}{4}\log(1) - \frac{1}{2}\tan^{-1}(0) + C \implies C = 1$$ $$\mathbf{y = \frac{1}{4} [2\log|x + 1| + 3\log(x^2 + 1)] - \frac{1}{2}\tan^{-1} x + 1}$$ $$\mathbf{y = \frac{1}{4} \log\left[(x + 1)^2 (x^2 + 1)^3\right] - \frac{1}{2}\tan^{-1} x + 1}$$

Q5
Exercise 9.4 (Verbatim)
Show that the differential equation $(x^2 + xy) \, dy = (x^2 + y^2) \, dx$ is homogeneous and solve it.
[5 Marks]
✅ CBSE Step-by-Step Mathematical Solution

Step 1: Test for Homogeneity:

Rewrite as: $$\frac{dy}{dx} = \frac{x^2 + y^2}{x^2 + xy} = F(x, y)$$ Let $F(\lambda x, \lambda y) = \frac{(\lambda x)^2 + (\lambda y)^2}{(\lambda x)^2 + (\lambda x)(\lambda y)} = \frac{\lambda^2(x^2 + y^2)}{\lambda^2(x^2 + xy)} = \lambda^0 F(x, y)$.
Since $F(\lambda x, \lambda y) = \lambda^0 F(x, y)$, the differential equation is homogeneous of degree $0$.

Step 2: Substitution $y = vx$:

$$\frac{dy}{dx} = v + x\frac{dv}{dx}$$ Substitute into the equation: $$v + x\frac{dv}{dx} = \frac{x^2 + (vx)^2}{x^2 + x(vx)} = \frac{x^2(1 + v^2)}{x^2(1 + v)} = \frac{1 + v^2}{1 + v}$$ $$x\frac{dv}{dx} = \frac{1 + v^2}{1 + v} - v = \frac{1 + v^2 - v(1 + v)}{1 + v} = \frac{1 + v^2 - v - v^2}{1 + v} = \frac{1 - v}{1 + v}$$

Step 3: Separate Variables & Integrate:

$$\frac{1 + v}{1 - v} \, dv = \frac{dx}{x}$$ Rewrite $\frac{1 + v}{1 - v} = \frac{-(1 - v) + 2}{1 - v} = -1 + \frac{2}{1 - v}$: $$\int \left( -1 + \frac{2}{1 - v} \right) dv = \int \frac{dx}{x}$$ $$-v - 2\log|1 - v| = \log|x| + C_1$$ $$-v = \log|x| + 2\log|1 - v| + C_1 = \log|x(1 - v)^2| + C_1$$ Substitute back $v = \frac{y}{x}$: $$-\frac{y}{x} = \log\left| x\left( 1 - \frac{y}{x} \right)^2 \right| + C_1 = \log\left| x \cdot \frac{(x - y)^2}{x^2} \right| + C_1 = \log\left| \frac{(x - y)^2}{x} \right| + C_1$$ $$\log\left| \frac{(x - y)^2}{x} \right| + \frac{y}{x} = C$$ $$\mathbf{(x - y)^2 = C x e^{-y/x}}$$

Q6
Exercise 9.4 (Verbatim)
Solve the differential equation: $$x \frac{dy}{dx} - y + x \sin\left(\frac{y}{x}\right) = 0$$
[4 Marks]
✅ CBSE Step-by-Step Mathematical Solution

Step 1: Formulate $\frac{dy}{dx}$:

$$x \frac{dy}{dx} = y - x \sin\left(\frac{y}{x}\right)$$ $$\frac{dy}{dx} = \frac{y}{x} - \sin\left(\frac{y}{x}\right)$$ This is a function of $\left(\frac{y}{x}\right)$, hence it is homogeneous.

Step 2: Substitute $y = vx \implies \frac{dy}{dx} = v + x\frac{dv}{dx}$:

$$v + x\frac{dv}{dx} = v - \sin v$$ $$x\frac{dv}{dx} = -\sin v$$

Step 3: Separate Variables:

$$-\frac{dv}{\sin v} = \frac{dx}{x} \implies -\operatorname{cosec} v \, dv = \frac{dx}{x}$$ Integrating both sides: $$-\int \operatorname{cosec} v \, dv = \int \frac{dx}{x}$$ $$-\log|\operatorname{cosec} v - \cot v| = \log|x| + \log C_1$$ $$\log|x| + \log|\operatorname{cosec} v - \cot v| = -\log C_1 = \log C$$ $$\log|x(\operatorname{cosec} v - \cot v)| = \log C$$ $$x(\operatorname{cosec} v - \cot v) = C$$ Using trigonometric identity $\operatorname{cosec} v - \cot v = \frac{1 - \cos v}{\sin v} = \tan(v/2)$: $$x \tan\left(\frac{v}{2}\right) = C$$ Substitute back $v = \frac{y}{x}$: $$\mathbf{x \tan\left(\frac{y}{2x}\right) = C}$$

Q7
Exercise 9.4 (Verbatim)
Solve the differential equation: $$(1 + e^{x/y}) \, dx + e^{x/y}\left(1 - \frac{x}{y}\right) dy = 0$$
[4 Marks]
✅ CBSE Step-by-Step Mathematical Solution

Step 1: Identify Type:

Notice the appearance of $\frac{x}{y}$. This signals that we should write the equation in $\frac{dx}{dy}$ form rather than $\frac{dy}{dx}$: $$(1 + e^{x/y}) \, dx = -e^{x/y}\left(1 - \frac{x}{y}\right) dy = e^{x/y}\left(\frac{x}{y} - 1\right) dy$$ $$\frac{dx}{dy} = \frac{e^{x/y}\left(\frac{x}{y} - 1\right)}{1 + e^{x/y}} = F\left(\frac{x}{y}\right)$$ This is a homogeneous differential equation in $\frac{x}{y}$.

Step 2: Substitution $x = vy \implies \frac{dx}{dy} = v + y\frac{dv}{dy}$:

$$v + y\frac{dv}{dy} = \frac{e^v(v - 1)}{1 + e^v}$$ $$y\frac{dv}{dy} = \frac{v e^v - e^v}{1 + e^v} - v = \frac{v e^v - e^v - v(1 + e^v)}{1 + e^v} = \frac{v e^v - e^v - v - v e^v}{1 + e^v} = -\frac{v + e^v}{1 + e^v}$$

Step 3: Separate Variables:

$$\frac{1 + e^v}{v + e^v} \, dv = -\frac{dy}{y}$$ Integrating both sides: $$\int \frac{1 + e^v}{v + e^v} \, dv = -\int \frac{dy}{y}$$ Notice that $\frac{d}{dv}(v + e^v) = 1 + e^v$: $$\log|v + e^v| = -\log|y| + \log C = \log\left|\frac{C}{y}\right|$$ $$v + e^v = \frac{C}{y} \implies y(v + e^v) = C$$ Substitute back $v = \frac{x}{y}$: $$y\left( \frac{x}{y} + e^{x/y} \right) = C$$ $$\mathbf{x + y e^{x/y} = C}$$

Q8
Exercise 9.5 (Verbatim)
Find the general solution of the differential equations:
(i) $\frac{dy}{dx} + 2y = \sin x$
(ii) $\frac{dy}{dx} + 3y = e^{-2x}$
[4 Marks]
✅ CBSE Step-by-Step Mathematical Solution

(i) $\frac{dy}{dx} + 2y = \sin x$:

This is a linear differential equation $\frac{dy}{dx} + Py = Q$ with $P = 2$ and $Q = \sin x$.
  1. Integrating Factor (I.F.): $$\text{I.F.} = e^{\int P \, dx} = e^{\int 2 \, dx} = e^{2x}$$
  2. General Solution: $$y \cdot (\text{I.F.}) = \int Q \cdot (\text{I.F.}) \, dx + C$$ $$y e^{2x} = \int e^{2x} \sin x \, dx + C$$
  3. We already know the standard integral $\int e^{ax} \sin bx \, dx = \frac{e^{ax}}{a^2 + b^2}(a\sin bx - b\cos bx)$:
    Here $a = 2, b = 1$: $$\int e^{2x} \sin x \, dx = \frac{e^{2x}}{2^2 + 1^2}(2\sin x - \cos x) = \frac{e^{2x}}{5}(2\sin x - \cos x)$$
  4. Substitute back: $$y e^{2x} = \frac{e^{2x}}{5}(2\sin x - \cos x) + C$$ $$\mathbf{y = \frac{1}{5}(2\sin x - \cos x) + C e^{-2x}}$$

(ii) $\frac{dy}{dx} + 3y = e^{-2x}$:

Here $P = 3, Q = e^{-2x}$.
  1. $\text{I.F.} = e^{\int 3 \, dx} = e^{3x}$.
  2. $$y e^{3x} = \int e^{-2x} e^{3x} \, dx + C = \int e^x \, dx + C = e^x + C$$
  3. Divide by $e^{3x}$: $$\mathbf{y = e^{-2x} + C e^{-3x}}$$

Q9
Exercise 9.5 (Verbatim)
Find the general solution of the differential equations:
(i) $\frac{dy}{dx} + (\sec x)y = \tan x, \; \left(0 \le x < \frac{\pi}{2}\right)$
(ii) $\cos^2 x \frac{dy}{dx} + y = \tan x, \; \left(0 \le x < \frac{\pi}{2}\right)$
[4 Marks]
✅ CBSE Step-by-Step Mathematical Solution

(i) $\frac{dy}{dx} + (\sec x)y = \tan x$:

Here $P = \sec x, \; Q = \tan x$.
  1. Integrating Factor: $$\text{I.F.} = e^{\int \sec x \, dx} = e^{\log|\sec x + \tan x|} = \sec x + \tan x$$
  2. General Solution: $$y (\sec x + \tan x) = \int \tan x (\sec x + \tan x) \, dx + C$$ $$= \int (\sec x \tan x + \tan^2 x) \, dx + C = \int [\sec x \tan x + (\sec^2 x - 1)] \, dx + C$$ $$= \sec x + \tan x - x + C$$
  3. $$\mathbf{y (\sec x + \tan x) = \sec x + \tan x - x + C}$$

(ii) $\cos^2 x \frac{dy}{dx} + y = \tan x$:

Divide throughout by $\cos^2 x$: $$\frac{dy}{dx} + \left(\frac{1}{\cos^2 x}\right) y = \frac{\tan x}{\cos^2 x}$$ $$\frac{dy}{dx} + (\sec^2 x) y = \tan x \sec^2 x$$ Here $P = \sec^2 x, \; Q = \tan x \sec^2 x$.
  1. $$\text{I.F.} = e^{\int \sec^2 x \, dx} = e^{\tan x}$$
  2. General Solution: $$y e^{\tan x} = \int (\tan x \sec^2 x) e^{\tan x} \, dx + C$$ For the integral, put $t = \tan x \implies dt = \sec^2 x \, dx$: $$\int t e^t \, dt = t e^t - e^t = e^t (t - 1) = e^{\tan x}(\tan x - 1)$$
  3. $$y e^{\tan x} = e^{\tan x}(\tan x - 1) + C$$ $$\mathbf{y = \tan x - 1 + C e^{-\tan x}}$$

Q10
Exercise 9.5 (Verbatim)
Find the general solution of the differential equation: $$(x + y) \frac{dy}{dx} = 1$$ Also solve $(x + 2y^2) \frac{dy}{dx} = y \; (y > 0)$.
[4 Marks]
✅ CBSE Step-by-Step Mathematical Solution

Part 1: $(x + y) \frac{dy}{dx} = 1$:

Invert to obtain $\frac{dx}{dy}$: $$\frac{dx}{dy} = x + y \implies \frac{dx}{dy} - x = y$$ This is a linear differential equation of Type 2: $\frac{dx}{dy} + P_1 x = Q_1$ with $P_1 = -1$ and $Q_1 = y$.
  1. Integrating Factor: $$\text{I.F.} = e^{\int (-1) \, dy} = e^{-y}$$
  2. General Solution: $$x \cdot (\text{I.F.}) = \int Q_1 \cdot (\text{I.F.}) \, dy + C$$ $$x e^{-y} = \int y e^{-y} \, dy + C$$
  3. Integrating by parts: $$\int y e^{-y} \, dy = y(-e^{-y}) - \int 1(-e^{-y}) \, dy = -y e^{-y} - e^{-y} = -e^{-y}(y + 1)$$
  4. $$x e^{-y} = -e^{-y}(y + 1) + C$$ $$\mathbf{x = -(y + 1) + C e^y \implies x + y + 1 = C e^y}$$

Part 2: $(x + 2y^2) \frac{dy}{dx} = y$:

$$\frac{dx}{dy} = \frac{x + 2y^2}{y} = \frac{x}{y} + 2y \implies \frac{dx}{dy} - \frac{1}{y} x = 2y$$ Here $P_1 = -\frac{1}{y}, \; Q_1 = 2y$.
  1. $$\text{I.F.} = e^{\int -\frac{1}{y} \, dy} = e^{-\log y} = e^{\log(y^{-1})} = \frac{1}{y}$$
  2. $$x \left(\frac{1}{y}\right) = \int 2y \left(\frac{1}{y}\right) dy + C = \int 2 \, dy + C = 2y + C$$
  3. $$\mathbf{x = 2y^2 + C y}$$

Q11
Exercise 9.5 (Verbatim)
Find the particular solution of the differential equation: $$\frac{dy}{dx} + 2y\tan x = \sin x; \quad y = 0 \text{ when } x = \frac{\pi}{3}$$ Also find particular solution of $(1 + x^2)\frac{dy}{dx} + 2xy = \frac{1}{1 + x^2}; \; y = 0 \text{ when } x = 1$.
[5 Marks]
✅ CBSE Step-by-Step Mathematical Solution

Part 1: $\frac{dy}{dx} + (2\tan x)y = \sin x$:

Here $P = 2\tan x, \; Q = \sin x$.
  1. $$\text{I.F.} = e^{\int 2\tan x \, dx} = e^{2\log|\sec x|} = e^{\log(\sec^2 x)} = \sec^2 x$$
  2. General Solution: $$y \sec^2 x = \int \sin x \sec^2 x \, dx + C = \int \sec x \tan x \, dx + C = \sec x + C$$ $$y = \frac{\sec x + C}{\sec^2 x} = \cos x + C \cos^2 x$$
  3. Substitute initial conditions $y = 0$ at $x = \frac{\pi}{3}$: $$0 = \cos\left(\frac{\pi}{3}\right) + C \cos^2\left(\frac{\pi}{3}\right) = \frac{1}{2} + C\left(\frac{1}{4}\right)$$ $$\frac{C}{4} = -\frac{1}{2} \implies C = -2$$
  4. $$\mathbf{y = \cos x - 2\cos^2 x}$$

Part 2: $(1 + x^2)\frac{dy}{dx} + 2xy = \frac{1}{1 + x^2}$:

$$\frac{dy}{dx} + \left(\frac{2x}{1 + x^2}\right) y = \frac{1}{(1 + x^2)^2}$$
  1. $$\text{I.F.} = e^{\int \frac{2x}{1 + x^2} \, dx} = e^{\log(1 + x^2)} = 1 + x^2$$
  2. $$y(1 + x^2) = \int \frac{1}{(1 + x^2)^2} (1 + x^2) \, dx + C = \int \frac{1}{1 + x^2} \, dx + C = \tan^{-1} x + C$$
  3. Given $y = 0$ when $x = 1$: $$0(1 + 1) = \tan^{-1}(1) + C \implies 0 = \frac{\pi}{4} + C \implies C = -\frac{\pi}{4}$$
  4. $$\mathbf{y(1 + x^2) = \tan^{-1} x - \frac{\pi}{4}}$$

Q12
Exercise 9.3 (Verbatim)
In a bank, principal increases continuously at the rate of $r\%$ per year. Find the value of $r$ if ₹$100$ double itself in $10\text{ years}$ $(\log_e 2 = 0.6931)$.
Also, in a culture, the bacteria count is $100{,}000$. The number is increased by $10\%$ in $2\text{ hours}$. In how many hours will the count reach $200{,}000$, if the rate of growth of bacteria is proportional to the number present?
[4 Marks]
✅ CBSE Step-by-Step Mathematical Solution

Part 1: Bank Principal Doubling:

Let $P$ be the principal at time $t$ (in years). $$\frac{dP}{dt} = \frac{r}{100} P$$ Separating variables: $$\frac{dP}{P} = \frac{r}{100} \, dt \implies \log P = \frac{r}{100} t + C$$
  1. At $t = 0, \; P = 100$: $$\log(100) = C \implies \log P - \log(100) = \frac{rt}{100} \implies \log\left(\frac{P}{100}\right) = \frac{rt}{100}$$
  2. At $t = 10$, principal doubles, so $P = 200$: $$\log\left(\frac{200}{100}\right) = \frac{r(10)}{100} \implies \log 2 = \frac{r}{10}$$ $$r = 10 \log 2 = 10(0.6931) = \mathbf{6.931\%}$$

Part 2: Bacterial Population Growth:

Let $N$ be the number of bacteria at time $t$ (in hours). $$\frac{dN}{dt} = k N \implies \frac{dN}{N} = k \, dt \implies \log N = k t + C$$
  1. At $t = 0, \; N = 100{,}000 \implies C = \log(100{,}000)$. $$\log\left(\frac{N}{100{,}000}\right) = k t$$
  2. At $t = 2\text{ hours}$, number increases by $10\%$, so $N = 110{,}000$: $$\log\left(\frac{110{,}000}{100{,}000}\right) = 2k \implies \log(1.1) = 2k \implies k = \frac{1}{2}\log\left(\frac{11}{10}\right)$$
  3. We need time $t$ when count reaches $200{,}000$: $$\log\left(\frac{200{,}000}{100{,}000}\right) = k t \implies \log 2 = \left[ \frac{1}{2}\log\left(\frac{11}{10}\right) \right] t$$ $$\mathbf{t = \frac{2\log 2}{\log(11/10)}\text{ hours}}$$
