Q1
Exercise 2.1 (Verbatim)
Find the principal value of $\sin^{-1}\left(-\frac{1}{2}\right)$.
[1 Mark]
✅ CBSE Step-by-Step Mathematical Solution

Let $y = \sin^{-1}\left(-\frac{1}{2}\right)$.

Then $\sin y = -\frac{1}{2}$.

We know that the principal value branch of $\sin^{-1}$ is $\left[-\frac{\pi}{2}, \frac{\pi}{2}\right]$.

Since $\sin\left(\frac{\pi}{6}\right) = \frac{1}{2}$, we have:

$$\sin y = -\sin\left(\frac{\pi}{6}\right) = \sin\left(-\frac{\pi}{6}\right)$$

Since $-\frac{\pi}{6} \in \left[-\frac{\pi}{2}, \frac{\pi}{2}\right]$, the principal value of $\sin^{-1}\left(-\frac{1}{2}\right)$ is:

$$\mathbf{-\frac{\pi}{6}}$$

[2 Marks]
✅ CBSE Step-by-Step Mathematical Solution

Method 1: Direct Principal Value Evaluation:

  • $\tan^{-1}(1) = \frac{\pi}{4}$ (since $\frac{\pi}{4} \in \left(-\frac{\pi}{2}, \frac{\pi}{2}\right)$).
  • $\cos^{-1}\left(-\frac{1}{2}\right) = \pi - \cos^{-1}\left(\frac{1}{2}\right) = \pi - \frac{\pi}{3} = \frac{2\pi}{3}$.
  • $\sin^{-1}\left(-\frac{1}{2}\right) = -\sin^{-1}\left(\frac{1}{2}\right) = -\frac{\pi}{6}$.

Substitute these values into the given expression:

$$\text{Value} = \frac{\pi}{4} + \frac{2\pi}{3} - \frac{\pi}{6}$$

Taking common denominator $12$:

$$\text{Value} = \frac{3\pi + 8\pi - 2\pi}{12} = \frac{9\pi}{12} = \mathbf{\frac{3\pi}{4}}$$

Method 2: Using the Identity $\sin^{-1}x + \cos^{-1}x = \frac{\pi}{2}$:

Notice that for $x = -\frac{1}{2}$, $\cos^{-1}\left(-\frac{1}{2}\right) + \sin^{-1}\left(-\frac{1}{2}\right) = \frac{\pi}{2}$.

$$\text{Value} = \tan^{-1}(1) + \frac{\pi}{2} = \frac{\pi}{4} + \frac{\pi}{2} = \mathbf{\frac{3\pi}{4}}$$

Q15
Exercise 2.2 (Verbatim)
Prove that: $$3\sin^{-1}x = \sin^{-1}(3x - 4x^3), \quad x \in \left[-\frac{1}{2}, \frac{1}{2}\right]$$
[3 Marks]
✅ CBSE Step-by-Step Mathematical Solution

Proof:

Let $\sin^{-1} x = \theta \implies x = \sin\theta$.

Given $x \in \left[-\frac{1}{2}, \frac{1}{2}\right]$:

$$-\frac{1}{2} \le x \le \frac{1}{2} \implies -\frac{1}{2} \le \sin\theta \le \frac{1}{2} \implies -\frac{\pi}{6} \le \theta \le \frac{\pi}{6}$$

Multiplying by $3$:

$$-\frac{\pi}{2} \le 3\theta \le \frac{\pi}{2}$$

We know the standard trigonometric identity for $\sin(3\theta)$:

$$\sin 3\theta = 3\sin\theta - 4\sin^3\theta$$

Since $x = \sin\theta$, this gives:

$$\sin 3\theta = 3x - 4x^3$$

Since $3\theta \in \left[-\frac{\pi}{2}, \frac{\pi}{2}\right]$ (which is the principal value branch of $\sin^{-1}$), we can take $\sin^{-1}$ on both sides:

$$3\theta = \sin^{-1}(3x - 4x^3)$$

Substituting back $\theta = \sin^{-1} x$:

$$3\sin^{-1} x = \sin^{-1}(3x - 4x^3)$$

Hence Proved.

Q17
Exercise 2.2 (Verbatim)
Write the function in the simplest form: $$\tan^{-1}\left(\frac{\sqrt{1+x^2}-1}{x}\right), \quad x \neq 0$$
[3 Marks]
✅ CBSE Step-by-Step Mathematical Solution

Simplification:

Put $x = \tan\theta \implies \theta = \tan^{-1} x$, where $\theta \in \left(-\frac{\pi}{2}, \frac{\pi}{2}\right) - \{0\}$.

Substitute $x = \tan\theta$ into the expression:

$$\frac{\sqrt{1+x^2}-1}{x} = \frac{\sqrt{1+\tan^2\theta}-1}{\tan\theta} = \frac{\sqrt{\sec^2\theta}-1}{\tan\theta} = \frac{\sec\theta - 1}{\tan\theta}$$

Expressing in terms of $\sin\theta$ and $\cos\theta$:

$$= \frac{\frac{1}{\cos\theta} - 1}{\frac{\sin\theta}{\cos\theta}} = \frac{1 - \cos\theta}{\sin\theta}$$

Using half-angle trigonometric formulas $1 - \cos\theta = 2\sin^2\left(\frac{\theta}{2}\right)$ and $\sin\theta = 2\sin\left(\frac{\theta}{2}\right)\cos\left(\frac{\theta}{2}\right)$:

$$= \frac{2\sin^2(\theta/2)}{2\sin(\theta/2)\cos(\theta/2)} = \frac{\sin(\theta/2)}{\cos(\theta/2)} = \tan\left(\frac{\theta}{2}\right)$$

Now evaluate the inverse tangent:

$$\tan^{-1}\left(\tan\frac{\theta}{2}\right) = \frac{\theta}{2}$$

Substituting back $\theta = \tan^{-1} x$:

$$= \mathbf{\frac{1}{2}\tan^{-1} x}$$

[2 Marks]
✅ CBSE Step-by-Step Mathematical Solution

Given $0 < x < \pi \implies 0 < \frac{x}{2} < \frac{\pi}{2}$.

$$1 - \cos x = 2\sin^2\left(\frac{x}{2}\right)$$ $$1 + \cos x = 2\cos^2\left(\frac{x}{2}\right)$$

Since $0 < \frac{x}{2} < \frac{\pi}{2}$, $\tan(x/2) > 0$. Hence:

$$\sqrt{\tan^2(x/2)} = \tan\left(\frac{x}{2}\right)$$

Now evaluate:

$$\tan^{-1}\left(\tan\frac{x}{2}\right) = \mathbf{\frac{x}{2}}$$

Write the function in the simplest form: $$\tan^{-1}\left(\frac{\cos x - \sin x}{\cos x + \sin x}\right), \quad -\frac{\pi}{4} < x < \frac{3\pi}{4}$$
[3 Marks]
✅ CBSE Step-by-Step Mathematical Solution

Simplification:

Divide both numerator and denominator by $\cos x$ (since $\cos x \neq 0$ on the given interval):

$$\frac{\cos x - \sin x}{\cos x + \sin x} = \frac{1 - \frac{\sin x}{\cos x}}{1 + \frac{\sin x}{\cos x}} = \frac{1 - \tan x}{1 + \tan x}$$

Using the identity $\tan\left(\frac{\pi}{4}\right) = 1$:

$$= \frac{\tan(\pi/4) - \tan x}{1 + \tan(\pi/4)\tan x} = \tan\left(\frac{\pi}{4} - x\right)$$

Check the domain condition: Given $-\frac{\pi}{4} < x < \frac{3\pi}{4}$:

$$-\frac{3\pi}{4} < -x < \frac{\pi}{4} \implies \frac{\pi}{4} - \frac{3\pi}{4} < \frac{\pi}{4} - x < \frac{\pi}{4} + \frac{\pi}{4} \implies -\frac{\pi}{2} < \frac{\pi}{4} - x < \frac{\pi}{2}$$

Since $\left(\frac{\pi}{4} - x\right)$ lies strictly within the principal value branch $\left(-\frac{\pi}{2}, \frac{\pi}{2}\right)$ of $\tan^{-1}$:

$$\tan^{-1}\left(\tan\left(\frac{\pi}{4} - x\right)\right) = \mathbf{\frac{\pi}{4} - x}$$

Q20
Exercise 2.2 (Verbatim)
Find the values of each of the following:
(i) $\sin^{-1}\left(\sin\frac{2\pi}{3}\right)$
(ii) $\tan^{-1}\left(\tan\frac{3\pi}{4}\right)$
[3 Marks]
✅ CBSE Step-by-Step Mathematical Solution
(i) Evaluate $\sin^{-1}\left(\sin\frac{2\pi}{3}\right)$:

We know that $\sin^{-1}(\sin\theta) = \theta$ only if $\theta \in \left[-\frac{\pi}{2}, \frac{\pi}{2}\right]$.

Here, $\frac{2\pi}{3} = 120^\circ \notin \left[-\frac{\pi}{2}, \frac{\pi}{2}\right]$.

Using the reduction formula $\sin(\pi - x) = \sin x$:

$$\sin\left(\frac{2\pi}{3}\right) = \sin\left(\pi - \frac{\pi}{3}\right) = \sin\left(\frac{\pi}{3}\right)$$

Since $\frac{\pi}{3} \in \left[-\frac{\pi}{2}, \frac{\pi}{2}\right]$:

$$\sin^{-1}\left(\sin\frac{2\pi}{3}\right) = \sin^{-1}\left(\sin\frac{\pi}{3}\right) = \mathbf{\frac{\pi}{3}}$$
(ii) Evaluate $\tan^{-1}\left(\tan\frac{3\pi}{4}\right)$:

We know that $\tan^{-1}(\tan\theta) = \theta$ only if $\theta \in \left(-\frac{\pi}{2}, \frac{\pi}{2}\right)$.

Here, $\frac{3\pi}{4} = 135^\circ \notin \left(-\frac{\pi}{2}, \frac{\pi}{2}\right)$.

Using the reduction formula $\tan(\pi - x) = -\tan x = \tan(-x)$:

$$\tan\left(\frac{3\pi}{4}\right) = \tan\left(\pi - \frac{\pi}{4}\right) = -\tan\left(\frac{\pi}{4}\right) = \tan\left(-\frac{\pi}{4}\right)$$

Since $-\frac{\pi}{4} \in \left(-\frac{\pi}{2}, \frac{\pi}{2}\right)$:

$$\tan^{-1}\left(\tan\frac{3\pi}{4}\right) = \tan^{-1}\left(\tan\left(-\frac{\pi}{4}\right)\right) = \mathbf{-\frac{\pi}{4}}$$
