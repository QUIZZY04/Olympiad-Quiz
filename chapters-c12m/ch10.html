Q1
Exercise 10.1 (Verbatim)
(i) Represent graphically a displacement of $40\text{ km}$, $30^\circ$ east of north.
(ii) Classify the following measures as scalars and vectors:
    (a) $10\text{ kg}$      (b) $2\text{ meters north-west}$      (c) $40^\circ$      (d) $40\text{ Watt}$      (e) $10^{-19}\text{ Coulomb}$      (f) $20\text{ m/s}^2$
(iii) In a square with vectors $\vec{a}, \vec{b}, \vec{c}, \vec{d}$, identify: (a) Co-initial vectors, (b) Equal vectors, (c) Collinear but not equal vectors.
[4 Marks]
✅ CBSE Step-by-Step Mathematical Solution

(i) Graphical Representation:

  • Choose a suitable scale: Let $1\text{ cm} = 10\text{ km}$, so a vector of length $4\text{ cm}$ represents $40\text{ km}$.
  • From the origin $O$, draw a directed ray making an angle of $30^\circ$ with the positive North axis towards the East axis.
  • The terminal point $P$ at distance $4\text{ cm}$ from $O$ represents $\vec{OP}$, which is a displacement of $40\text{ km}, 30^\circ$ East of North.

(ii) Classification of Measures:

  • (a) $10\text{ kg}$: Scalar (mass has only magnitude).
  • (b) $2\text{ meters north-west}$: Vector (displacement has both magnitude and specific direction).
  • (c) $40^\circ$: Scalar (angle has only magnitude).
  • (d) $40\text{ Watt}$: Scalar (power has no directional aspect).
  • (e) $10^{-19}\text{ Coulomb}$: Scalar (electric charge is an algebraic quantity).
  • (f) $20\text{ m/s}^2$: Vector (acceleration has direction).

(iii) Square Vector Identification:

  • (a) Co-initial vectors: Vectors that have the same initial starting point (e.g., $\vec{a}$ and $\vec{d}$).
  • (b) Equal vectors: Vectors having both the same magnitude and the same direction (e.g., $\vec{b}$ and $\vec{d}$).
  • (c) Collinear but not equal: Vectors parallel to the same line but opposite in direction or unequal in magnitude (e.g., $\vec{a}$ and $\vec{c}$, which are opposite vectors: $\vec{a} = -\vec{c}$).

Q2
Exercise 10.2 (Verbatim)
(i) Compute the magnitude of the following vectors:
$$\vec{a} = \hat{i} + \hat{j} + \hat{k}, \quad \vec{b} = 2\hat{i} - 7\hat{j} - 3\hat{k}, \quad \vec{c} = \frac{1}{\sqrt{3}}\hat{i} + \frac{1}{\sqrt{3}}\hat{j} - \frac{1}{\sqrt{3}}\hat{k}$$ (ii) Find the values of $x$ and $y$ so that the vectors $2\hat{i} + 3\hat{j}$ and $x\hat{i} + y\hat{j}$ are equal.
(iii) Find the sum of the vectors $\vec{a} = \hat{i} - 2\hat{j} + \hat{k}$, $\vec{b} = -2\hat{i} + 4\hat{j} + 5\hat{k}$ and $\vec{c} = \hat{i} - 6\hat{j} - 7\hat{k}$.
[3 Marks]
✅ CBSE Step-by-Step Mathematical Solution

(i) Magnitudes:

  • $|\vec{a}| = \sqrt{1^2 + 1^2 + 1^2} = \mathbf{\sqrt{3}}$
  • $|\vec{b}| = \sqrt{2^2 + (-7)^2 + (-3)^2} = \sqrt{4 + 49 + 9} = \mathbf{\sqrt{62}}$
  • $|\vec{c}| = \sqrt{\left(\frac{1}{\sqrt{3}}\right)^2 + \left(\frac{1}{\sqrt{3}}\right)^2 + \left(-\frac{1}{\sqrt{3}}\right)^2} = \sqrt{\frac{1}{3} + \frac{1}{3} + \frac{1}{3}} = \sqrt{1} = \mathbf{1}$ (Unit vector)

(ii) Equality of Vectors:

Two vectors are equal if and only if their corresponding components are equal: $$2\hat{i} + 3\hat{j} = x\hat{i} + y\hat{j} \implies \mathbf{x = 2, \quad y = 3}$$

(iii) Sum of Vectors:

$$\vec{a} + \vec{b} + \vec{c} = (1 - 2 + 1)\hat{i} + (-2 + 4 - 6)\hat{j} + (1 + 5 - 7)\hat{k}$$ $$= 0\hat{i} - 4\hat{j} - 1\hat{k} = \mathbf{-4\hat{j} - \hat{k}}$$

Q3
Exercise 10.2 (Verbatim)
(i) Find the unit vector in the direction of the vector $\vec{a} = \hat{i} + \hat{j} + 2\hat{k}$.
(ii) Find the unit vector in the direction of vector $\vec{PQ}$, where $P$ and $Q$ are the points $(1, 2, 3)$ and $(4, 5, 6)$, respectively.
(iii) For given vectors, $\vec{a} = 2\hat{i} - \hat{j} + 2\hat{k}$ and $\vec{b} = -\hat{i} + \hat{j} - \hat{k}$, find the unit vector in the direction of the vector $\vec{a} + \vec{b}$.
[4 Marks]
✅ CBSE Step-by-Step Mathematical Solution

(i) Unit Vector $\hat{a}$:

$|\vec{a}| = \sqrt{1^2 + 1^2 + 2^2} = \sqrt{1 + 1 + 4} = \sqrt{6}$. $$\mathbf{\hat{a} = \frac{\vec{a}}{|\vec{a}|} = \frac{\hat{i} + \hat{j} + 2\hat{k}}{\sqrt{6}} = \frac{1}{\sqrt{6}}\hat{i} + \frac{1}{\sqrt{6}}\hat{j} + \frac{2}{\sqrt{6}}\hat{k}}$$

(ii) Vector $\vec{PQ}$ and its Unit Vector:

$$\vec{PQ} = (x_2 - x_1)\hat{i} + (y_2 - y_1)\hat{j} + (z_2 - z_1)\hat{k}$$ $$= (4 - 1)\hat{i} + (5 - 2)\hat{j} + (6 - 3)\hat{k} = 3\hat{i} + 3\hat{j} + 3\hat{k}$$ $|\vec{PQ}| = \sqrt{3^2 + 3^2 + 3^2} = \sqrt{27} = 3\sqrt{3}$. $$\mathbf{\widehat{PQ} = \frac{3\hat{i} + 3\hat{j} + 3\hat{k}}{3\sqrt{3}} = \frac{1}{\sqrt{3}}\hat{i} + \frac{1}{\sqrt{3}}\hat{j} + \frac{1}{\sqrt{3}}\hat{k}}$$

(iii) Unit Vector of $\vec{a} + \vec{b}$:

$$\vec{c} = \vec{a} + \vec{b} = (2 - 1)\hat{i} + (-1 + 1)\hat{j} + (2 - 1)\hat{k} = \hat{i} + 0\hat{j} + \hat{k} = \hat{i} + \hat{k}$$ $|\vec{c}| = \sqrt{1^2 + 0^2 + 1^2} = \sqrt{2}$. $$\mathbf{\hat{c} = \frac{\hat{i} + \hat{k}}{\sqrt{2}} = \frac{1}{\sqrt{2}}\hat{i} + \frac{1}{\sqrt{2}}\hat{k}}$$

Q4
Exercise 10.2 (Verbatim)
(i) Show that the vectors $2\hat{i} - 3\hat{j} + 4\hat{k}$ and $-4\hat{i} + 6\hat{j} - 8\hat{k}$ are collinear.
(ii) Find the position vector of a point $R$ which divides the line joining two points $P$ and $Q$ whose position vectors are $\hat{i} + 2\hat{j} - \hat{k}$ and $-\hat{i} + \hat{j} + \hat{k}$ respectively, in the ratio $2 : 1$:
    (a) internally
    (b) externally
[4 Marks]
✅ CBSE Step-by-Step Mathematical Solution

(i) Collinearity Test:

Let $\vec{a} = 2\hat{i} - 3\hat{j} + 4\hat{k}$ and $\vec{b} = -4\hat{i} + 6\hat{j} - 8\hat{k}$.
Notice that: $$\vec{b} = -2(2\hat{i} - 3\hat{j} + 4\hat{k}) = -2\vec{a}$$ Since $\vec{b} = \lambda\vec{a}$ with scalar $\lambda = -2$, the vectors $\vec{a}$ and $\vec{b}$ are collinear (they are anti-parallel).
(Alternatively, the ratios of corresponding components are equal: $\frac{-4}{2} = \frac{6}{-3} = \frac{-8}{4} = -2$).

(ii) Section Formula:

Let $\vec{p} = \hat{i} + 2\hat{j} - \hat{k}$ and $\vec{q} = -\hat{i} + \hat{j} + \hat{k}$. The ratio is $m : n = 2 : 1$.
  1. (a) Internally: $$\vec{r} = \frac{m\vec{q} + n\vec{p}}{m + n} = \frac{2(-\hat{i} + \hat{j} + \hat{k}) + 1(\hat{i} + 2\hat{j} - \hat{k})}{2 + 1}$$ $$= \frac{-2\hat{i} + 2\hat{j} + 2\hat{k} + \hat{i} + 2\hat{j} - \hat{k}}{3} = \frac{-\hat{i} + 4\hat{j} + \hat{k}}{3} = \mathbf{-\frac{1}{3}\hat{i} + \frac{4}{3}\hat{j} + \frac{1}{3}\hat{k}}$$
  2. (b) Externally: $$\vec{r} = \frac{m\vec{q} - n\vec{p}}{m - n} = \frac{2(-\hat{i} + \hat{j} + \hat{k}) - 1(\hat{i} + 2\hat{j} - \hat{k})}{2 - 1}$$ $$= \frac{-2\hat{i} + 2\hat{j} + 2\hat{k} - \hat{i} - 2\hat{j} + \hat{k}}{1} = \mathbf{-3\hat{i} + 3\hat{k}}$$

(i) Establishing b = -2a to prove collinearity1 Mark
(ii)(a) Internal division formula yielding (-i + 4j + k)/31.5 Marks
(ii)(b) External division formula yielding -3i + 3k1.5 Marks
Q5
Exercise 10.3 (Verbatim)
(i) Find the angle between two vectors $\vec{a}$ and $\vec{b}$ with magnitudes $\sqrt{3}$ and $2$, respectively, having $\vec{a} \cdot \vec{b} = \sqrt{6}$.
(ii) Find the angle between the vectors $\hat{i} - 2\hat{j} + 3\hat{k}$ and $3\hat{i} - 2\hat{j} + \hat{k}$.
(iii) Find the projection of the vector $\vec{a} = \hat{i} + 3\hat{j} + 7\hat{k}$ on the vector $\vec{b} = 7\hat{i} - \hat{j} + 8\hat{k}$.
[4 Marks]
✅ CBSE Step-by-Step Mathematical Solution

(i) Angle between $\vec{a}$ and $\vec{b}$:

$$\vec{a} \cdot \vec{b} = |\vec{a}||\vec{b}|\cos\theta$$ $$\cos\theta = \frac{\vec{a} \cdot \vec{b}}{|\vec{a}||\vec{b}|} = \frac{\sqrt{6}}{(\sqrt{3})(2)} = \frac{\sqrt{3}\sqrt{2}}{2\sqrt{3}} = \frac{\sqrt{2}}{2} = \frac{1}{\sqrt{2}}$$ $$\mathbf{\theta = \frac{\pi}{4} = 45^\circ}$$

(ii) Angle between $\vec{a} = \hat{i} - 2\hat{j} + 3\hat{k}$ and $\vec{b} = 3\hat{i} - 2\hat{j} + \hat{k}$:

  • $\vec{a} \cdot \vec{b} = (1)(3) + (-2)(-2) + (3)(1) = 3 + 4 + 3 = 10$.
  • $|\vec{a}| = \sqrt{1^2 + (-2)^2 + 3^2} = \sqrt{1 + 4 + 9} = \sqrt{14}$.
  • $|\vec{b}| = \sqrt{3^2 + (-2)^2 + 1^2} = \sqrt{9 + 4 + 1} = \sqrt{14}$.
$$\cos\theta = \frac{10}{\sqrt{14}\sqrt{14}} = \frac{10}{14} = \frac{5}{7}$$ $$\mathbf{\theta = \cos^{-1}\left(\frac{5}{7}\right)}$$

(iii) Projection of $\vec{a}$ on $\vec{b}$:

$$\text{Projection of } \vec{a} \text{ on } \vec{b} = \frac{\vec{a} \cdot \vec{b}}{|\vec{b}|}$$
  • $\vec{a} \cdot \vec{b} = (1)(7) + (3)(-1) + (7)(8) = 7 - 3 + 56 = 60$.
  • $|\vec{b}| = \sqrt{7^2 + (-1)^2 + 8^2} = \sqrt{49 + 1 + 64} = \sqrt{114}$.
$$\text{Projection} = \mathbf{\frac{60}{\sqrt{114}}}$$

(i) Evaluating cos θ = 1/√2 yielding θ = π/41 Mark
(ii) Evaluating dot product = 10 and magnitudes √14 to obtain cos⁻¹(5/7)1.5 Marks
(iii) Projection formula application yielding 60/√1141.5 Marks
Q6
Exercise 10.3 (Verbatim)
(i) Find $|\vec{a}|$ and $|\vec{b}|$, if $(\vec{a} + \vec{b}) \cdot (\vec{a} - \vec{b}) = 8$ and $|\vec{a}| = 8|\vec{b}|$.
(ii) Evaluate the product $(3\vec{a} - 5\vec{b}) \cdot (2\vec{a} + 7\vec{b})$.
[4 Marks]
✅ CBSE Step-by-Step Mathematical Solution

(i) Finding $|\vec{a}|$ and $|\vec{b}|$:

Expanding the dot product using the distributive property: $$(\vec{a} + \vec{b}) \cdot (\vec{a} - \vec{b}) = \vec{a} \cdot \vec{a} - \vec{a} \cdot \vec{b} + \vec{b} \cdot \vec{a} - \vec{b} \cdot \vec{b}$$ Since the dot product is commutative ($\vec{a} \cdot \vec{b} = \vec{b} \cdot \vec{a}$) and $\vec{u} \cdot \vec{u} = |\vec{u}|^2$: $$(\vec{a} + \vec{b}) \cdot (\vec{a} - \vec{b}) = |\vec{a}|^2 - |\vec{b}|^2$$ Given: $|\vec{a}|^2 - |\vec{b}|^2 = 8$.
Substitute $|\vec{a}| = 8|\vec{b}|$: $$(8|\vec{b}|)^2 - |\vec{b}|^2 = 8$$ $$64|\vec{b}|^2 - |\vec{b}|^2 = 8 \implies 63|\vec{b}|^2 = 8$$ $$|\vec{b}|^2 = \frac{8}{63} \implies |\vec{b}| = \sqrt{\frac{8}{63}} = \frac{2\sqrt{2}}{3\sqrt{7}} = \mathbf{\frac{2\sqrt{14}}{21}}$$ Now compute $|\vec{a}|$: $$|\vec{a}| = 8|\vec{b}| = 8 \left( \frac{2\sqrt{2}}{3\sqrt{7}} \right) = \frac{16\sqrt{2}}{3\sqrt{7}} = \mathbf{\frac{16\sqrt{14}}{21}}$$

(ii) Expanding $(3\vec{a} - 5\vec{b}) \cdot (2\vec{a} + 7\vec{b})$:

$$= 3\vec{a} \cdot (2\vec{a} + 7\vec{b}) - 5\vec{b} \cdot (2\vec{a} + 7\vec{b})$$ $$= 6(\vec{a} \cdot \vec{a}) + 21(\vec{a} \cdot \vec{b}) - 10(\vec{b} \cdot \vec{a}) - 35(\vec{b} \cdot \vec{b})$$ $$= \mathbf{6|\vec{a}|^2 + 11(\vec{a} \cdot \vec{b}) - 35|\vec{b}|^2}$$

Q7
Exercise 10.3 (Verbatim)
If $\vec{a}, \vec{b}, \vec{c}$ are unit vectors such that $\vec{a} + \vec{b} + \vec{c} = \vec{0}$, find the value of $\vec{a} \cdot \vec{b} + \vec{b} \cdot \vec{c} + \vec{c} \cdot \vec{a}$.
[3 Marks]
✅ CBSE Step-by-Step Mathematical Solution

Given: $|\vec{a}| = 1, \; |\vec{b}| = 1, \; |\vec{c}| = 1$ and $\vec{a} + \vec{b} + \vec{c} = \vec{0}$.

Take the dot product of $\vec{a} + \vec{b} + \vec{c}$ with itself:

$$(\vec{a} + \vec{b} + \vec{c}) \cdot (\vec{a} + \vec{b} + \vec{c}) = |\vec{a} + \vec{b} + \vec{c}|^2 = |\vec{0}|^2 = 0$$

Expanding the LHS:

$$|\vec{a}|^2 + |\vec{b}|^2 + |\vec{c}|^2 + 2(\vec{a} \cdot \vec{b} + \vec{b} \cdot \vec{c} + \vec{c} \cdot \vec{a}) = 0$$ Substitute $|\vec{a}| = 1, |\vec{b}| = 1, |\vec{c}| = 1$: $$1^2 + 1^2 + 1^2 + 2(\vec{a} \cdot \vec{b} + \vec{b} \cdot \vec{c} + \vec{c} \cdot \vec{a}) = 0$$ $$3 + 2(\vec{a} \cdot \vec{b} + \vec{b} \cdot \vec{c} + \vec{c} \cdot \vec{a}) = 0$$ $$2(\vec{a} \cdot \vec{b} + \vec{b} \cdot \vec{c} + \vec{c} \cdot \vec{a}) = -3$$ $$\mathbf{\vec{a} \cdot \vec{b} + \vec{b} \cdot \vec{c} + \vec{c} \cdot \vec{a} = -\frac{3}{2}}$$

Q8
Exercise 10.4 (Verbatim)
(i) Find $|\vec{a} \times \vec{b}|$, if $\vec{a} = \hat{i} - 7\hat{j} + 7\hat{k}$ and $\vec{b} = 3\hat{i} - 2\hat{j} + 2\hat{k}$.
(ii) Find a unit vector perpendicular to each of the vector $\vec{a} + \vec{b}$ and $\vec{a} - \vec{b}$, where $\vec{a} = 3\hat{i} + 2\hat{j} + 2\hat{k}$ and $\vec{b} = \hat{i} + 2\hat{j} - 2\hat{k}$.
[4 Marks]
✅ CBSE Step-by-Step Mathematical Solution

(i) $|\vec{a} \times \vec{b}|$:

$$\vec{a} \times \vec{b} = \begin{vmatrix} \hat{i} & \hat{j} & \hat{k} \\ 1 & -7 & 7 \\ 3 & -2 & 2 \end{vmatrix}$$ $$= \hat{i}[(-7)(2) - (7)(-2)] - \hat{j}[(1)(2) - (7)(3)] + \hat{k}[(1)(-2) - (-7)(3)]$$ $$= \hat{i}[-14 + 14] - \hat{j}[2 - 21] + \hat{k}[-2 + 21] = 0\hat{i} + 19\hat{j} + 19\hat{k} = 19(\hat{j} + \hat{k})$$ $$|\vec{a} \times \vec{b}| = \sqrt{0^2 + 19^2 + 19^2} = \sqrt{19^2(1 + 1)} = \mathbf{19\sqrt{2}}$$

(ii) Unit vector perpendicular to $(\vec{a} + \vec{b})$ and $(\vec{a} - \vec{b})$:

  1. $\vec{u} = \vec{a} + \vec{b} = (3 + 1)\hat{i} + (2 + 2)\hat{j} + (2 - 2)\hat{k} = 4\hat{i} + 4\hat{j} + 0\hat{k}$.
  2. $\vec{v} = \vec{a} - \vec{b} = (3 - 1)\hat{i} + (2 - 2)\hat{j} + (2 - (-2))\hat{k} = 2\hat{i} + 0\hat{j} + 4\hat{k}$.
  3. A vector perpendicular to both $\vec{u}$ and $\vec{v}$ is given by their cross product: $$\vec{w} = \vec{u} \times \vec{v} = \begin{vmatrix} \hat{i} & \hat{j} & \hat{k} \\ 4 & 4 & 0 \\ 2 & 0 & 4 \end{vmatrix}$$ $$= \hat{i}(16 - 0) - \hat{j}(16 - 0) + \hat{k}(0 - 8) = 16\hat{i} - 16\hat{j} - 8\hat{k} = 8(2\hat{i} - 2\hat{j} - \hat{k})$$
  4. Magnitude: $$|\vec{w}| = 8\sqrt{2^2 + (-2)^2 + (-1)^2} = 8\sqrt{4 + 4 + 1} = 8\sqrt{9} = 8 \times 3 = 24$$
  5. Required unit vector: $$\mathbf{\hat{n} = \pm \frac{\vec{w}}{|\vec{w}|} = \pm \frac{16\hat{i} - 16\hat{j} - 8\hat{k}}{24} = \pm \left(\frac{2}{3}\hat{i} - \frac{2}{3}\hat{j} - \frac{1}{3}\hat{k}\right)}$$

Q9
Exercise 10.4 (Verbatim)
(i) Given that $\vec{a} \cdot \vec{b} = 0$ and $\vec{a} \times \vec{b} = \vec{0}$. What can you conclude about the vectors $\vec{a}$ and $\vec{b}$?
(ii) Find the area of the triangle with vertices $A(1, 1, 2)$, $B(2, 3, 5)$ and $C(1, 5, 5)$.
[4 Marks]
✅ CBSE Step-by-Step Mathematical Solution

(i) Deduction from $\vec{a} \cdot \vec{b} = 0$ and $\vec{a} \times \vec{b} = \vec{0}$:

  • $\vec{a} \cdot \vec{b} = 0 \implies |\vec{a}| = 0$ or $|\vec{b}| = 0$ or $\vec{a} \perp \vec{b}$.
  • $\vec{a} \times \vec{b} = \vec{0} \implies |\vec{a}| = 0$ or $|\vec{b}| = 0$ or $\vec{a} \parallel \vec{b}$.
Since two non-zero vectors cannot be simultaneously perpendicular and parallel (an angle cannot be both $90^\circ$ and $0^\circ$ or $180^\circ$), the only possibility is: $$\mathbf{|\vec{a}| = 0 \quad \text{or} \quad |\vec{b}| = 0 \quad (\text{i.e. } \vec{a} = \vec{0} \text{ or } \vec{b} = \vec{0})}$$

(ii) Area of Triangle $ABC$:

Form adjacent edge vectors from vertex $A$: $$\vec{AB} = (2 - 1)\hat{i} + (3 - 1)\hat{j} + (5 - 2)\hat{k} = \hat{i} + 2\hat{j} + 3\hat{k}$$ $$\vec{AC} = (1 - 1)\hat{i} + (5 - 1)\hat{j} + (5 - 2)\hat{k} = 0\hat{i} + 4\hat{j} + 3\hat{k}$$ Compute cross product $\vec{AB} \times \vec{AC}$: $$\vec{AB} \times \vec{AC} = \begin{vmatrix} \hat{i} & \hat{j} & \hat{k} \\ 1 & 2 & 3 \\ 0 & 4 & 3 \end{vmatrix}$$ $$= \hat{i}(6 - 12) - \hat{j}(3 - 0) + \hat{k}(4 - 0) = -6\hat{i} - 3\hat{j} + 4\hat{k}$$ Magnitude: $$|\vec{AB} \times \vec{AC}| = \sqrt{(-6)^2 + (-3)^2 + 4^2} = \sqrt{36 + 9 + 16} = \sqrt{61}$$ Area of triangle: $$\text{Area} = \frac{1}{2} |\vec{AB} \times \vec{AC}| = \mathbf{\frac{\sqrt{61}}{2}\text{ sq. units}}$$

Q10
Exercise 10.4 (Verbatim)
(i) Find the area of the parallelogram whose adjacent sides are determined by the vectors $\vec{a} = \hat{i} - \hat{j} + 3\hat{k}$ and $\vec{b} = 2\hat{i} - 7\hat{j} + \hat{k}$.
(ii) Let the vectors $\vec{a}$ and $\vec{b}$ be such that $|\vec{a}| = 3$ and $|\vec{b}| = \frac{\sqrt{2}}{3}$, then $\vec{a} \times \vec{b}$ is a unit vector, if the angle between $\vec{a}$ and $\vec{b}$ is:
    (A) $\frac{\pi}{6}$      (B) $\frac{\pi}{4}$      (C) $\frac{\pi}{3}$      (D) $\frac{\pi}{2}$
[3 Marks]
✅ CBSE Step-by-Step Mathematical Solution

(i) Area of Parallelogram:

$$\vec{a} \times \vec{b} = \begin{vmatrix} \hat{i} & \hat{j} & \hat{k} \\ 1 & -1 & 3 \\ 2 & -7 & 1 \end{vmatrix}$$ $$= \hat{i}[(-1)(1) - (3)(-7)] - \hat{j}[(1)(1) - (3)(2)] + \hat{k}[(1)(-7) - (-1)(2)]$$ $$= \hat{i}[-1 + 21] - \hat{j}[1 - 6] + \hat{k}[-7 + 2] = 20\hat{i} + 5\hat{j} - 5\hat{k}$$ $$\text{Area } = |\vec{a} \times \vec{b}| = \sqrt{20^2 + 5^2 + (-5)^2} = \sqrt{400 + 25 + 25} = \sqrt{450} = \sqrt{225 \times 2} = \mathbf{15\sqrt{2}\text{ sq. units}}$$

(ii) Angle between $\vec{a}$ and $\vec{b}$:

Given: $|\vec{a} \times \vec{b}| = 1$.
We know that $|\vec{a} \times \vec{b}| = |\vec{a}||\vec{b}|\sin\theta$. $$1 = (3) \left(\frac{\sqrt{2}}{3}\right) \sin\theta = \sqrt{2}\sin\theta$$ $$\sin\theta = \frac{1}{\sqrt{2}} \implies \mathbf{\theta = \frac{\pi}{4}}$$ Correct Option: (B) $\frac{\pi}{4}$

Q11
Exercise 10.4 (Verbatim)
Find $\lambda$ and $\mu$ if: $$(2\hat{i} + 6\hat{j} + 27\hat{k}) \times (\hat{i} + \lambda\hat{j} + \mu\hat{k}) = \vec{0}$$
[3 Marks]
✅ CBSE Step-by-Step Mathematical Solution

Let $\vec{a} = 2\hat{i} + 6\hat{j} + 27\hat{k}$ and $\vec{b} = \hat{i} + \lambda\hat{j} + \mu\hat{k}$.

Compute cross product $\vec{a} \times \vec{b}$:

$$\vec{a} \times \vec{b} = \begin{vmatrix} \hat{i} & \hat{j} & \hat{k} \\ 2 & 6 & 27 \\ 1 & \lambda & \mu \end{vmatrix}$$ $$= \hat{i}(6\mu - 27\lambda) - \hat{j}(2\mu - 27) + \hat{k}(2\lambda - 6)$$ Given that $\vec{a} \times \vec{b} = \vec{0} = 0\hat{i} + 0\hat{j} + 0\hat{k}$, each component must be zero:
  1. From $\hat{k}$ component: $$2\lambda - 6 = 0 \implies 2\lambda = 6 \implies \mathbf{\lambda = 3}$$
  2. From $\hat{j}$ component: $$-(2\mu - 27) = 0 \implies 2\mu = 27 \implies \mathbf{\mu = \frac{27}{2}}$$
  3. Check consistency with $\hat{i}$ component: $$6\mu - 27\lambda = 6\left(\frac{27}{2}\right) - 27(3) = 3(27) - 81 = 81 - 81 = 0 \quad (\text{Consistent})$$

Final Answer: $\mathbf{\lambda = 3, \quad \mu = \frac{27}{2}}$.

Q12
Exercise 10.4 & Board Special
(i) For any two vectors $\vec{a}$ and $\vec{b}$, prove Lagrange's Identity: $$|\vec{a} \times \vec{b}|^2 = |\vec{a}|^2 |\vec{b}|^2 - (\vec{a} \cdot \vec{b})^2$$ (ii) If diagonals of a parallelogram are given by $\vec{d_1} = 3\hat{i} + \hat{j} - 2\hat{k}$ and $\vec{d_2} = \hat{i} - 3\hat{j} + 4\hat{k}$, find the area of the parallelogram.
[4 Marks]
✅ CBSE Step-by-Step Mathematical Solution

(i) Proof of Lagrange's Identity:

Let $\theta$ be the angle between $\vec{a}$ and $\vec{b}$.
We know that: $$|\vec{a} \times \vec{b}| = |\vec{a}||\vec{b}|\sin\theta \implies |\vec{a} \times \vec{b}|^2 = |\vec{a}|^2 |\vec{b}|^2 \sin^2\theta$$ Using $\sin^2\theta = 1 - \cos^2\theta$: $$|\vec{a} \times \vec{b}|^2 = |\vec{a}|^2 |\vec{b}|^2 (1 - \cos^2\theta) = |\vec{a}|^2 |\vec{b}|^2 - |\vec{a}|^2 |\vec{b}|^2 \cos^2\theta$$ Since $\vec{a} \cdot \vec{b} = |\vec{a}||\vec{b}|\cos\theta$: $$(|\vec{a}||\vec{b}|\cos\theta)^2 = (\vec{a} \cdot \vec{b})^2$$ Therefore: $$\mathbf{|\vec{a} \times \vec{b}|^2 = |\vec{a}|^2 |\vec{b}|^2 - (\vec{a} \cdot \vec{b})^2}$$ Hence proved.

(ii) Area of Parallelogram with Diagonals $\vec{d_1}, \vec{d_2}$:

Formula: $\text{Area} = \frac{1}{2} |\vec{d_1} \times \vec{d_2}|$. $$\vec{d_1} \times \vec{d_2} = \begin{vmatrix} \hat{i} & \hat{j} & \hat{k} \\ 3 & 1 & -2 \\ 1 & -3 & 4 \end{vmatrix}$$ $$= \hat{i}(4 - 6) - \hat{j}(12 - (-2)) + \hat{k}(-9 - 1) = -2\hat{i} - 14\hat{j} - 10\hat{k}$$ Magnitude: $$|\vec{d_1} \times \vec{d_2}| = \sqrt{(-2)^2 + (-14)^2 + (-10)^2} = \sqrt{4 + 196 + 100} = \sqrt{300} = 10\sqrt{3}$$ Area: $$\text{Area} = \frac{1}{2}(10\sqrt{3}) = \mathbf{5\sqrt{3}\text{ sq. units}}$$
