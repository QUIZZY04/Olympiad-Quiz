Q1
Exercise 12.1 (Verbatim)
Maximize $Z = 3x + 4y$
subject to the constraints:
$$x + y \le 4, \quad x \ge 0, \quad y \ge 0$$
[3 Marks]
✅ CBSE Step-by-Step Mathematical Solution
Figure 12.1: Feasible Region $OAB$ bounded by $x + y \le 4, x \ge 0, y \ge 0$

Step 1: Feasible Region:

  • The non-negativity constraints $x \ge 0, y \ge 0$ restrict the region to the first quadrant.
  • Draw the boundary line $x + y = 4$:
    When $x = 0 \implies y = 4$, point $(0, 4)$.
    When $y = 0 \implies x = 4$, point $(4, 0)$.
  • Testing the origin $(0, 0)$: $0 + 0 = 0 \le 4$, which is true. Therefore, the half plane containing $(0, 0)$ is the solution region.
  • The feasible region $OAB$ is bounded by the polygon with vertices $O(0, 0)$, $A(4, 0)$, and $B(0, 4)$.

Step 2: Corner Point Table:

Corner Point Value of $Z = 3x + 4y$ Verdict
$O(0, 0)$ $3(0) + 4(0) = 0$ Minimum
$A(4, 0)$ $3(4) + 4(0) = 12$
$B(0, 4)$ $3(0) + 4(4) = 16$ Maximum

Conclusion:

The maximum value of $Z$ is $16$, which occurs at the point $(0, 4)$.

Exercise 12.1 (Verbatim)
Minimize $Z = -3x + 4y$
subject to:
$$x + 2y \le 8, \quad 3x + 2y \le 12, \quad x \ge 0, \quad y \ge 0$$
[4 Marks]
✅ CBSE Step-by-Step Mathematical Solution
Figure 12.2: Bounded quadrilateral feasible region $OABC$

Step 1: Constraint Lines and Intersection:

  1. Line $L_1 : x + 2y = 8$:
    Intercepts: $(8, 0)$ and $(0, 4)$. Origin $(0, 0)$ satisfies $0 \le 8$.
  2. Line $L_2 : 3x + 2y = 12$:
    Intercepts: $(4, 0)$ and $(0, 6)$. Origin $(0, 0)$ satisfies $0 \le 12$.
  3. Intersection of $L_1$ and $L_2$:
    Subtracting $L_1$ from $L_2$: $(3x + 2y) - (x + 2y) = 12 - 8 \implies 2x = 4 \implies x = 2$.
    From $L_1$: $2 + 2y = 8 \implies 2y = 6 \implies y = 3$.
    Point of intersection: $B(2, 3)$.

The bounded feasible region is quadrilateral $OABC$ where:

$$O(0, 0), \quad A(4, 0), \quad B(2, 3), \quad C(0, 4)$$

Step 2: Corner Point Table:

Corner Point Value of $Z = -3x + 4y$ Verdict
$O(0, 0)$ $-3(0) + 4(0) = 0$
$A(4, 0)$ $-3(4) + 4(0) = -12$ Minimum
$B(2, 3)$ $-3(2) + 4(3) = -6 + 12 = 6$
$C(0, 4)$ $-3(0) + 4(4) = 16$ Maximum

Conclusion:

The minimum value of $Z$ is $-12$ at the point $(4, 0)$.

Q3
Exercise 12.1 (Verbatim)
Maximize $Z = 5x + 3y$
subject to:
$$3x + 5y \le 15, \quad 5x + 2y \le 10, \quad x \ge 0, \quad y \ge 0$$
[4 Marks]
✅ CBSE Step-by-Step Mathematical Solution
Figure 12.3: Bounded polygon with intersection $B(20/19, 45/19)$

Step 1: Lines and Intersection:

  • Line $L_1 : 3x + 5y = 15$: Intercepts $(5, 0)$ and $(0, 3)$. Origin satisfies $0 \le 15$.
  • Line $L_2 : 5x + 2y = 10$: Intercepts $(2, 0)$ and $(0, 5)$. Origin satisfies $0 \le 10$.
  • Intersection of $L_1$ and $L_2$: $$2(3x + 5y) - 5(5x + 2y) = 2(15) - 5(10)$$ $$6x + 10y - 25x - 10y = 30 - 50 \implies -19x = -20 \implies x = \frac{20}{19}$$ Substitute into $5x + 2y = 10$: $$2y = 10 - 5\left(\frac{20}{19}\right) = 10 - \frac{100}{19} = \frac{90}{19} \implies y = \frac{45}{19}$$ Point of intersection: $B\left(\frac{20}{19}, \frac{45}{19}\right)$.

Feasible corner points are: $O(0, 0), \; A(2, 0), \; B\left(\frac{20}{19}, \frac{45}{19}\right), \; C(0, 3)$.

Step 2: Corner Point Table:

Corner Point Value of $Z = 5x + 3y$
$O(0, 0)$ $5(0) + 3(0) = 0$
$A(2, 0)$ $5(2) + 3(0) = 10$
$B\left(\frac{20}{19}, \frac{45}{19}\right)$ $5\left(\frac{20}{19}\right) + 3\left(\frac{45}{19}\right) = \frac{100 + 135}{19} = \frac{235}{19} \approx 12.37$ (Max)
$C(0, 3)$ $5(0) + 3(3) = 9$

Conclusion:

The maximum value of $Z$ is $\frac{235}{19}$ at the point $\left(\frac{20}{19}, \frac{45}{19}\right)$.

Q4
Exercise 12.1 (Verbatim)
Minimize $Z = 3x + 5y$
such that:
$$x + 3y \ge 3, \quad x + y \ge 2, \quad x, y \ge 0$$
[4 Marks]
✅ CBSE Step-by-Step Mathematical Solution
Figure 12.4: Unbounded feasible region and dotted validation line $3x + 5y = 7$

Step 1: Graphing Constraints & Feasible Region:

  • Line $L_1 : x + 3y = 3$: Intercepts $(3, 0)$ and $(0, 1)$. Since $0 + 0 ot\ge 3$, origin is excluded. Region lies away from origin.
  • Line $L_2 : x + y = 2$: Intercepts $(2, 0)$ and $(0, 2)$. Origin is excluded.
  • Intersection of $L_1$ and $L_2$: $$(x + 3y) - (x + y) = 3 - 2 \implies 2y = 1 \implies y = \frac{1}{2}$$ $$x = 2 - y = 2 - \frac{1}{2} = \frac{3}{2}$$ Intersection point: $B\left(\frac{3}{2}, \frac{1}{2}\right)$.
  • The feasible region is unbounded with corner points $A(3, 0)$, $B\left(\frac{3}{2}, \frac{1}{2}\right)$, and $C(0, 2)$.

Step 2: Corner Point Table:

Corner Point Value of $Z = 3x + 5y$
$A(3, 0)$ $3(3) + 5(0) = 9$
$B\left(\frac{3}{2}, \frac{1}{2}\right)$ $3\left(\frac{3}{2}\right) + 5\left(\frac{1}{2}\right) = \frac{9 + 5}{2} = 7$ (Candidate Min)
$C(0, 2)$ $3(0) + 5(2) = 10$

Step 3: Validation for Unbounded Region:

Since the feasible region is unbounded, we must check whether the open half plane: $$3x + 5y < 7$$ has any points in common with the feasible region.
  • Draw the dotted line $3x + 5y = 7$.
    When $x = 0 \implies y = 1.4$. When $y = 0 \implies x = 7/3 \approx 2.33$.
  • Test $(0, 0)$: $0 < 7$ is true, so the open half plane lies strictly below the line $3x + 5y = 7$.
  • Observing the graph, the open half plane $3x + 5y < 7$ has no common point with the feasible region.

Conclusion:

The minimum value of $Z$ is $7$ at the point $\left(\frac{3}{2}, \frac{1}{2}\right)$.

Q5
Exercise 12.1 (Verbatim)
Minimize $Z = x + 2y$
subject to:
$$2x + y \ge 3, \quad x + 2y \ge 6, \quad x, y \ge 0$$ Show that the minimum of $Z$ occurs at more than two points.
[4 Marks]
✅ CBSE Step-by-Step Mathematical Solution
Figure 12.5: Line segment $AB$ of optimal points giving $Z = 6$

Step 1: Constraint Lines & Corners:

  • Line $L_1 : 2x + y = 3$: Intercepts $(1.5, 0)$ and $(0, 3)$. Half plane away from $(0, 0)$.
  • Line $L_2 : x + 2y = 6$: Intercepts $(6, 0)$ and $(0, 3)$. Half plane away from $(0, 0)$.
  • Intersection of $L_1$ and $L_2$:
    From $L_1$, $y = 3 - 2x$.
    Substitute into $L_2$: $x + 2(3 - 2x) = 6 \implies x + 6 - 4x = 6 \implies -3x = 0 \implies x = 0, y = 3$.
    The two lines intersect on the y-axis at $(0, 3)$.
  • Feasible region is unbounded with corner points: $$A(6, 0) \quad \text{and} \quad B(0, 3)$$

Step 2: Value of $Z = x + 2y$ at Corners:

  • At $A(6, 0)$: $Z = 6 + 2(0) = \mathbf{6}$
  • At $B(0, 3)$: $Z = 0 + 2(3) = \mathbf{6}$

Step 3: Verification of Unbounded Region:

Draw open half plane $x + 2y < 6$.
The line $x + 2y = 6$ is one of the boundary lines of the feasible region itself!
The open inequality $x + 2y < 6$ has no points in common with the feasible region $x + 2y \ge 6$.
Therefore, the minimum value of $Z$ is $6$.

Conclusion:

Since the minimum value $Z = 6$ is attained at two distinct corner points $A(6, 0)$ and $B(0, 3)$, by the fundamental theorem of LPP, $Z$ attains the same minimum value $6$ at every single point on the line segment joining $A(6, 0)$ and $B(0, 3)$.
Hence, the minimum occurs at infinitely many points (more than two points).

Q6
Exercise 12.1 (Verbatim)
Minimize and Maximize $Z = 5x + 10y$
subject to:
$$x + 2y \le 120, \quad x + y \ge 60, \quad x - 2y \ge 0, \quad x, y \ge 0$$
[4 Marks]
✅ CBSE Step-by-Step Mathematical Solution
Figure 12.6: Bounded quadrilateral feasible polygon $ABCD$

Step 1: Constraint Lines & Intersection:

  1. $L_1 : x + 2y = 120$: Passes through $(120, 0)$ and $(0, 60)$. Origin $(0,0)$ satisfies $0 \le 120$.
  2. $L_2 : x + y = 60$: Passes through $(60, 0)$ and $(0, 60)$. Origin $(0, 0)$ does not satisfy $0 \not\ge 60$.
  3. $L_3 : x - 2y = 0 \implies x = 2y$: Line through origin passing through $(60, 30), (120, 60)$. Test point $(10, 0)$: $10 - 0 = 10 \ge 0$, region lies towards positive x-axis.

Step 2: Finding Corner Points:

  • Intersection of $x + y = 60$ and $x - 2y = 0$:
    $2y + y = 60 \implies 3y = 60 \implies y = 20, x = 40$. Point $A(40, 20)$.
  • Intersection of $x + 2y = 120$ and $x - 2y = 0$:
    $2y + 2y = 120 \implies 4y = 120 \implies y = 30, x = 60$. Point $B(60, 30)$.
  • Intersection of $x + 2y = 120$ with x-axis ($y = 0$): Point $C(120, 0)$.
  • Intersection of $x + y = 60$ with x-axis ($y = 0$): Point $D(60, 0)$.

The bounded feasible region is polygon $ABCD$.

Step 3: Corner Point Table:

Corner Point Value of $Z = 5x + 10y$ Verdict
$A(40, 20)$ $5(40) + 10(20) = 200 + 200 = 400$
$B(60, 30)$ $5(60) + 10(30) = 300 + 300 = 600$ Maximum
$C(120, 0)$ $5(120) + 10(0) = 600$ Maximum
$D(60, 0)$ $5(60) + 10(0) = 300$ Minimum

Conclusion:

  • The minimum value of $Z$ is $300$ at the point $(60, 0)$.
  • The maximum value of $Z$ is $600$ at all points on the line segment joining $(60, 30)$ and $(120, 0)$.

Exercise 12.1 (Verbatim)
Minimize and Maximize $Z = x + 2y$
subject to:
$$x + 2y \ge 100, \quad 2x - y \le 0, \quad 2x + y \le 200, \quad x, y \ge 0$$
[5 Marks]
✅ CBSE Step-by-Step Mathematical Solution
Figure 12.7: Bounded feasible region $ABCD$ with y-axis boundary

Step 1: Lines and Intersection:

  1. $L_1 : x + 2y = 100$: Passes through $(100, 0)$ and $(0, 50)$. Region lies away from origin.
  2. $L_2 : 2x - y = 0 \implies y = 2x$: Passes through origin and $(50, 100)$. Test point $(0, 10)$: $2(0) - 10 = -10 \le 0$ (true, region lies above line).
  3. $L_3 : 2x + y = 200$: Passes through $(100, 0)$ and $(0, 200)$. Region lies towards origin.

Step 2: Finding Corner Points of the Feasible Polygon:

  • Intersection of $x + 2y = 100$ and $2x - y = 0$ ($y = 2x$):
    $x + 2(2x) = 100 \implies 5x = 100 \implies x = 20, y = 40$. Point $A(20, 40)$.
  • Intersection of $2x - y = 0$ and $2x + y = 200$:
    $2x + 2x = 200 \implies 4x = 200 \implies x = 50, y = 100$. Point $B(50, 100)$.
  • Intersection of $2x + y = 200$ and y-axis: Point $C(0, 200)$.
  • Intersection of $x + 2y = 100$ and y-axis: Point $D(0, 50)$.

The four corner points are: $A(20, 40), \; B(50, 100), \; C(0, 200), \; D(0, 50)$.

Step 3: Corner Point Table:

Corner Point Value of $Z = x + 2y$ Verdict
$A(20, 40)$ $20 + 2(40) = 100$ Minimum
$B(50, 100)$ $50 + 2(100) = 250$
$C(0, 200)$ $0 + 2(200) = 400$ Maximum
$D(0, 50)$ $0 + 2(50) = 100$ Minimum

Conclusion:

  • The maximum value of $Z$ is $400$ at $(0, 200)$.
  • The minimum value of $Z$ is $100$ at all points on the line segment joining $(20, 40)$ and $(0, 50)$.

Q8
Exercise 12.1 (Verbatim)
Maximize $Z = -x + 2y$, subject to the constraints:
$$x \ge 3, \quad x + y \ge 5, \quad x + 2y \ge 6, \quad y \ge 0$$
[4 Marks]
✅ CBSE Step-by-Step Mathematical Solution
Figure 12.8: Unbounded region & dashed test line $-x + 2y = 1$ intersecting the region

Step 1: Constraint Lines & Graphing:

  • $x \ge 3$: Vertical line $x = 3$. Half plane to the right.
  • $x + y \ge 5$: Intercepts $(5, 0)$ and $(0, 5)$. Half plane away from origin.
  • $x + 2y \ge 6$: Intercepts $(6, 0)$ and $(0, 3)$. Half plane away from origin.
  • Intersection of $x = 3$ and $x + y = 5$: $x = 3, y = 2$. Point $A(3, 2)$.
  • Intersection of $x + y = 5$ and $x + 2y = 6$:
    $(x + 2y) - (x + y) = 6 - 5 \implies y = 1, x = 4$. Point $B(4, 1)$.
  • Intersection of $x + 2y = 6$ with x-axis ($y = 0$): Point $C(6, 0)$.

The feasible region is unbounded with corner points $A(3, 2), \; B(4, 1), \; C(6, 0)$ and extending infinitely as $x, y \to \infty$.

Step 2: Corner Point Table:

Corner Point Value of $Z = -x + 2y$
$A(3, 2)$ $-(3) + 2(2) = 1$
$B(4, 1)$ $-(4) + 2(1) = -2$
$C(6, 0)$ $-(6) + 2(0) = -6$

The maximum value among corner points is $M = 1$ at $(3, 2)$.

Step 3: Verification for Unbounded Region:

We draw the open half plane: $$-x + 2y > 1$$ Notice that point $(3, 3)$ lies in the feasible region because: $$3 \ge 3, \quad 3 + 3 = 6 \ge 5, \quad 3 + 2(3) = 9 \ge 6$$ Now evaluate $-x + 2y$ at $(3, 3)$: $$-3 + 2(3) = 3 > 1$$ Indeed, for any point $(3, y)$ with $y > 2$, $-3 + 2y$ can be made arbitrarily large!
The open half plane $-x + 2y > 1$ has infinitely many points in common with the feasible region.
Conclusion: $Z$ has NO MAXIMUM VALUE subject to the given constraints.

Q9
Exercise 12.1 (Verbatim)
Maximize $Z = x + y$, subject to:
$$x - y \le -1, \quad -x + y \le 0, \quad x, y \ge 0$$
[3 Marks]
✅ CBSE Step-by-Step Mathematical Solution
Figure 12.9: Parallel boundary lines with disjoint half-planes (Empty Feasible Region)

Step 1: Analysis of Constraints:

  1. Constraint 1: $x - y \le -1 \implies y - x \ge 1 \implies y \ge x + 1$.
    This half plane lies strictly on and above the line $y = x + 1$.
  2. Constraint 2: $-x + y \le 0 \implies y \le x$.
    This half plane lies strictly on and below the line $y = x$.
  3. Non-negativity: $x \ge 0, \; y \ge 0$.

Step 2: Checking for Common Region:

  • The line $y = x + 1$ and the line $y = x$ are two parallel lines with identical slope $m = 1$.
  • The vertical distance between them is $1$ unit.
  • Constraint 1 requires all points to lie on or above $y = x + 1$ ($y - x \ge 1$).
  • Constraint 2 requires all points to lie on or below $y = x$ ($y - x \le 0$).

There are no points $(x, y)$ in the coordinate plane that can simultaneously satisfy $y - x \ge 1$ and $y - x \le 0$.
The intersection of the half-planes is the empty set ($\emptyset$).

Conclusion:

There is no feasible region. Hence, there exists no maximum value of $Z$.

Q10
NCERT Chapter 12 Landmark Word Problem
A merchant plans to sell two types of personal computers — a desktop model and a portable model that will cost ₹$25{,}000$ and ₹$40{,}000$ respectively. He estimates that the total monthly demand of computers will not exceed $250$ units. Determine the number of units of each type of computers which the merchant should stock to get maximum profit if he does not want to invest more than ₹$70\text{ lakhs}$ and if his profit on the desktop model is ₹$4{,}500$ and on portable model is ₹$5{,}000$. Formulate this problem as an LPP and solve it graphically.
[5 Marks]
✅ CBSE Step-by-Step Mathematical Solution
Figure 12.10: Feasible polygon $OABC$ with optimal profit corner $B(200, 50)$

Step 1: Mathematical Formulation:

Let $x$ be the number of desktop models and $y$ be the number of portable models stocked.
  • Objective Function: Maximize total profit: $$Z = 4500x + 5000y$$
  • Constraints:
    1. Investment constraint: $25000x + 40000y \le 70{,}00{,}000$.
      Divide by $5000$: $$5x + 8y \le 1400$$
    2. Storage / demand constraint: $$x + y \le 250$$
    3. Non-negativity: $x \ge 0, \; y \ge 0$.

Step 2: Finding Corner Points of Feasible Region:

  • Line $L_1 : 5x + 8y = 1400$:
    When $x = 0 \implies y = 175$, point $(0, 175)$.
    When $y = 0 \implies x = 280$, point $(280, 0)$.
  • Line $L_2 : x + y = 250$:
    When $x = 0 \implies y = 250$, point $(0, 250)$.
    When $y = 0 \implies x = 250$, point $(250, 0)$.
  • Intersection of $L_1$ and $L_2$:
    Multiply $L_2$ by 5: $5x + 5y = 1250$.
    Subtract from $L_1$: $(5x + 8y) - (5x + 5y) = 1400 - 1250 \implies 3y = 150 \implies y = 50$.
    Then $x = 250 - 50 = 200$.
    Point of intersection: $B(200, 50)$.

The bounded feasible region has vertices: $O(0, 0), \; A(250, 0), \; B(200, 50), \; C(0, 175)$.

Step 3: Corner Point Table:

Corner Point Profit $Z = 4500x + 5000y$ (in ₹)
$O(0, 0)$ $0$
$A(250, 0)$ $4500(250) + 0 = 11{,}25{,}000$
$B(200, 50)$ $4500(200) + 5000(50) = 9{,}00{,}000 + 2{,}50{,}000 = 11{,}50{,}000$ (Max)
$C(0, 175)$ $0 + 5000(175) = 8{,}75{,}000$

Final Answer:

The merchant should stock $200$ desktop models and $50$ portable models to obtain a maximum profit of ₹$11{,}50{,}000$.
