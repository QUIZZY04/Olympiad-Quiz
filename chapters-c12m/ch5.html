Q1
Exercise 5.1 (Verbatim)
(i) Prove that the function $f(x) = 5x - 3$ is continuous at $x = 0$, at $x = -3$ and at $x = 5$.
(ii) Examine the continuity of the function $f(x) = 2x^2 - 1$ at $x = 3$.
[3 Marks]
✅ CBSE Step-by-Step Mathematical Solution

(i) Function $f(x) = 5x - 3$:

  1. At $x = 0$:
    $f(0) = 5(0) - 3 = -3$.
    $\lim_{x \to 0} f(x) = \lim_{x \to 0} (5x - 3) = 5(0) - 3 = -3$.
    Since $\lim_{x \to 0} f(x) = f(0) = -3$, $f(x)$ is continuous at $x = 0$.
  2. At $x = -3$:
    $f(-3) = 5(-3) - 3 = -15 - 3 = -18$.
    $\lim_{x \to -3} f(x) = \lim_{x \to -3} (5x - 3) = 5(-3) - 3 = -18$.
    Since $\lim_{x \to -3} f(x) = f(-3) = -18$, $f(x)$ is continuous at $x = -3$.
  3. At $x = 5$:
    $f(5) = 5(5) - 3 = 25 - 3 = 22$.
    $\lim_{x \to 5} f(x) = \lim_{x \to 5} (5x - 3) = 5(5) - 3 = 22$.
    Since $\lim_{x \to 5} f(x) = f(5) = 22$, $f(x)$ is continuous at $x = 5$.

(ii) Function $f(x) = 2x^2 - 1$ at $x = 3$:

  • Value of function: $f(3) = 2(3)^2 - 1 = 2(9) - 1 = 18 - 1 = 17$.
  • Limit: $\lim_{x \to 3} f(x) = \lim_{x \to 3} (2x^2 - 1) = 2(3)^2 - 1 = 17$.
  • Since $\lim_{x \to 3} f(x) = f(3) = 17$, $f(x)$ is continuous at $x = 3$.

Q2
Exercise 5.1 (Verbatim)
Find all points of discontinuity of $f$, where $f$ is defined by:
(i) $f(x) = \begin{cases} 2x + 3, & \text{if } x \le 2 \\ 2x - 3, & \text{if } x > 2 \end{cases}$
(ii) $f(x) = \begin{cases} |x| + 3, & \text{if } x \le -3 \\ -2x, & \text{if } -3 < x < 3 \\ 6x + 2, & \text{if } x \ge 3 \end{cases}$
[4 Marks]
✅ CBSE Step-by-Step Mathematical Solution

(i) $f(x) = \begin{cases} 2x + 3, & x \le 2 \\ 2x - 3, & x > 2 \end{cases}$:

For $x < 2$ and $x > 2$, $f(x)$ is a polynomial and hence continuous. We check continuity at the partition point $x = 2$:

  • $f(2) = 2(2) + 3 = 7$.
  • LHL: $\lim_{x \to 2^-} f(x) = \lim_{h \to 0} [2(2 - h) + 3] = 4 + 3 = 7$.
  • RHL: $\lim_{x \to 2^+} f(x) = \lim_{h \to 0} [2(2 + h) - 3] = 4 - 3 = 1$.

Since $\text{LHL} \neq \text{RHL}$ ($7 \neq 1$), $\lim_{x \to 2} f(x)$ does not exist.
Therefore, $x = 2$ is the only point of discontinuity.

(ii) $f(x) = \begin{cases} |x| + 3, & x \le -3 \\ -2x, & -3 < x < 3 \\ 6x + 2, & x \ge 3 \end{cases}$:

Since $|x| = -x$ for $x \le -3$, we write: $$f(x) = \begin{cases} -x + 3, & x \le -3 \\ -2x, & -3 < x < 3 \\ 6x + 2, & x \ge 3 \end{cases}$$

  1. At $x = -3$:
    • $f(-3) = -(-3) + 3 = 6$.
    • $\text{LHL} = \lim_{x \to -3^-} (-x + 3) = -(-3) + 3 = 6$.
    • $\text{RHL} = \lim_{x \to -3^+} (-2x) = -2(-3) = 6$.
    • Since $\text{LHL} = \text{RHL} = f(-3) = 6$, $f$ is continuous at $x = -3$.
  2. At $x = 3$:
    • $f(3) = 6(3) + 2 = 20$.
    • $\text{LHL} = \lim_{x \to 3^-} (-2x) = -2(3) = -6$.
    • $\text{RHL} = \lim_{x \to 3^+} (6x + 2) = 6(3) + 2 = 20$.
    • Since $\text{LHL} \neq \text{RHL}$ ($-6 \neq 20$), $f$ is discontinuous at $x = 3$.

Conclusion: $x = 3$ is the only point of discontinuity of $f$.

Q3
Exercise 5.1 (Verbatim)
(i) Find the relationship between $a$ and $b$ so that the function $f$ defined by: $$f(x) = \begin{cases} ax + 1, & \text{if } x \le 3 \\ bx + 3, & \text{if } x > 3 \end{cases}$$ is continuous at $x = 3$.

(ii) Find the value of $k$ so that the function $f$ is continuous at $x = \frac{\pi}{2}$: $$f(x) = \begin{cases} \frac{k \cos x}{\pi - 2x}, & \text{if } x \neq \frac{\pi}{2} \\[6pt] 3, & \text{if } x = \frac{\pi}{2} \end{cases}$$
[4 Marks]
✅ CBSE Step-by-Step Mathematical Solution

(i) Relation between $a$ and $b$ for continuity at $x = 3$:

Given that $f$ is continuous at $x = 3$, we must have: $$\lim_{x \to 3^-} f(x) = \lim_{x \to 3^+} f(x) = f(3)$$
  1. $f(3) = a(3) + 1 = 3a + 1$.
  2. $\text{LHL} = \lim_{x \to 3^-} (ax + 1) = 3a + 1$.
  3. $\text{RHL} = \lim_{x \to 3^+} (bx + 3) = 3b + 3$.
Equating LHL and RHL: $$3a + 1 = 3b + 3$$ $$3a - 3b = 2 \implies 3(a - b) = 2 \implies a - b = \frac{2}{3} \implies \mathbf{a = b + \frac{2}{3}}$$

(ii) Finding $k$ for continuity at $x = \frac{\pi}{2}$:

Given $f\left(\frac{\pi}{2}\right) = 3$. For $f$ to be continuous at $x = \frac{\pi}{2}$: $$\lim_{x \to \pi/2} f(x) = f\left(\frac{\pi}{2}\right) = 3$$ Evaluate the limit: $$\lim_{x \to \pi/2} \frac{k \cos x}{\pi - 2x}$$ Put $x = \frac{\pi}{2} + h$. As $x \to \frac{\pi}{2}$, $h \to 0$: $$\cos x = \cos\left(\frac{\pi}{2} + h\right) = -\sin h$$ $$\pi - 2x = \pi - 2\left(\frac{\pi}{2} + h\right) = \pi - \pi - 2h = -2h$$ Substitute into the limit: $$\lim_{h \to 0} \frac{k(-\sin h)}{-2h} = \frac{k}{2} \lim_{h \to 0} \frac{\sin h}{h} = \frac{k}{2} \times 1 = \frac{k}{2}$$ Since the limit must equal $f(\pi/2) = 3$: $$\frac{k}{2} = 3 \implies \mathbf{k = 6}$$

Q4
Exercise 5.2 (Verbatim)
(i) Prove that the function $f$ given by $f(x) = |x - 1|, \; x \in \mathbb{R}$ is not differentiable at $x = 1$.
(ii) Prove that the greatest integer function defined by $f(x) = [x], \; 0 < x < 3$ is not differentiable at $x = 1$ and $x = 2$.
[4 Marks]
✅ CBSE Step-by-Step Mathematical Solution

(i) Non-differentiability of $f(x) = |x - 1|$ at $x = 1$:

By definition: $$f(x) = \begin{cases} -(x - 1) = 1 - x, & x < 1 \\ x - 1, & x \ge 1 \end{cases}$$ Here $f(1) = |1 - 1| = 0$.
  1. Left Hand Derivative (LHD) at $x = 1$: $$\text{LHD} = \lim_{h \to 0^-} \frac{f(1 + h) - f(1)}{h} = \lim_{h \to 0^-} \frac{|1 + h - 1| - 0}{h} = \lim_{h \to 0^-} \frac{|h|}{h}$$ Since $h < 0$, $|h| = -h$: $$\text{LHD} = \lim_{h \to 0^-} \frac{-h}{h} = -1$$
  2. Right Hand Derivative (RHD) at $x = 1$: $$\text{RHD} = \lim_{h \to 0^+} \frac{f(1 + h) - f(1)}{h} = \lim_{h \to 0^+} \frac{|h|}{h}$$ Since $h > 0$, $|h| = h$: $$\text{RHD} = \lim_{h \to 0^+} \frac{h}{h} = 1$$
Since $\text{LHD} \neq \text{RHD}$ ($-1 \neq 1$), $f(x)$ is not differentiable at $x = 1$.

(ii) Non-differentiability of $f(x) = [x]$ at $x = 1$:

$f(1) = [1] = 1$.
  1. LHD at $x = 1$: $$\text{LHD} = \lim_{h \to 0^-} \frac{f(1 + h) - f(1)}{h} = \lim_{h \to 0^-} \frac{[1 + h] - 1}{h}$$ For $h \to 0^-$, $1 + h < 1$ (e.g. $1 - 0.01 = 0.99$), so $[1 + h] = 0$: $$\text{LHD} = \lim_{h \to 0^-} \frac{0 - 1}{h} = \lim_{h \to 0^-} \frac{-1}{h} = +\infty$$
  2. RHD at $x = 1$: For $h \to 0^+$, $1 + h > 1$ (e.g. $1.01$), so $[1 + h] = 1$: $$\text{RHD} = \lim_{h \to 0^+} \frac{1 - 1}{h} = 0$$
Since $\text{LHD} \neq \text{RHD}$, $f$ is not differentiable at $x = 1$.
(By identical steps, at $x = 2$, $\text{LHD} \to \infty$ and $\text{RHD} = 0$, so $f$ is not differentiable at $x = 2$).

Q5
Exercise 5.3 (Verbatim)
Find $\frac{dy}{dx}$ in the following:
(i) $2x + 3y = \sin x$
(ii) $xy + y^2 = \tan x + y$
(iii) $\sin^2 x + \cos^2 y = 1$
[4 Marks]
✅ CBSE Step-by-Step Mathematical Solution

(i) $2x + 3y = \sin x$:

Differentiating both sides with respect to $x$: $$\frac{d}{dx}(2x) + \frac{d}{dx}(3y) = \frac{d}{dx}(\sin x)$$ $$2 + 3\frac{dy}{dx} = \cos x$$ $$3\frac{dy}{dx} = \cos x - 2 \implies \mathbf{\frac{dy}{dx} = \frac{\cos x - 2}{3}}$$

(ii) $xy + y^2 = \tan x + y$:

Differentiating with respect to $x$ (applying product rule on $xy$): $$\left(x \frac{dy}{dx} + y \cdot 1\right) + 2y \frac{dy}{dx} = \sec^2 x + \frac{dy}{dx}$$ Collecting terms containing $\frac{dy}{dx}$ on LHS: $$x \frac{dy}{dx} + 2y \frac{dy}{dx} - \frac{dy}{dx} = \sec^2 x - y$$ $$(x + 2y - 1) \frac{dy}{dx} = \sec^2 x - y$$ $$\mathbf{\frac{dy}{dx} = \frac{\sec^2 x - y}{x + 2y - 1}}$$

(iii) $\sin^2 x + \cos^2 y = 1$:

Differentiating with respect to $x$ using the chain rule: $$2\sin x \frac{d}{dx}(\sin x) + 2\cos y \frac{d}{dx}(\cos y) = 0$$ $$2\sin x \cos x + 2\cos y \left(-\sin y \frac{dy}{dx}\right) = 0$$ $$\sin 2x - \sin 2y \frac{dy}{dx} = 0$$ $$\sin 2y \frac{dy}{dx} = \sin 2x \implies \mathbf{\frac{dy}{dx} = \frac{\sin 2x}{\sin 2y}}$$

Q6
Exercise 5.3 (Verbatim)
Find $\frac{dy}{dx}$ in the following:
(i) $y = \sin^{-1}\left(\frac{2x}{1 + x^2}\right)$
(ii) $y = \tan^{-1}\left(\frac{3x - x^3}{1 - 3x^2}\right), \; -\frac{1}{\sqrt{3}} < x < \frac{1}{\sqrt{3}}$
(iii) $y = \cos^{-1}\left(\frac{2x}{1 + x^2}\right), \; -1 < x < 1$
[4 Marks]
✅ CBSE Step-by-Step Mathematical Solution

(i) $y = \sin^{-1}\left(\frac{2x}{1 + x^2}\right)$:

Let $x = \tan\theta \implies \theta = \tan^{-1} x$. $$y = \sin^{-1}\left(\frac{2\tan\theta}{1 + \tan^2\theta}\right) = \sin^{-1}(\sin 2\theta) = 2\theta = 2\tan^{-1} x$$ Differentiating with respect to $x$: $$\mathbf{\frac{dy}{dx} = \frac{2}{1 + x^2}}$$

(ii) $y = \tan^{-1}\left(\frac{3x - x^3}{1 - 3x^2}\right)$:

Let $x = \tan\theta \implies \theta = \tan^{-1} x$.
Given $-\frac{1}{\sqrt{3}} < x < \frac{1}{\sqrt{3}} \implies -\frac{\pi}{6} < \theta < \frac{\pi}{6} \implies -\frac{\pi}{2} < 3\theta < \frac{\pi}{2}$. $$y = \tan^{-1}\left(\frac{3\tan\theta - \tan^3\theta}{1 - 3\tan^2\theta}\right) = \tan^{-1}(\tan 3\theta) = 3\theta = 3\tan^{-1} x$$ Differentiating with respect to $x$: $$\mathbf{\frac{dy}{dx} = \frac{3}{1 + x^2}}$$

(iii) $y = \cos^{-1}\left(\frac{2x}{1 + x^2}\right)$:

Let $x = \tan\theta \implies \theta = \tan^{-1} x$. $$y = \cos^{-1}(\sin 2\theta) = \cos^{-1}\left(\cos\left(\frac{\pi}{2} - 2\theta\right)\right) = \frac{\pi}{2} - 2\theta = \frac{\pi}{2} - 2\tan^{-1} x$$ Differentiating with respect to $x$: $$\mathbf{\frac{dy}{dx} = 0 - 2\left(\frac{1}{1 + x^2}\right) = -\frac{2}{1 + x^2}}$$

Q7
Exercise 5.4 (Verbatim)
Differentiate the following with respect to $x$:
(i) $\frac{e^x}{\sin x}$
(ii) $\sin(\tan^{-1}(e^{-x}))$
(iii) $\log(\log x), \; x > 1$
(iv) $\sqrt{e^{\sqrt{x}}}, \; x > 0$
[4 Marks]
✅ CBSE Step-by-Step Mathematical Solution

(i) $y = \frac{e^x}{\sin x}$:

Using quotient rule $\frac{d}{dx}\left(\frac{u}{v}\right) = \frac{v u' - u v'}{v^2}$: $$\frac{dy}{dx} = \frac{\sin x \frac{d}{dx}(e^x) - e^x \frac{d}{dx}(\sin x)}{\sin^2 x} = \frac{\sin x (e^x) - e^x (\cos x)}{\sin^2 x} = \mathbf{\frac{e^x (\sin x - \cos x)}{\sin^2 x}}$$

(ii) $y = \sin(\tan^{-1}(e^{-x}))$:

Applying chain rule step-by-step: $$\frac{dy}{dx} = \cos(\tan^{-1}(e^{-x})) \cdot \frac{d}{dx}(\tan^{-1}(e^{-x}))$$ $$= \cos(\tan^{-1}(e^{-x})) \cdot \frac{1}{1 + (e^{-x})^2} \cdot \frac{d}{dx}(e^{-x})$$ $$= \cos(\tan^{-1}(e^{-x})) \cdot \frac{1}{1 + e^{-2x}} \cdot (-e^{-x}) = \mathbf{-\frac{e^{-x} \cos(\tan^{-1}(e^{-x}))}{1 + e^{-2x}}}$$

(iii) $y = \log(\log x)$:

$$\frac{dy}{dx} = \frac{1}{\log x} \cdot \frac{d}{dx}(\log x) = \frac{1}{\log x} \cdot \frac{1}{x} = \mathbf{\frac{1}{x \log x}}$$

(iv) $y = \sqrt{e^{\sqrt{x}}} = (e^{\sqrt{x}})^{1/2} = e^{\frac{1}{2}\sqrt{x}}$:

$$\frac{dy}{dx} = e^{\frac{1}{2}\sqrt{x}} \cdot \frac{d}{dx}\left(\frac{1}{2} x^{1/2}\right) = e^{\frac{1}{2}\sqrt{x}} \cdot \frac{1}{4\sqrt{x}} = \mathbf{\frac{\sqrt{e^{\sqrt{x}}}}{4\sqrt{x}}}$$

(ii) Three-link chain rule application yielding -e⁻ˣ cos(tan⁻¹(e⁻ˣ))/(1 + e⁻²ˣ)1 Mark
(iii) Derivative of log(log x) = 1/(x log x)1 Mark

Q8
Exercise 5.5 (Verbatim)
Differentiate with respect to $x$:
(i) $\cos x \cdot \cos 2x \cdot \cos 3x$
(ii) $x^x - 2^{\sin x}$
[4 Marks]
✅ CBSE Step-by-Step Mathematical Solution

(i) $y = \cos x \cdot \cos 2x \cdot \cos 3x$:

Taking natural logarithm on both sides: $$\log y = \log(\cos x) + \log(\cos 2x) + \log(\cos 3x)$$ Differentiating with respect to $x$: $$\frac{1}{y} \frac{dy}{dx} = \frac{1}{\cos x}(-\sin x) + \frac{1}{\cos 2x}(-2\sin 2x) + \frac{1}{\cos 3x}(-3\sin 3x)$$ $$\frac{1}{y} \frac{dy}{dx} = -\tan x - 2\tan 2x - 3\tan 3x$$ $$\mathbf{\frac{dy}{dx} = -(\cos x \cos 2x \cos 3x) [\tan x + 2\tan 2x + 3\tan 3x]}$$

(ii) $y = x^x - 2^{\sin x}$:

(CBSE Crucial Rule: NEVER take log of a difference directly as $\log(u - v) \neq \log u - \log v$. We must split into $y = u - v$)

Let $u = x^x$ and $v = 2^{\sin x}$. Then $y = u - v \implies \frac{dy}{dx} = \frac{du}{dx} - \frac{dv}{dx}$.
  1. For $u = x^x$:
    $\log u = x \log x$.
    $\frac{1}{u} \frac{du}{dx} = x \cdot \frac{1}{x} + \log x \cdot 1 = 1 + \log x$.
    $\frac{du}{dx} = x^x (1 + \log x)$.
  2. For $v = 2^{\sin x}$:
    Using standard formula $\frac{d}{dx}(a^z) = a^z (\ln a) \frac{dz}{dx}$:
    $\frac{dv}{dx} = 2^{\sin x} (\log 2) \cdot \frac{d}{dx}(\sin x) = 2^{\sin x} (\cos x) \log 2$.
Combining both parts: $$\mathbf{\frac{dy}{dx} = x^x (1 + \log x) - 2^{\sin x} (\cos x) \log 2}$$

Q9
Exercise 5.5 (Verbatim)
(i) Differentiate $(\log x)^x + x^{\log x}$ with respect to $x$.
(ii) Find $\frac{dy}{dx}$ if $x^y + y^x = 1$.
[5 Marks]
✅ CBSE Step-by-Step Mathematical Solution

(i) $y = (\log x)^x + x^{\log x}$:

Let $y = u + v$, where $u = (\log x)^x$ and $v = x^{\log x}$.
  1. For $u = (\log x)^x$:
    $\log u = x \log(\log x)$.
    $\frac{1}{u} \frac{du}{dx} = x \cdot \frac{1}{\log x} \cdot \frac{1}{x} + \log(\log x) \cdot 1 = \frac{1}{\log x} + \log(\log x)$.
    $$\frac{du}{dx} = (\log x)^x \left[ \frac{1}{\log x} + \log(\log x) \right]$$
  2. For $v = x^{\log x}$:
    $\log v = (\log x) \log x = (\log x)^2$.
    $\frac{1}{v} \frac{dv}{dx} = 2\log x \cdot \frac{1}{x} = \frac{2\log x}{x}$.
    $$\frac{dv}{dx} = x^{\log x} \left( \frac{2\log x}{x} \right) = 2x^{\log x - 1} \log x$$
$$\mathbf{\frac{dy}{dx} = (\log x)^x \left[ \frac{1}{\log x} + \log(\log x) \right] + 2x^{\log x - 1} \log x}$$

(ii) $x^y + y^x = 1$:

Let $u = x^y$ and $v = y^x$. Then $u + v = 1 \implies \frac{du}{dx} + \frac{dv}{dx} = 0$.
  1. $u = x^y \implies \log u = y \log x$.
    $\frac{1}{u} \frac{du}{dx} = y \cdot \frac{1}{x} + \log x \frac{dy}{dx} \implies \frac{du}{dx} = x^y \left[ \frac{y}{x} + \log x \frac{dy}{dx} \right] = y x^{y-1} + x^y \log x \frac{dy}{dx}$.
  2. $v = y^x \implies \log v = x \log y$.
    $\frac{1}{v} \frac{dv}{dx} = x \cdot \frac{1}{y} \frac{dy}{dx} + \log y \cdot 1 \implies \frac{dv}{dx} = y^x \left[ \frac{x}{y} \frac{dy}{dx} + \log y \right] = x y^{x-1} \frac{dy}{dx} + y^x \log y$.
Substituting into $\frac{du}{dx} + \frac{dv}{dx} = 0$: $$\left( y x^{y-1} + x^y \log x \frac{dy}{dx} \right) + \left( x y^{x-1} \frac{dy}{dx} + y^x \log y \right) = 0$$ $$\left( x^y \log x + x y^{x-1} \right) \frac{dy}{dx} = -\left( y x^{y-1} + y^x \log y \right)$$ $$\mathbf{\frac{dy}{dx} = -\frac{y x^{y-1} + y^x \log y}{x^y \log x + x y^{x-1}}}$$

Q10
Exercise 5.6 (Verbatim)
(i) Find $\frac{dy}{dx}$, if $x = a(\cos t + \log \tan(t/2))$ and $y = a \sin t$.
(ii) If $x = \sqrt{a^{\sin^{-1} t}}$ and $y = \sqrt{a^{\cos^{-1} t}}$, show that $\frac{dy}{dx} = -\frac{y}{x}$.
[4 Marks]
✅ CBSE Step-by-Step Mathematical Solution

(i) $x = a(\cos t + \log \tan(t/2))$ and $y = a \sin t$:

  1. Differentiate $y$ with respect to $t$: $$\frac{dy}{dt} = a \cos t$$
  2. Differentiate $x$ with respect to $t$: $$\frac{dx}{dt} = a \left[ -\sin t + \frac{1}{\tan(t/2)} \cdot \sec^2(t/2) \cdot \frac{1}{2} \right]$$ Simplify the second term: $$\frac{\sec^2(t/2)}{2\tan(t/2)} = \frac{1}{2 \cos^2(t/2) \frac{\sin(t/2)}{\cos(t/2)}} = \frac{1}{2\sin(t/2)\cos(t/2)} = \frac{1}{\sin t}$$ Thus: $$\frac{dx}{dt} = a \left[ -\sin t + \frac{1}{\sin t} \right] = a \left( \frac{1 - \sin^2 t}{\sin t} \right) = a \frac{\cos^2 t}{\sin t}$$
  3. Compute $\frac{dy}{dx}$: $$\frac{dy}{dx} = \frac{dy/dt}{dx/dt} = \frac{a \cos t}{a \frac{\cos^2 t}{\sin t}} = \frac{\sin t}{\cos t} = \mathbf{\tan t}$$

(ii) $x = \sqrt{a^{\sin^{-1} t}}$ and $y = \sqrt{a^{\cos^{-1} t}}$:

Elegant Method: Multiply $x$ and $y$ directly: $$xy = \sqrt{a^{\sin^{-1} t}} \cdot \sqrt{a^{\cos^{-1} t}} = \sqrt{a^{\sin^{-1} t + \cos^{-1} t}}$$ Since $\sin^{-1} t + \cos^{-1} t = \frac{\pi}{2}$ for all $t \in [-1, 1]$: $$xy = \sqrt{a^{\pi/2}} = \text{constant}$$ Now, differentiate both sides with respect to $x$ using product rule: $$x \frac{dy}{dx} + y(1) = 0$$ $$x \frac{dy}{dx} = -y \implies \mathbf{\frac{dy}{dx} = -\frac{y}{x}}$$ Hence proved.

Q11
Exercise 5.7 (Verbatim)
(i) If $y = 5\cos x - 3\sin x$, prove that $\frac{d^2y}{dx^2} + y = 0$.
(ii) If $y = 3\cos(\log x) + 4\sin(\log x)$, show that $x^2 y_2 + x y_1 + y = 0$.
[4 Marks]
✅ CBSE Step-by-Step Mathematical Solution

(i) $y = 5\cos x - 3\sin x$:

First derivative: $$\frac{dy}{dx} = 5(-\sin x) - 3(\cos x) = -5\sin x - 3\cos x$$ Second derivative: $$\frac{d^2y}{dx^2} = -5(\cos x) - 3(-\sin x) = -5\cos x + 3\sin x = -(5\cos x - 3\sin x) = -y$$ $$\frac{d^2y}{dx^2} + y = 0$$ Hence proved.

(ii) $y = 3\cos(\log x) + 4\sin(\log x)$:

Differentiating with respect to $x$ using chain rule: $$y_1 = \frac{dy}{dx} = -3\sin(\log x) \cdot \frac{1}{x} + 4\cos(\log x) \cdot \frac{1}{x}$$ Multiply both sides by $x$: $$x y_1 = -3\sin(\log x) + 4\cos(\log x)$$ Differentiating again with respect to $x$ using product rule on LHS: $$x y_2 + y_1 (1) = -3\cos(\log x) \cdot \frac{1}{x} - 4\sin(\log x) \cdot \frac{1}{x}$$ Multiply both sides by $x$ again: $$x(x y_2 + y_1) = -[3\cos(\log x) + 4\sin(\log x)]$$ $$x^2 y_2 + x y_1 = -y$$ $$\mathbf{x^2 y_2 + x y_1 + y = 0}$$ Hence proved.

Q12
Exercise 5.7 (Verbatim)
(i) If $y = A e^{mx} + B e^{nx}$, show that $\frac{d^2y}{dx^2} - (m + n)\frac{dy}{dx} + mny = 0$.
(ii) If $y = (\tan^{-1} x)^2$, show that $(x^2 + 1)^2 y_2 + 2x(x^2 + 1)y_1 = 2$.
[4 Marks]
✅ CBSE Step-by-Step Mathematical Solution

(i) $y = A e^{mx} + B e^{nx}$:

  1. First derivative: $$\frac{dy}{dx} = A m e^{mx} + B n e^{nx}$$
  2. Second derivative: $$\frac{d^2y}{dx^2} = A m^2 e^{mx} + B n^2 e^{nx}$$
  3. Substitute into LHS: $$\text{LHS} = \frac{d^2y}{dx^2} - (m + n)\frac{dy}{dx} + mny$$ $$= (A m^2 e^{mx} + B n^2 e^{nx}) - (m + n)(A m e^{mx} + B n e^{nx}) + mn(A e^{mx} + B e^{nx})$$ $$= A e^{mx}[m^2 - m(m+n) + mn] + B e^{nx}[n^2 - n(m+n) + mn]$$ $$= A e^{mx}[m^2 - m^2 - mn + mn] + B e^{nx}[n^2 - mn - n^2 + mn]$$ $$= A e^{mx}(0) + B e^{nx}(0) = 0 = \text{RHS}$$
Hence proved.

(ii) $y = (\tan^{-1} x)^2$:

Differentiating with respect to $x$: $$y_1 = 2(\tan^{-1} x) \cdot \frac{1}{1 + x^2}$$ Multiplying both sides by $(1 + x^2)$: $$(1 + x^2) y_1 = 2\tan^{-1} x$$ Squaring both sides (or differentiating directly by product rule):
Differentiating with respect to $x$: $$(1 + x^2) y_2 + y_1 (2x) = 2 \cdot \frac{1}{1 + x^2}$$ Multiplying both sides by $(1 + x^2)$: $$(1 + x^2)^2 y_2 + 2x(1 + x^2) y_1 = 2$$ $$\mathbf{(x^2 + 1)^2 y_2 + 2x(x^2 + 1) y_1 = 2}$$ Hence proved.

Q13
Exercise 5.7 & Board Favorite (Verbatim)
(i) If $e^y (x + 1) = 1$, show that $\frac{d^2y}{dx^2} = \left(\frac{dy}{dx}\right)^2$.
(ii) If $x = a(\cos\theta + \theta\sin\theta)$ and $y = a(\sin\theta - \theta\cos\theta)$, find $\frac{d^2y}{dx^2}$ at $\theta = \frac{\pi}{4}$.
[4 Marks]
✅ CBSE Step-by-Step Mathematical Solution

(i) $e^y (x + 1) = 1$:

Rewrite as $e^y = \frac{1}{x + 1} = (x + 1)^{-1}$.
Taking log on both sides: $$y = -\log(x + 1)$$ Differentiating with respect to $x$: $$\frac{dy}{dx} = -\frac{1}{x + 1}$$ Differentiating again: $$\frac{d^2y}{dx^2} = -\left(-\frac{1}{(x + 1)^2}\right) = \frac{1}{(x + 1)^2}$$ Notice that: $$\left(\frac{dy}{dx}\right)^2 = \left(-\frac{1}{x + 1}\right)^2 = \frac{1}{(x + 1)^2}$$ Therefore: $$\mathbf{\frac{d^2y}{dx^2} = \left(\frac{dy}{dx}\right)^2}$$ Hence proved.

(ii) Second derivative of parametric curve:

  1. $\frac{dx}{d\theta} = a[-\sin\theta + (\theta\cos\theta + \sin\theta)] = a\theta\cos\theta$.
  2. $\frac{dy}{d\theta} = a[\cos\theta - (-\theta\sin\theta + \cos\theta)] = a\theta\sin\theta$.
  3. First derivative: $$\frac{dy}{dx} = \frac{dy/d\theta}{dx/d\theta} = \frac{a\theta\sin\theta}{a\theta\cos\theta} = \tan\theta$$
  4. Second derivative: $$\frac{d^2y}{dx^2} = \frac{d}{dx}\left(\frac{dy}{dx}\right) = \frac{d}{d\theta}(\tan\theta) \cdot \frac{d\theta}{dx}$$ $$= \sec^2\theta \cdot \frac{1}{a\theta\cos\theta} = \frac{\sec^3\theta}{a\theta}$$
  5. At $\theta = \frac{\pi}{4}$: $$\sec\left(\frac{\pi}{4}\right) = \sqrt{2} \implies \sec^3\left(\frac{\pi}{4}\right) = (\sqrt{2})^3 = 2\sqrt{2}$$ $$\left. \frac{d^2y}{dx^2} \right|_{\theta = \pi/4} = \frac{2\sqrt{2}}{a\left(\frac{\pi}{4}\right)} = \mathbf{\frac{8\sqrt{2}}{\pi a}}$$

Q14
Exercise 5.5 & Board Exam Special
Find the derivative of the function given by $f(x) = (1 + x)(1 + x^2)(1 + x^4)(1 + x^8)$ and hence find $f'(1)$.
[4 Marks]
✅ CBSE Step-by-Step Mathematical Solution

Given: $f(x) = (1 + x)(1 + x^2)(1 + x^4)(1 + x^8)$.

Taking natural logarithm on both sides:

$$\log f(x) = \log(1 + x) + \log(1 + x^2) + \log(1 + x^4) + \log(1 + x^8)$$

Differentiating both sides with respect to $x$:

$$\frac{1}{f(x)} f'(x) = \frac{1}{1 + x} + \frac{2x}{1 + x^2} + \frac{4x^3}{1 + x^4} + \frac{8x^7}{1 + x^8}$$ $$f'(x) = f(x) \left[ \frac{1}{1 + x} + \frac{2x}{1 + x^2} + \frac{4x^3}{1 + x^4} + \frac{8x^7}{1 + x^8} \right]$$ $$f'(x) = (1 + x)(1 + x^2)(1 + x^4)(1 + x^8) \left[ \frac{1}{1 + x} + \frac{2x}{1 + x^2} + \frac{4x^3}{1 + x^4} + \frac{8x^7}{1 + x^8} \right]$$

Finding $f'(1)$:

  1. Value of $f(1)$: $$f(1) = (1 + 1)(1 + 1)(1 + 1)(1 + 1) = 2 \times 2 \times 2 \times 2 = 16$$
  2. Bracketed expression at $x = 1$: $$\left[ \frac{1}{2} + \frac{2}{2} + \frac{4}{2} + \frac{8}{2} \right] = \frac{1 + 2 + 4 + 8}{2} = \frac{15}{2}$$
  3. Multiplying: $$f'(1) = 16 \times \frac{15}{2} = 8 \times 15 = \mathbf{120}$$
